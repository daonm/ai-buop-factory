# Day 51 — 2026-10-08

## 목표
`로드맵.md`에서 상태가 "대기"인 항목 중 Day 번호가 가장 작은 **Day51 — AI로 상속세·증여세 계산 대행하는 법 (전자책)** 을 제작한다. Day49~50(해외직구 관부가세 계산) 페어에 이어, "AI에게 조건만 알려주면 즉시 숫자로 답이 나오는 계산기 부업" 패턴을 상속세·증여세 도메인으로 확장하는 전자책이다. 실제 래피드/스레드 계정 등록·포스팅·결제는 하지 않고 콘텐츠 제작 + 기록까지만 진행한다.

## 진행 과정

### 1. 저장소 상태 점검
- 세션 시작 시 `git status`가 `HEAD detached from refs/heads/main` 상태였음(Day42~48 진행일지에 반복 보고된 패턴과 동일 재발). `git fetch origin main && git checkout -B main origin/main`으로 origin/main과 동일한 상태의 로컬 main 브랜치를 복원하고 정상 진행.
- `로드맵.md`를 읽고 Day01~50이 모두 "완료", Day51이 가장 앞선 "대기" 항목임을 확인. 상태를 "진행중"으로 갱신하고 먼저 커밋·푸시(작업 시작 마커).

### 3. 상속세·증여세 규정 리서치 (WebSearch)
세금 계산 계열 주제라 정확한 최신 규정 확인이 중요해서 2025~2026년 기준 아래 내용을 웹 검색 3회로 확인:
- **상속공제**: 기초공제 2억 원(모든 상속에 적용), 일괄공제 5억 원(기초공제+인적공제 합계가 5억 원보다 적을 때 선택 가능, 배우자 단독상속 시 선택 불가), 배우자공제 최소 5억~최대 30억 원(실제 상속받은 금액 기준), 자녀공제 1인당 5,000만 원, 미성년자공제(1,000만 원×(19세−현재나이)), 연로자공제(65세 이상, 1인당 5,000만 원).
- **상속세·증여세 세율표**(공통): 1억 이하 10%, 1억~5억 20%(누진공제 1,000만 원), 5억~10억 30%(누진공제 6,000만 원), 10억~30억 40%(누진공제 1억 6,000만 원), 30억 초과 50%(누진공제 4억 6,000만 원). 신고세액공제 3%(기한 내 신고 시).
- **신고기한**: 상속세는 상속개시일이 속한 달의 말일부터 6개월(국외 거주·국외 재산은 9개월), 증여세는 증여받은 달의 말일부터 3개월.
- **증여재산공제**: 배우자 6억 원, 직계존속→성년자녀 5,000만 원, 직계존속→미성년자녀 2,000만 원, 기타친족 1,000만 원. 10년 단위 합산 — 부모·조부모는 "직계존속" 하나의 그룹으로 묶여 공제 한도를 공유한다는 점(개별로 따로 받을 수 없음)이 흔히 오해되는 지점이라 방법7·흔한실수 표에서 명시적으로 강조하기로 결정.
- **세대생략증여 할증**: 조부모→손자녀 직접 증여 시 산출세액의 30% 할증(수증자가 미성년자이고 증여재산가액 20억 원 초과 시 40%).
- **사전증여재산 합산**: 상속개시일 전 10년(상속인 외의 자는 5년) 이내 증여재산은 상속재산에 합산되어 상속세로 재계산됨 — "지금 증여 vs 나중에 상속" 비교(방법8)의 핵심 변수로 반영.
- **2024년 신설 혼인·출산 증여재산공제**: 혼인신고일 전후 2년 또는 출생일로부터 2년 이내 직계존속 증여에 기존 공제와 별도로 최대 1억 원 추가 공제.
- **2025년 3월 발표 개편안(유산세→유산취득세 전환)**: 자녀공제 5억 원 상향, 일괄공제 폐지, 배우자공제 최대 10억 원(실제 수령액 기준) 등이 논의 중이나 2026년 10월 현재 국회 미통과·시행 전 상태임을 확인. manuscript 방법5의 주의 문구에 "2025~2026년에도 개편 논의가 진행 중"이라고 명시해, 책 내용이 현행법 기준이며 개편 확정 시 재확인이 필요하다는 점을 안내.

## 이슈/트러블슈팅
- **detached HEAD 재발** — Day42~48에서 반복 보고됐고 Day49에서는 미재발했던 패턴이 이번 세션에서 다시 발생. `git fetch origin main && git checkout -B main origin/main`으로 즉시 복구, 작업에는 지장 없었음. 컨테이너 초기화 시점에 따라 간헐적으로 발생하는 것으로 보이며, 매 세션 시작 시 `git status`로 먼저 확인하는 절차를 계속 유지해야 함.
- `pip install pillow numpy`가 이번에도 사전 설치돼 있지 않아 즉석 설치 필요(Day43·45·47~49에 이미 보고된 것과 동일 패턴) — 이번에는 `pip install`(시스템 pip) 실행 후에도 `python3 -c "import PIL"`이 `ModuleNotFoundError`를 내는 현상이 있어, `python3 -m pip install --break-system-packages`로 다시 설치해 해결함. `pip`와 `python3`이 서로 다른 인터프리터를 가리킬 수 있다는 점을 다음 세션을 위해 기록.
- manuscript 초안에서 "빠뜨리다"를 "빠뜻리다"로 3곳 오타 — `grep`으로 발견 후 `sed`로 일괄 치환해 바로 수정. 향후 세금·법률 용어가 많은 주제에서는 작성 직후 핵심 동사·조사 오타를 `grep`으로 한 번 더 스캔하는 습관이 유효함을 확인.
