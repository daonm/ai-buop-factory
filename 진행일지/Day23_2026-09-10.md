## 진행 과정

### 1. 저장소 상태 점검 및 복구
- 세션 시작 시 `git status`가 "HEAD detached from refs/heads/main"이었고, 로컬 `main` 브랜치는 Day20에서 멈춰 있는 반면 detached HEAD는 Day21·Day22 커밋(총 4개)을 포함하고 있는 상태를 발견. 이전 회차가 로컬 main 브랜치를 갱신하지 않고 detached HEAD 상태로 커밋만 남겨둔 것으로 추정.
- `git branch -f main HEAD`로 로컬 main을 detached HEAD 위치로 옮기고 `git checkout main`으로 정상 브랜치 상태로 복구. `git push -u origin main` 시도 결과 origin/main이 이미 해당 커밋들을 갖고 있었음("Everything up-to-date") — 즉 실제 푸시는 이전에 이미 됐었고, 로컬 클론의 브랜치 포인터만 꼬여 있던 상황이었음. `git fetch origin main`으로 재확인 후 정상 상태(main이 origin/main과 동기화) 확인.

### 3. 주제 리서치 및 차별화 설계
- `WebSearch`로 "2026 프리랜서 급여 4대보험 종합소득세 계산 AI 세무 대행 부업 크몽 트렌드"와 "2026 소상공인 1인사업자 급여명세서 프리랜서 원천징수 엑셀 자동화 AI 챗봇 활용" 2회 조사.
- 확인한 핵심 사실: 2026년 국민연금 요율 9.5%·건강보험료율 7.19%로 전년 대비 인상, 종합소득세 신고기간은 매년 5월, 프리랜서 3.3% 원천징수 세율 자체는 유지되나 간이지급명세서 기준 강화, 세무 대행 수수료는 필요경비(지급수수료) 처리 가능.
- 리서치 중 가장 중요하게 판단한 것은 **세무사법상 무자격자의 "세무 대리"(신고·상담 대행) 금지** 이슈. 4대보험·종합소득세 계산기가 과거 실제로 "세무 상담"이 아니라 "엑셀 계산 도구"로 판매됐다는 로드맵 로그의 선례와 정확히 일치하는 법적 경계였기 때문에, 이 경계를 책의 핵심 차별화 훅으로 채택. 책 제목을 "세무사가 아니어도, 계산기는 팔 수 있습니다"로 정하고, 목차 3번째 방법을 "계산기와 세무 상담의 경계 긋기"로 가장 먼저 배치해 법적 리스크를 다루는 동시에 진입장벽("저는 세무사가 아닌데요")을 없애는 훅으로 설계.
- 참고 파일로 가장 최근 전자책인 `products/day21_ai-마케팅카피-대행/ebook/`(manuscript.md, ebook.html)을 정독해 형식·CSS를 재사용 기준으로 채택. Day21은 2026-09-08에 이미 카테고리 색상 구분(`--cat-a`~`--cat-d`) + 2단 프롬프트 그리드 + 배지형 체크리스트로 개정된 버전이라 별도 리디자인 없이 그대로 이어받음(2026-08-21 Day02에서 지적된 "동일 박스 단순 나열" 문제가 이미 해결된 상태).

## 이슈/트러블슈팅
- **detached HEAD로 세션 시작**: 로컬 `main` 브랜치가 이전 완료분(Day21·Day22)을 반영하지 못한 채 detached HEAD로 세션이 시작된 문제를 발견·복구(위 1번 참고). 다행히 origin에는 이미 정상 푸시돼 있었지만, 로컬 브랜치 포인터가 꼬여 있으면 다음 세션에서 실수로 오래된 main 기준으로 새 커밋을 쌓을 위험이 있었음. **다음 세션에서도 작업 시작 전 반드시 `git status`로 detached HEAD 여부를 먼저 확인하고, detached 상태라면 `git branch -f main HEAD && git checkout main`으로 복구 후 진행할 것.**
- 그 외 특이 이슈 없음 — 표지 nowrap 처리를 처음부터 꼼꼼히 적용해 673px 검증에서 추가 수정이 필요 없었고, PDF 페이지 여백도 Day21 이후 확립된 padding/margin 기준(카드 10~15px, 섹션 30px 0 34px 등)을 그대로 따라 별도 압축 없이 통과.
