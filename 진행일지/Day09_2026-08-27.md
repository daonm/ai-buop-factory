### 3. 최신 트렌드 조사 (WebSearch)

- "Notion template selling business 2026 pricing trends Gumroad" 검색 — 해외(Gumroad 등) 가격대는 단일 템플릿 $9~29, 번들 $30~47, 팀/비즈니스용 $79~149. "Life admin, 직업별 맞춤형, ADHD 플래너 등 특정 대상 템플릿이 성장하고 범용 생산성 템플릿은 하락"이라는 2026년 트렌드 신호 확인 — 이 발견을 프롤로그, 방법 1(니치 표), 에필로그에 핵심 논지로 반영.
- "노션 템플릿 갤러리 인기 카테고리 PARA 세컨드브레인 자기관리 2026" 검색 — PARA/세컨드브레인 인기, 노션 공식 템플릿 갤러리 3만 개 이상 존재 확인. "3만 개짜리 레드오션처럼 보이지만 니치는 기회"라는 반박형 홍보 논지에 활용.
- "Claude AI Notion 템플릿 설계 데이터베이스 스키마 자동화 만드는 법" 검색 — Claude-Notion MCP 연동 사례를 확인했으나, 이 책은 MCP 직접 연동보다 "AI에게 구조·수식을 설계받아 사람이 노션에 직접 입력"하는 더 낮은 진입장벽 방식으로 방향을 잡음 (구매자 대다수가 MCP 세팅까지 하지 않을 것으로 판단).

### 4. 콘텐츠 설계
- 목차를 Day07과 동일한 16단 구조(도입 1 + 준비 1 + 방법 12 + 프롬프트 1 + 체크리스트 1)로 설계: 카테고리·니치 선정 → DB 스키마 → 수식·관계형·롤업 → 버튼·자동화 → 페이지 구조·대시보드 → 비주얼 → 온보딩 가이드 → 가격 책정 → 판매 페이지 → 채널 선택 → 후기 개선 → 라인업 확장.
- 표는 두 곳에 배치: 방법 1(범용 vs 니치 카테고리 비교, 대분류/범용 예시/니치 예시 3열)과 방법 8(가격 책정 표, 유형/가격대/특징 3열, 크몽·해외 조사 데이터를 원화 환산 기준으로 재구성).
- 프롬프트는 기획·구조설계(A) / 데이터베이스·자동화(B) / 비주얼·가이드(C) / 가격·판매페이지(D) / 홍보·확장(E) 5개 카테고리로 설계, **각 카테고리 정확히 4개씩 총 20개**로 처음부터 짝수 설계(Day07에서 겪은 홀수 버그 예방 절차 적용) — 작성 완료 후 A~E 각 4개, 합계 20개임을 재검산해 표지·본문 수치와 일치 확인.
