## 진행 과정

### 1. 클라우드 세션 환경 확인
- 사용자가 이전 세션에서 세팅한 클라우드 라우틴(매일 08:00 KST 자동 실행)이 첫 실행된 세션. `git status` 확인 결과 로컬이 `HEAD detached` 상태로 시작함(직전 커밋 `7418b3c`가 브랜치 없이 떠 있었음) → `git checkout main && git pull origin main`으로 정상화. 이 환경은 매번 저장소를 새로 클론하는 방식이라 발생한 것으로 추정, 이후 커밋은 정상적으로 `main` 브랜치에 쌓이도록 확인.
- 이 세션은 로컬 Windows가 아니라 격리된 리눅스 클라우드 컨테이너에서 실행됨을 확인. 기존 `scripts/render_pdf.js`가 Windows Chrome 경로(`C:\Program Files\...`)를 하드코딩하고 있어 이 환경에서는 동작하지 않음을 사전에 파악.

- `진행일지/Day01_2026-08-20.md`를 템플릿으로 삼아 이번 일지의 항목 구성(목표/진행과정/파일목록/이슈/다음액션)을 그대로 따름.

### 4. 콘텐츠 설계 결정
- 실습자료 유형 지침(프롬프트팩 주제 → 실제 프롬프트 모음 문서)에 따라, 단순히 20개를 재탕하지 않고 **Day01의 20개 프롬프트를 5개 카테고리(A 전자책제작·B SNS홍보·C 판매/가격·D 실습자료제작·E 운영/회고)로 재구성해 60개로 3배 확장**하기로 결정. 이렇게 해야 "전자책을 이미 읽은 사람"에게도 새로운 가치가 있다고 판단.
- "그냥 문서 모음"이 아니라 **실제로 빈칸을 채우며 쓰는 워크시트**가 있어야 실행률이 올라간다고 판단해 워크시트 6종(주제선정/목차설계/가격계산기/3주홍보캘린더/반응분석/월간회고)을 설계. 각 워크시트에 관련 프롬프트 번호를 명시해서 막히면 바로 프롬프트팩으로 연결되게 구성.
- 체크리스트는 Day01의 "오늘/이번주/이번달" 3단 구조보다 실행력이 높은 **30일 일자별 체크리스트**로 확장 (1주차 기획·제작 / 2주차 다듬기·판매준비 / 3주차 홍보시작 / 4주차 분석·확장).
- 세 문서(프롬프트팩/워크시트/체크리스트)를 markdown으로 각각 만들되, 실제 판매 결과물로 쓸 수 있도록 **Day01의 `ebook.html` 디자인 시스템을 그대로 재사용한 `kit.html` 워크북**을 별도로 제작해 시리즈 톤을 통일. 표지에 "VOL.02 · 실행 키트" 배지 추가, 워크시트는 점선 밑줄(`border-bottom:1px dotted var(--gold)`) 스타일의 채울 수 있는 표로 디자인.

### 5. PDF 렌더링 — 클라우드 환경용 스크립트 신규 작성
- 기존 `scripts/render_pdf.js`(puppeteer-core + Windows Chrome 경로)는 이 클라우드 세션에서 그대로 쓸 수 없음을 확인 (puppeteer-core 미설치, Windows 경로 없음).
- 환경 확인 결과 `/opt/node22/lib/node_modules`에 `playwright`가 전역 설치되어 있고, `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`에 Chromium이 사전 설치되어 있음을 발견.
- `scripts/render_pdf_cloud.js` 신규 작성: Playwright + 사전 설치된 Chromium을 사용해 HTML→PDF 변환. `/opt/pw-browsers` 하위에서 `chromium-*` 폴더를 자동 탐색해 실행 파일 경로를 잡도록 구현(버전 번호가 바뀌어도 재사용 가능하게). 기존 `render_pdf.js`는 로컬 Windows 작업용으로 그대로 유지(삭제하지 않음) — 사용자가 로컬에서 작업할 때는 계속 필요.
- `NODE_PATH=/opt/node22/lib/node_modules node scripts/render_pdf_cloud.js <입력.html> <출력.pdf>` 형태로 실행해 `AI_부수입_실행키트.pdf`(약 1.1MB) 생성 성공.
- Playwright로 표지·워크시트 섹션을 개별 스크린샷으로 캡처해 디자인이 의도대로 렌더링됐는지 직접 확인 (골드 톤 표지, 점선 밑줄 워크시트 표 모두 정상).

## 이슈/트러블슈팅
- **git `HEAD detached` 상태로 세션 시작**: 원인 불명(클라우드 세션이 매번 저장소를 새로 준비하는 방식과 관련된 것으로 추정). `git checkout main && git pull origin main`으로 해결. 다음 실행에서도 재발할 수 있으므로, 향후 세션은 작업 시작 전 `git status`/`git branch`로 브랜치 상태를 먼저 확인하는 습관 필요.
- **`render_pdf.js`가 클라우드 환경에서 동작 불가**: Windows 전용 경로와 `puppeteer-core` 의존성 때문. `render_pdf_cloud.js`를 새로 만들어 해결. **앞으로 클라우드(자동 실행) 세션에서 PDF가 필요하면 `render_pdf_cloud.js`를, 사용자가 로컬 Windows에서 직접 작업할 때는 기존 `render_pdf.js`를 사용할 것.**
- PDF 페이지 분할 버그(Day01 일지 13~14번 항목)는 이번 `kit.html`에서는 처음부터 "큰 컨테이너에 break-inside:avoid 금지" 원칙을 적용해서 설계했기 때문에 재발하지 않음 — 렌더링된 PDF를 페이지 단위로 재검수했으나 특이사항 없음.
