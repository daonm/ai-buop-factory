# Day 21 — 2026-09-08

## 목표
로드맵.md에서 상태가 "대기"인 항목 중 Day 번호가 가장 작은 **Day 21 — AI로 마케팅 카피 대행 서비스 시작하는 법 (전자책)**을 제작한다. Day05(AI로 상세페이지 카피 잘 쓰는 법)가 상세페이지 카피 문장력 자체에 집중했다면, Day21은 그보다 넓은 범위 — 상세페이지·SNS 광고·이메일 등 여러 채널을 다루는 "카피 대행 서비스"를 **비즈니스로 시작하는 법**(브리프 인터뷰, 브랜드 톤 추출, 채널별 생성, 검수, 가격·영업)에 초점을 맞춰 차별화하는 것이 목표.

## 진행 과정

### 1. 로드맵 확인 및 저장소 상태 점검
- `git status`/`git log`로 확인한 결과 워킹트리는 깨끗했고 origin/main과 동기화된 상태(Day20까지 완료). detached HEAD 같은 이전 회차(Day20)의 이슈는 이번엔 발생하지 않음.
- `로드맵.md`에서 Day21(전자책, 대기)이 다음 작업임을 확인. Day22(실습자료 — 업종별 카피 템플릿팩)와 짝을 이루는 전자책.

### 2. 주제 차별화 및 콘텐츠 설계
- Day05가 이미 "상세페이지 카피" 단일 채널에 집중한 전자책이라, Day21은 겹치지 않도록 **카피 대행을 여러 채널(상세페이지/SNS 광고/이메일/브랜드 슬로건)을 아우르는 서비스 사업으로 시작하는 법**으로 범위를 넓혀 설계. 핵심 프레임을 "브리프 인터뷰 → 톤앤매너 추출 → 페르소나·메시지 도출 → 채널별 생성 → A/B 버전 → 검수 → 성과 개선"이라는 표준 공정으로 잡고, 이 공정 자체가 책의 훅("팔리는 문장, 재능이 아니라 공정입니다")이 되도록 프롤로그·표지 카피를 설계.
- 참고 파일로 가장 최근 전자책인 `products/day19_ai-온라인강의-커리큘럼설계/ebook/`(manuscript.md, ebook.html)을 그대로 정독하고 형식·CSS를 재사용 기준으로 채택. 카테고리 4개(A~D)로 프롬프트 16개를 나누는 관례, `.checklist-group`의 `오늘/이번 주/이번 달` 3단계 구조, 챕터 16개(왜 지금+준비+12방법+프롬프트+체크리스트) 구성을 그대로 따름.
- `WebSearch`로 "2026 프리랜서 마케팅 카피라이팅 대행 서비스 크몽 숨고 AI 카피라이터 트렌드" 조사. "카피라이터의 78%가 이미 AI 도구를 사용 중이며 2026년 콘텐츠 마케터의 90%가 AI로 콘텐츠 제작 전망"이라는 통계와, 크몽·숨고의 수수료·단가 특성(크몽=트래픽 많지만 경쟁 치열, 숨고=견적 요청형으로 단가가 크몽보다 높은 편)을 확인해 프롤로그(1장)와 13장(등록·영업) 내용에 반영.
- 12가지 방법을 "카피 종류 파악 → 브리프 인터뷰 → 톤앤매너 → 페르소나/메시지 → 채널별 생성 → A/B 버전 → 검수 → 성과 개선 → 포트폴리오(실적 없을 때) → 패키지/가격 → 플랫폼 등록·영업 → 재구매/구독 리텐션" 순서로 설계 — Day19와 동일하게 "원료 수집 → 구조 설계 → 콘텐츠 생성 → 운영" 4단계 흐름을 카피 대행 도메인에 맞게 재구성.
- 프롬프트 16개를 A.브리프·리서치(4) / B.채널별 카피 생성(4) / C.검수·최적화(4) / D.운영·영업(4) 4개 카테고리로 구성.

### 3. 원고 및 HTML 제작
- `ebook/manuscript.md`: Day19와 동일한 마크다운 구조(제목/부제 → 프롤로그 → 목차 → 본문 16절 → 에필로그)로 작성. 총 16개 섹션, 프롬프트 16개, 체크리스트 3단계(오늘 30분/이번 주 1차 완성/이번 달 확장) 모두 포함.
- `ebook/ebook.html`: Day19의 CSS(색상 토큰, Gowun Batang + Noto Sans KR + Nanum Gothic Coding 폰트, 라이트/다크 테마, `--cat-a`~`--cat-d` 4색 카테고리, `.prompt-grid` 2단 배치, `.checklist-group`의 원형 배지, 표 zebra stripe)를 그대로 복사해 재사용하고 본문 콘텐츠만 교체. 표지는 "팔리는 문장, 재능이 아니라 공정입니다"를 세리프 타이틀로, "AI 부업 시리즈 · VOL. 21" 킥커와 "CLAUDE가 기획·집필" 배지를 유지.

### 4. PDF 인쇄폭 검증 및 수정
- `scripts/screenshot_element_cloud.js`로 `.cover`를 673px(A4 실제 인쇄폭) 뷰포트에서 캡처해 확인한 결과, 부제 "AI로 마케팅 카피 대행 서비스 시작하는 법 — 그대로 쓰는 브리프·카피·검수 프롬프트 16개"에서 "그대로"가 "그 / 대로"로 줄바꿈되어 갈라지는 문제 발견.
- `<span class="nowrap">그대로 쓰는</span>`으로 감싸 수정 후 재캡처, 정상적으로 "AI로 마케팅 카피 대행 서비스 시작하는 법 —" / "그대로 쓰는 브리프·카피·검수 프롬프트 16개" 두 줄로 자연스럽게 개행되는 것을 확인.

### 5. PDF 렌더링 및 페이지 여백 검증
- `scripts/render_pdf_cloud.js`로 `팔리는_문장_재능이_아니라_공정입니다.pdf` 생성.
- 정확한 페이지 수 확인을 위해 poppler(pdfinfo) 미설치를 확인하고, PDF 원본 바이트에서 `/Type /Page` 패턴을 정규식으로 카운트하는 방법으로 총 **14페이지**를 확인. 동일한 방법으로 Day19 PDF(`그_지식_아직_커리큘럼이_아닙니다.pdf`)를 검사해 역시 14페이지임을 확인 — 본문 분량과 구조가 거의 동일한 Day19와 페이지 수가 일치해 별도 압축 없이 적정 분량으로 판단.
- `scripts/screenshot_pdf_pages_cloud.js`로 전체 페이지를 스크린샷 캡처해 육안으로 순서대로 검토. 목차 페이지 하단에 약간의 여유 공간, 05장(브랜드 톤앤매너) 챕터 제목이 페이지 하단에 걸쳐 다음 페이지로 본문이 넘어가는 지점에 중간 정도의 여백이 있었으나, 카드 2~3개 분량이 통째로 빌 정도의 심각한 빈 공간은 없음을 확인. 프롬프트 카드 그리드(15장)는 카테고리 4개(A~D) 색상이 모두 정상 렌더링되고 2단 그리드가 페이지 경계에서 깔끔하게 이어짐을 확인. 체크리스트(16장)와 에필로그도 정상.

### 6. 마케팅 자료 및 썸네일

## 이슈/트러블슈팅
- **표지 부제 줄바꿈**: "그대로"가 "그" / "대로"로 쪼개지는 문제를 673px 인쇄폭 검증 단계에서 발견, `nowrap` span으로 수정. (위 4번 참고) — 앞으로도 표지 문구에 접속사+명사 조합("그대로", "이번 달" 등)이 있으면 숫자+단위 조합과 마찬가지로 nowrap 검증 대상에 포함시킬 것.
- **poppler 미설치**: `pdfinfo`/`pdftk`/`qpdf` 모두 이 클라우드 세션에 없음. PDF 원본 바이트에서 `/Type /Page` 패턴을 정규식으로 세는 방법(`node -e "..."`)으로 페이지 수를 확인하는 우회법을 사용 — 다음 Day에서도 poppler 없이 페이지 수를 빠르게 확인할 때 이 방법을 재사용할 것.
- 그 외 특이 이슈 없음 — Day19/20에서 이미 검증된 클라우드 렌더링 파이프라인(`NODE_PATH=/opt/node22/lib/node_modules`, `/opt/pw-browsers` Chromium)이 그대로 잘 작동함을 재확인.
