- 세션 시작 시 `git status`가 `HEAD detached from refs/heads/main` 상태였음(Day42~48, Day51에 이어 반복 재발). `git fetch origin main`으로 origin/main이 현재 detached HEAD(Day52 완료 커밋)와 완전히 동일함을 확인한 뒤 `git checkout -B main origin/main`으로 로컬 main 브랜치를 복원.
- `로드맵.md`를 읽고 Day01~52가 모두 "완료"이며 "대기" 항목이 하나도 없음을 확인 — 작업 지시의 "모든 항목이 완료라면" 분기를 따라야 하는 상황.

### 4. 결혼 준비 비용 리서치 (WebSearch)
새 도메인이라 최근 시세 통계와 관련 세법 변경사항을 웹 검색 2회로 확인:
- **결혼식장+스드메 패키지 평균 비용**(한국소비자원 조사): 전국 2,160만 원, 수도권 2,665만 원, 비수도권 1,511만 원, 서울 강남권 3,509만 원. 1인당 식대 중간값이 처음으로 6만 원을 넘었고, 결혼식장 비용(대관료+식대) 중간값은 1,580만 원.
- 조사 기관·기사마다 "전국 평균"이 2,000만 원대 초반~2,000만 원대 후반까지 조금씩 다르게 보도되는 것을 확인 — manuscript·ebook.html 전반에 "통계는 조사 시점마다 다를 수 있으니 실제 업체 견적으로 재확인" 안내 문구를 반복 배치하기로 결정(세율표처럼 법령이 아니라 시장 조사치이므로, Day51의 "법 개정 가능성" 주의 문구와 유사한 역할).
- 2024년 기사 기준 신혼집 제외 평균 결혼 비용 6,298만 원(스드메 479만, 예식장 990만), 개인 사례 기준 웨딩홀 2,300만+스드메 360만+혼수 2,300만+신혼여행 1,200만=7,200만 원 — 공식 통계와 개인 사례를 구분해서 인용.
- **혼인증여재산공제**(2024.1.1 이후 증여분부터 적용): 혼인신고일 전 2년~후 2년(총 4년) 이내 직계존속 증여에 기존 공제 5,000만 원+1억 원 추가=최대 1억 5,000만 원 비과세, 양가 합산 시 부부 기준 최대 3억 원, 여러 번 혼인해도 합계 공제는 1억 원까지만, 출산증여공제와 중복 불가 — Day51~52에서 이미 다룬 세법 주제를 "자금 조달 계획의 한 변수"로 재활용(방법9).

## 이슈/트러블슈팅
- **detached HEAD 재발** — Day42~48, Day51에서 반복 보고됐던 패턴이 이번 세션에서도 다시 발생. `git fetch origin main && git checkout -B main origin/main`으로 즉시 복구, 작업에는 지장 없었음. 컨테이너 초기화 시점에 따라 간헐적으로 발생하는 것으로 보이며, 매 세션 시작 시 `git status`로 먼저 확인하는 절차를 계속 유지해야 함.
- `pip install pillow numpy`가 이번에도 사전 설치돼 있지 않아 즉석 설치 필요(Day43·45·47~49·51에 이미 보고된 것과 동일 패턴) — `python3 -m pip install --break-system-packages`로 바로 해결됨.
- 결혼 비용 통계는 세율표 같은 법령 수치와 달리 "조사 기관·시점마다 수치가 다른" 특성이 있어, Day51의 "법 개정 주의" 패턴을 "통계 변동성 주의" 패턴으로 변형해 적용함 — 세금 계열과 시장조사 계열 주제를 섞어 다룰 때 참고할 만한 패턴으로 기록.
- 타이포 사전 스캔(`grep -n "빠뜻\|핸들\|쪻\|젴"`)을 manuscript 작성 직후 바로 수행해 Day51에서 겪었던 오타 재발을 예방 — 세금·법률 용어가 많은 주제뿐 아니라 매 Day 공통 점검 단계로 정착시킬 만함.
