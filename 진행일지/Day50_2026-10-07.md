## 진행 과정

### 1. 저장소 상태 점검 — 이번엔 "detached HEAD에 Day49 미push 커밋" 패턴
- 세션 시작 시 `git status`가 "HEAD detached from refs/heads/main"을 출력. `git branch -a`로 보니 로컬 `main`은 Day48 완료 시점(`9e81698`)에 멈춰 있었고, HEAD(detached)는 Day49까지 진행된 커밋(`c373958`, `38f8ebc`)을 가리키고 있었음.
- 이번엔 이전 Day42~48 진행일지에 반복 기록된 "로컬 main 포인터만 뒤처진" 경우와 달리, `git fetch origin main`으로 확인한 결과 **origin도 아직 Day48(`9e81698`)까지만 push되어 있었고 Day49 커밋 2개가 origin에 반영되지 않은 상태**였음 — 즉 직전 Day49 세션이 로컬 커밋까지는 완료했지만 push를 하지 못했거나 세션이 종료된 것으로 추정.
- `git diff main HEAD --stat`으로 Day49 커밋에 manuscript.md·ebook.html·PDF·marketing 파일이 모두 정상적으로 포함되어 있음을 확인한 뒤, `git checkout main && git merge --ff-only c373958`로 로컬 main을 Day49 커밋까지 비파괴적으로 fast-forward.
- `git push -u origin main`으로 Day49 커밋을 origin에 반영 완료 (`c373958..9996ea9`로 이어지는 히스토리의 출발점 확보). 이 과정에서 데이터 유실은 없었음 — Day49 작업물은 로컬 커밋에 온전히 보존되어 있었고, push 동기화만 지연됐던 것.
- `로드맵.md`를 읽고 Day01~49가 모두 "완료", Day50이 가장 앞선 "대기" 항목임을 확인 → 상태를 "진행중"으로 갱신하고 커밋·푸시.

### 3. 엑셀 계산기 3종 + 가이드 1종 + 워드 템플릿 1종 설계·제작
Day49 전자책 방법을 아래 5개 파일로 재구성(Day48의 "4개 xlsx + 1개 docx" 패턴을 "3개 계산기 xlsx + 1개 가이드 xlsx + 1개 docx"로 변형 — 로드맵 Day50 제목이 "계산기 + 사이트별 가이드 템플릿팩"이라 가이드를 별도 산출물로 명시):
- **A. 면세판단_관부가세_계산기.xlsx** — 방법1(면세기준·자가사용 판단)+방법2(과세환율 적용)+방법3(품목별 관세율 계산)+방법4(부가세 포함 총 관부가세)를 하나로 통합. 면세 기준(미국 200달러/그 외 150달러)·품목별 간이세율 참고표(의류·신발·가방·시계·화장품·완구·서적·전자기기·건기식 9종)를 VLOOKUP으로 자동 반영, 발송국가·물품가격·배송비·품목·과세환율 입력 → 면세 여부 → 원화 과세가격 → 관세 → 부가세 → 총 관부가세·최종 총지출액까지 8단계 수식 체인.
- **B. 합산과세_시나리오비교_계산기.xlsx** — 방법5(합산과세 판단)+방법6(면세 한도 초과 시나리오 비교)를 통합. 판매자 동일여부·구매일자 동일여부를 AND 조건으로 판정해 합산 대상 여부 자동 계산, 한도내/소폭초과(+10달러)/대폭초과(+100달러) 3개 시나리오의 예상 관부가세·실질 총단가를 수식으로 자동 비교.
- **C. 품목별_추가세금_계산기.xlsx** — 방법8(품목별 주의사항)을 확장. 주종별(위스키·브랜디, 와인, 맥주, 전통주) 주세율(종가세 기준 72%/30%/72%/30%)·교육세율·1인당 반입 면세 한도 참고표를 만들고, 원화 과세가격+관세를 입력하면 주세→교육세→추가 부가세까지 자동 계산. 건강기능식품·화장품 체크리스트 4항목, 전자기기(KC인증 등) 체크리스트 4항목을 별도 표로 추가.
- **D. 사이트별_직구_가이드.xlsx** — 방법7(개인통관고유부호 안내)+로드맵 Day50 제목이 명시한 "사이트별 가이드"를 신규 설계. 아마존·알리익스프레스·테무·쉬인·이베이·큐텐/지마켓글로벌·라쿠텐·타오바오 8개 사이트의 목록통관 가능 여부·배송비 분할배송 이슈·인보이스 이슈·주의사항을 비교표로 정리하고, 별도 시트에 개인통관고유부호 발급 절차·갱신 주기(신규 발급자 1년)·만료 시 영향·확인 방법을 정리. 계산 파일이 아니라 참고용 리서치 자료로 설계.
- **E. 의뢰접수_고객리포트_템플릿.docx** — 방법9(대행 수익화)의 의뢰 접수 질문지(9문항: 사이트·국가·물품가격·배송비·품목·합산여부·통관부호·사업자여부·희망결과물)에 사이트·품목별 특이사항 체크표, 고객용 관부가세 리포트 템플릿(6단계), 서비스 안내·가격 템플릿(4단계 패키지)을 추가.
- 모든 수식은 Day48과 동일한 색상 컨벤션(입력=연한 골드 `FFF6D9`, 결과=연한 올리브 `E3E6CE`, 헤더=골드 `B87F1F`+흰 글자)을 openpyxl 스크립트로 생성.
- **이번 컨테이너에서 LibreOffice가 정상 동작**해, `soffice --headless --convert-to xlsx`로 각 계산기를 실제로 재계산시킨 뒤 `openpyxl(data_only=True)`로 결과값을 읽어 수식을 직접 검증: 계산기 A(미국·의류 195달러→면세, 265달러→관부가세 88,865원/최종 454,565원), 계산기 B(그 외 국가·110+95달러 합산→205달러 과세 대상, 미국·소폭초과 시나리오→관부가세 70,421원/실질단가 360,221원), 계산기 C(위스키 2병·과세가격 50만원→주세 360,000원+교육세 108,000원+추가부가세 46,800원=총 514,800원) 모두 수작업 재계산과 일치함을 확인 — Day48에서 "LibreOffice 실행 불가로 Python 재구현 검증으로 대체"했던 것과 달리, 이번엔 LibreOffice 자체의 수식 재계산 결과로 직접 검증.

- **Day49 커밋이 로컬에만 존재하고 origin에는 push되지 않은 상태로 발견됨.** 기존에 5회 연속 보고된 "로컬 main 포인터만 뒤처진" 패턴과 달리, 이번엔 origin 자체가 Day48까지만 반영돼 있었음 — 즉 Day49를 진행한 세션이 로컬 커밋(`38f8ebc`, `c373958`)까지는 정상 완료했지만 `git push`를 실행하지 못했거나 세션이 push 전에 종료된 것으로 추정됨. `git diff main HEAD --stat`으로 Day49 커밋에 모든 산출물(manuscript.md·ebook.html·PDF·marketing 3종·진행일지)이 완전하게 포함돼 있음을 확인한 뒤 `git checkout main && git merge --ff-only`로 비파괴적으로 병합하고 즉시 `git push`로 origin에 반영 완료. **데이터 유실 없이 복구했지만, 매 세션 컨테이너가 작업을 로컬 커밋까지만 하고 종료되는 경우가 있는 것으로 보여, 작업 완료 후 push 성공 여부를 세션 마지막에 반드시 재확인하는 절차가 필요함을 다음 세션에 전달.**
- **LibreOffice가 이번 컨테이너에서는 정상 동작함** — Day48 진행일지에서 "모든 xlsx 파일 열기 실패"로 보고됐던 것과 달리, `~/.config/libreoffice` 캐시를 비운 뒤 `soffice --headless --convert-to xlsx`가 정상적으로 수식을 재계산함을 확인. 이번엔 Python 수식 재구현 대신 LibreOffice의 실제 재계산 결과로 모든 계산기(A·B·C)를 직접 검증 — 컨테이너마다 LibreOffice 가용 여부가 달라질 수 있으므로, 다음 세션에서도 먼저 캐시를 비우고 간단한 테스트 파일로 가용 여부를 확인하는 절차를 권장.
- `pip install openpyxl python-docx pillow numpy`가 이번 컨테이너에도 사전 설치돼 있지 않아 즉석 설치 후 진행 — 이전 Day들에 이미 보고된 것과 동일한 상황으로, 매 세션 컨테이너가 새로 시작되는 한 계속 반복될 것으로 예상됨. (`pip`가 python3.13 환경을 가리키고 실제 실행되는 `python3`는 3.11이라, `python3 -m pip install`로 설치해야 함에 유의.)
- 표지 줄바꿈 문제, 카드 밀림으로 인한 여백 문제는 Day46~49에서 확립된 템플릿·검증 절차를 그대로 재사용해 추가 수정 사이클 없이 1차 작업에서 전체 검증을 통과함.
