# Day 01 — 2026-08-20

## 목표
사용자가 공유한 유튜브 영상("AI에게 100만 원 벌어오라 했더니 2,873만 원을 벌어왔습니다", 채널 윤자동)을 참고해, 클로드를 활용해 상품을 만들고 판매까지 진행하는 프로세스를 실제로 구축·실행한다.

## 진행 과정

### 1. 원본 영상 조사
- `WebFetch`로 유튜브 페이지 직접 접근 시도 → 실패 (YouTube가 JS 렌더링 콘텐츠라 자막/설명 추출 불가)
- `youtubetotranscript.com`, `youtube-transcript.io` 등 3rd party 자막 추출 서비스 시도 → 모두 403 또는 빈 응답
- YouTube 공식 `oEmbed` API(`https://www.youtube.com/oembed?...`)로 제목/채널명만 확보 성공
  - 제목: "(실화) AI에게 100만 원 벌어오라 했더니 2,873만 원을 벌어왔습니다."
  - 채널: 윤자동
- `WebSearch`로 채널 성격 추가 확인: 18년차 자동화 전문가, 평소 클로드 코드로 PC 자동화(브라우저 조작, 스레드 포스팅 등) 시연하는 채널
- **결론**: 영상의 정확한 스크립트(어떤 상품을 정확히 어떤 순서로 팔았는지)는 끝내 확보하지 못함. 채널 성격과 제목만으로 "AI가 시장조사→상품제작→SNS 홍보→판매까지 주도한 실험"이라는 큰 틀만 추정하고 사용자에게 확인을 구함.

### 2. 방향 설정 (사용자 확인)
`AskUserQuestion`으로 3가지 확인:
- 상품 유형: 사용자가 "AI 활용법 전자책"이라고 확인 (영상 속 실제 상품)
- 판매 채널: "래피드(latpeed)" — `WebSearch`로 실체 확인. 사업자등록 없이 PDF/디지털 콘텐츠 판매 가능한 한국 플랫폼
- 실행 범위: "계획+콘텐츠 제작까지" (실제 계정 등록/결제는 사용자가 직접) — 이 원칙은 이후에도 유지 중

### 3. 1차 산출물 제작
- `ebook/manuscript.md`: "AI를 활용한 부수입 방법" 전자책 초안. 12가지 방법(전자책 제작, 스레드 홍보, 프리랜서 외주, 노션 템플릿, 업무자동화 대행, 숏폼 스크립트, 강의 커리큘럼, 자소서 첨삭, 마케팅 카피, 리서치 리포트, 챗봇 세팅, AI 컨설팅) + 프롬프트 20선 + 실전 체크리스트 구성
- `marketing/sales_page.md`: 래피드 상세페이지 카피, 가격 제안(9,900원 → 후기 쌓이면 14,900원, 얼리버드 6,900원)
- `marketing/threads_posts.md`: 스레드 7일치 홍보 글(스토리/질문/리스트/반박/공감/증거/긴급성 톤), 댓글 답글 템플릿
- `ebook/ebook.html`: `artifact-design` 스킬 로드 후 디자인 시스템(색상: 웜페이퍼+인디고잉크+골드 액센트, 폰트: Gowun Batang(표지/제목)+Noto Sans KR(본문)+Nanum Gothic Coding(프롬프트박스)) 수립해 표지 포함 완성본 제작
- `Artifact` 툴로 발행: https://claude.ai/code/artifact/89e40380-9046-4f43-a30a-b331e14da39d (브라우저에서 열어 인쇄→PDF저장 가능)

### 4. 핵심 피드백 반영 — "AI가 썼다"는 훅이 약하다
사용자 질문: "이걸 클로드가 썼다 하면 팔릴까?"
- 판단: "AI가 썼다"는 문구 자체는 요즘 저품질 AI 콘텐츠 범람 때문에 오히려 신뢰를 깎을 수 있음. 원본 영상이 실제로 주목받은 이유는 "AI 저작"이 아니라 "100만원→2,873만원"이라는 **구체적 결과 숫자**였을 가능성이 높다고 답변.
- 대안 제시: (1) 표지 카피를 결과/숫자 중심으로 전환 (2) 실제로 방법을 실행해 나온 진짜 결과를 훅으로 재구성 — 사용자 결정 대기 중.

### 5. 방향 전환 — 단일 상품 → 매일 생산 파이프라인
사용자 피드백:
- 원본 영상은 "참고"였을 뿐 그대로 재현하라는 뜻이 아니었음
- 실제 목표: 코딩/상세페이지/영상제작 등 "AI로 할 수 있는 것들"을 주제별로 **매일 하나씩** 자동 제작·테스트 (무엇이 팔릴지 모르니 다양하게 시도)
- 한 주제당 순서: **전자책 → 그 주제의 실습자료(소스코드/템플릿)**
- 실행은 **매일 아침 자동**으로 원함
- 래피드/스레드 계정 자동화 필요 여부 질문 → 이 환경에는 브라우저 자동조작 도구가 없음을 확인 및 설명. 콘텐츠 제작은 100% 자동, 실제 등록/포스팅은 사용자가 복붙으로 진행하는 역할 분담으로 정리.

### 6. 자동화 인프라 구축 착수
- `schedule` 스킬 로드 → 클라우드 라우틴(RemoteTrigger)은 격리된 클라우드 샌드박스라 로컬 폴더에 접근 불가 → **GitHub 저장소 필요**를 사용자에게 설명
- 사용자에게 로컬(Windows 작업 스케줄러) vs 클라우드(GitHub 연동) 중 선택 요청 → **클라우드 방식** 선택
- `gh` CLI 미설치 확인 (Bash, PowerShell 둘 다) → 자동 저장소 생성 불가, 사용자에게 수동으로 빈 GitHub 저장소 생성 요청
- 사용자가 저장소 URL 제공: `https://github.com/daonm/ai-buop-factory`

### 7. 로컬 Git 저장소 세팅
- `git init` 시도 중 "dubious ownership" 오류 발생 (Windows 파일시스템 특성상 소유권 기록 안 됨) → `git config --global --add safe.directory` 로 해결
- 로컬 git identity 설정: user.name "daonm", user.email "lgcjnk2@gmail.com" (repo-local config, global 아님)
- 기본 브랜치명 `main`으로 설정

### 8. 폴더 구조 재정비 (매일 생산 체계에 맞게)
기존 루트의 `ebook/`, `marketing/`, `실행계획.md`를 1일차 결과물로 재배치:
```
0.부업 자동화/
├── 로드맵.md                  ← 매일 실행 시 참조하는 주제 큐 (신규)
├── 진행일지/                  ← 일자별 상세 작업 기록 (신규, 이 파일)
└── products/
    └── day01_ai-부수입-가이드/
        ├── ebook/manuscript.md, ebook.html
        ├── marketing/sales_page.md, threads_posts.md
        └── 실행계획.md         ← 원래 루트에 있던 파일 이동
```
- `로드맵.md`: Day01~22까지 11개 주제 × (전자책+실습자료) 큐 작성. 운영 규칙(상태 갱신, 폴더 규칙, 일지 규칙, 반응 기반 재배치 규칙) 명시.
