### 4. 수식 버그 2건 발견·수정
- **`노후소득_합산진단_계산기.xlsx`의 "국민연금 수령여부" 열 버그** — 최초 작성 시 `=IF(B{row}>={r_np_age},"수령","미수령")`에서 `{r_np_age}`가 셀 참조("$C$6")가 아니라 파이썬 변수(정수 행번호 6) 그대로 문자열에 꽂혀 들어가, 실제로는 `=IF(나이>=6,"수령","미수령")`이 되어 모든 연령 구간에서 "수령"으로 잘못 표시되는 버그였다. 1차 LibreOffice 재계산 결과에서 "60세인데 국민연금 수령여부가 '수령'으로 나오는데 월액은 0원"이라는 모순을 발견해 원인을 추적 — `$C${r_np_age}` 형태의 절대참조로 수정.
- **"상태" 열 설계 실수** — 진단표 헤더에 "상태"(8번째 컬럼, I열)를 만들어놓고 실제로는 거기에 값을 채우지 않은 채 별도로 10번째 컬럼(J열)에 "부족분 상태"라는 새 헤더와 값을 추가해, 표에 빈 헤더만 있는 열이 생기는 실수를 1차 작성 중 발견 — J열 로직을 I열로 옮겨 헤더-값이 일치하도록 정정.
- **합산진단 계산기 예시값 설계 미흡** — 최초 기본값은 국민연금·개인연금 수령 시작 나이가 둘 다 65세로 같아서, 전자책에서 강조한 "소득 크레바스"(한쪽만 먼저 들어오는 소득 공백 구간) 예시가 전혀 드러나지 않았다. 개인연금 수령 시작 나이 기본값을 65세→60세로 바꿔, 60세 구간에서 "국민연금 미수령 + 개인연금 수령"이라는 실제 크레바스 완충 사례가 보이도록 조정.

## 이슈/트러블슈팅
- **엑셀 수식 버그 2건** — (1) "국민연금 수령여부" IF 조건에서 파이썬 변수(행번호)가 셀참조 대신 그대로 박혀 들어가 모든 나이가 "수령"으로 잘못 표시된 버그, (2) 헤더만 만들고 값은 안 채운 빈 "상태" 열. 둘 다 LibreOffice headless 재계산 결과를 꼼꼼히 들여다보는 과정에서 발견·수정했다 — **엑셀 수식을 동적으로 문자열 포맷팅할 때는 셀 참조 문자열(`$C$6`)과 파이썬 변수(정수 `6`)를 혼동하지 않도록, 수식 작성 직후 반드시 LibreOffice 재계산 값을 셀 단위로 눈으로 대조할 것.**
- **표지 줄바꿈 검증의 허점** — 673px 단독 스크린샷만으로는 실제 PDF 뷰어 렌더링에서 발생하는 단어 중간 줄바꿈을 놓칠 수 있다는 것을 이번에 처음 확인했다. 673px 캡처에서는 "국민연금·개인연금 노후 수령액,"이 멀쩡해 보였지만, PDF 전체 페이지를 렌더링해서 보니 "개인연" / "금"으로 단어가 끊겨 있었다 — **다음 Day부터는 673px 단독 캡처 확인에서 끝내지 말고, 반드시 PDF 전체 렌더링 후 1페이지(표지)를 다시 한 번 육안 확인하는 것을 표준 절차에 추가할 것.**
- **PDF 페이지 하단 빈 공간(카드 밀림)** — "04 판매 준비 체크리스트"의 마지막 두 체크리스트 카드와 에필로그가 통째로 다음 페이지로 밀리면서 그 앞 페이지에 약 44% 빈 공간이 생겼던 것을, `section.chapter`/`.worksheet`/`.domain-block`/`.task-grid`/`.task-card`/`.checklist-group`의 padding·margin을 1~2px씩 줄여 해결. `scan_page_margins.py` 정량 스캔으로 2~6페이지가 전부 21% 이하임을 재확인.
- **python3/pip3 인터프리터 불일치 재발** — `openpyxl`/`python-docx` 설치 시, 그리고 이후 `scan_page_margins.py` 실행을 위한 `pillow`/`numpy` 설치 시에도 동일한 문제가 반복됐다(`python3`는 `/usr/local/bin/python3`, `pip3`는 `/usr/bin/pip3`를 가리켜 서로 다른 인터프리터에 설치됨). `python3 -m pip install` 또는 `/usr/local/bin/python3 -m pip install --force-reinstall`로 명시적으로 현재 인터프리터에 설치해 해결 — Day57~61에서도 반복된 문제이므로 다음 Day부터는 작업 시작 시점에 `python3 -c "import openpyxl"` 등으로 먼저 확인 후 필요하면 바로 `python3 -m pip install`을 쓰는 습관을 들일 것.
