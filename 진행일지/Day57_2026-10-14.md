## 진행 과정

### 1. 저장소 상태 점검
- 세션 시작 시 `git status`가 `HEAD detached from refs/heads/main` 상태였음(Day42~48·51·53·55에 이어 반복되는 패턴). `git fetch origin main`으로 확인한 결과 origin/main(`6ba2fc6`, Day56 완료 커밋)과 detached HEAD가 완전히 동일했고, 로컬 `main` 브랜치만 Day55(`b2d72b5`)에 멈춰 있던 오래된 참조였음.
- 로드맵 편집 중이던 작업 트리를 `git stash`로 대피시킨 뒤 `git checkout main && git merge --ff-only origin/main`으로 로컬 main을 fast-forward하고, `git stash pop`으로 편집을 복원 — Day55 진행일지에 기록된 것과 동일한 해결 절차를 그대로 재사용.
- `로드맵.md`를 읽고 Day57(AI로 재산세·종합부동산세 계산 대행하는 법, 전자책)이 "대기" 상태인 첫 행임을 확인. Day53~62 큐는 2026-10-10에 이미 추가되어 있어 이번엔 신규 주제 추가 단계 없이 바로 진행.

### 3. 재산세·종부세 리서치 (WebSearch 4회)
세율·공제 기준이 해마다 고시·개정되는 세금 도메인이라, 최신 기준값과 2026년 세제개편 동향을 함께 확인:
- **재산세 과세표준**: 공시가격 × 공정시장가액비율(1세대1주택 공시가격 구간별 43~45%, 다주택·일반 60%)로 구하는 구조를 확인. 세율은 과세표준 6천만 원 이하 0.1%, 6천만~1억5천만 원 6만 원+0.15%, 1억5천만~3억 원 19만5천 원+0.25%, 3억 원 초과 57만 원+0.4%의 4단계 누진 구조.
- **1세대1주택 특례**: 공시가격 9억 원 이하 1세대1주택자는 구간별 0.05%p 인하된 특례세율 적용. 도시지역분(과세표준의 0.14%, 지역에 따라 해당 여부 다름)과 지방교육세(재산세 본세의 20%)가 추가로 붙는 구조도 확인.
- **세부담상한**: 전년도 세액의 105~130% 범위를 초과해서 오르지 않도록 제한하는 제도. 분할납부 기준(250만 원 초과 시 신청 가능, 250~500만 원은 초과분을, 500만 원 초과는 세액의 50% 이하를 분할), 납부 시기(주택분 7월·9월 각 1/2, 20만 원 이하는 7월 일괄)도 함께 확인.
- **종부세 공제금액·세율**: 1세대1주택 12억 원, 다주택·일반 9억 원 수준의 공제 구조와 공정시장가액비율 60% 체계가 현재까지 유지되어 왔음을 확인. 다만 **2026년 세제개편안(진행 중, 미확정)**에서 1세대1주택 공제금액 14억 원 확대, 과세표준 6~12억 구간 세율 1.0%→1.3% 인상, 공정시장가액비율 60%→70% 상향이 논의되고 있다는 점도 함께 확인 — 확정 법령이 아니라 "개편안 단계"라는 점이 검색 결과에 명확히 드러나, 책 본문에는 이 개편안 수치를 넣지 않고 현재까지 통용되는 기준 구조만 서술하기로 결정(혼선을 막기 위한 판단).
- **고령자·장기보유 세액공제**: 1세대1주택자 한정, 고령자 공제(60세 20%/65세 30%/70세 40%)와 장기보유 공제(5년 20%/10년 40%/15년 50%)가 합산 적용되며 합산 한도가 있는 구조. 2027년 이후 보유기간 공제가 거주기간 공제로 전환되는 개편안도 있으나, 역시 "시행 전 개편안"이라 본문에는 현행 구조만 반영.

## 이슈/트러블슈팅
- **로컬 `main` 브랜치 참조 정체** — Day55에서 보고된 것과 동일한 패턴(로컬 main이 과거 커밋에 멈춰 있고 origin/main·detached HEAD는 최신으로 동기화돼 있던 상태)이 이번에도 재발. `git stash` → `git checkout main` → `git merge --ff-only origin/main` → `git stash pop` 순서로 해결. 이 패턴이 이제 거의 매일 재발하고 있어, 다음 세션에서도 세션 시작 시 가장 먼저 `git fetch origin main`과 로컬 main의 커밋 비교부터 수행할 것을 권장.
- **PDF 여백 스캔 스크립트 의존성 누락** — `scripts/scan_page_margins.py` 실행 시 `ModuleNotFoundError: No module named 'PIL'` 발생. `pip3 install pillow`는 설치 성공 메시지를 냈지만 실제로는 `python3.13` 환경에 설치되고 있었고, 이 세션의 `python3`는 `/usr/bin/python3.11`을 가리키고 있어 설치가 반영되지 않았던 것이 원인(시스템에 python3.11/3.12/3.13이 공존). `python3.11 -m pip install pillow numpy`로 실행 인터프리터에 직접 설치해 해결. 다음 세션에서 동일 에러가 재발하면, `python3 --version`과 `pip3 --version`이 가리키는 인터프리터가 다를 수 있다는 점부터 의심할 것.
- **2026년 세제개편안과 현행 기준 구분** — 종부세 공제금액 확대(12억→14억), 세율 인상, 공정시장가액비율 상향 등이 "2026년 세제개편안"으로 논의 중이라는 검색 결과를 확인했으나, 법 개정 완료 여부가 불확실해(검색 결과만으로는 국회 통과 여부 확인 불가) 책 본문에는 이 개편안 수치를 넣지 않고 현행(개편 전) 기준 구조만 서술하기로 결정. 다음 세금 관련 Day(59~62: 육아휴직급여·출산휴가급여, 국민연금·개인연금)에서도 세제·급여 기준이 개편 중인 항목이 있는지 먼저 확인하고, 확정되지 않은 수치는 책에 넣지 않는 동일한 원칙을 유지할 것.
