### 4. 콘텐츠 리서치 (WebSearch)
- "2025 부동산 중개수수료 요율표 매매 전세 계산법" → 매매 0.4~0.7%(거래금액 구간별), 전세(임대차) 0.3~0.8% 구간별 상한 요율 확인 → 방법 5(중개수수료 계산)의 표에 정확히 반영.
- "포장이사 비용 견적 평수별 시세 2025" → 15평 약 50만원, 24평 약 80만원, 30~34평 90만원 이상, 1톤/2.5톤/5톤 차량별 비용대 확인 → 방법 2(평수·거리별 비용 계산)에 반영.
- "이사 손없는날 비용 차이 성수기 비수기" → 평일 < 주말·월말 < 손없는날(평일) < 손없는날(주말) 순으로 비용 상승, 성수기(2~4월/9~11월)는 비수기 대비 20~30%, 많게는 50% 이상 비쌀 수 있다는 점 확인 → 방법 3(날짜 전략)에 반영.
- "이사 체크리스트 전입신고 확정일자 순서 전월세 계약" → 전입신고는 이사 후 14일 이내, 전월세신고(보증금 6천만원 초과 또는 월세 30만원 초과)는 계약일로부터 30일 이내, 전입신고와 확정일자는 같은 날 처리하는 것이 안전하다는 실무 팁 확인 → 방법 7(행정 체크리스트)에 정확히 반영.
- 위 리서치를 바탕으로 11가지 방법을 설계: ①이사 비용 구성 원리 ②평수·거리별 비용 계산 ③손없는날·성수기 반영 날짜 전략 ④견적서 3개 비교·바가지 판별 ⑤중개수수료 법정 상한액 계산 ⑥중개수수료 협상 멘트 ⑦전입신고·확정일자·전월세신고 체크리스트 ⑧이사 당일 타임라인·역할분담 ⑨대행 부업 수익화 ⑩흔한 실수 ⑪나만의 대행 시스템. 프롬프트는 A(이사비용 계산)·B(중개수수료 계산)·C(견적 비교·검증)·D(행정·대행 서비스화) 4개 카테고리 × 4/4/4/3개로 총 15개.

### 6. 표지 인쇄 폭(673px) 검증 — 1차 실패 후 수정
- 1차 PDF 렌더링 후 150dpi(약 1240px 폭) 스크린샷을 육안 확인한 결과, 표지 부제 "AI로 이사 비용 · 부동산 중개수수료 계산 대행하는 법 — 그대로 쓰는..."이 "계산 대행하" / "는 법 —"으로 단어 중간에서 갈라지는 문제를 발견. `<span class="nowrap">`으로 감싸지 않은 구간이었음.
- `계산 대행하는 법` 전체를 `<span class="nowrap">`으로 감싸도록 수정.
- `scripts/screenshot_element_cloud.js`로 `.cover`를 673×950px(실제 PDF 인쇄 폭)로 재캡처해 육안 확인 — 제목·부제·통계 배지 3개 모두 어색한 줄바꿈 없이 깔끔하게 출력됨을 확인.

### 7. PDF 렌더링 및 페이지 여백 검증
- 수정된 HTML로 `scripts/render_pdf_cloud.js`를 재실행(A4, margin 18mm/16mm) → `그견적서_AI한테먼저검증받으세요.pdf` 생성.
- `pdftoppm -r 150`으로 전체 페이지를 PNG로 변환해 정확한 페이지 수(총 **14페이지**) 확인.
- `scripts/scan_page_margins.py`로 페이지별 하단 여백 비율을 정량 스캔 — 표지(1p, 42.8%)와 마지막 에필로그(14p, 38.0%)만 30% 경고 기준을 넘었고, 본문 2~13p는 전부 7.6~19.5%로 정상 범위.
- Read 도구로 1p(표지), 5p, 7p, 12p, 13p, 14p를 직접 육안 확인: 표지·에필로그는 Day41에서도 동일하게 나타난 책 말미/표지 관례적 여백으로 문제 삼지 않음(기존 진행일지 기준과 동일). 본문 페이지는 카테고리별 색상 구분 2단 프롬프트 그리드, zebra stripe 표, 원형 배지 체크리스트가 자연스럽게 페이지 경계를 채우고 있어 중간에 30% 이상 비는 페이지 없음을 확인.

## 이슈/트러블슈팅
- **표지 부제 단어 중간 줄바꿈** — 1차 PDF 렌더링(150dpi, 약 1240px 폭) 육안 확인에서 "계산 대행하" / "는 법 —"처럼 "대행하는" 이라는 한 단어가 줄 경계에서 갈라지는 문제 발견. 원인은 해당 구간을 `<span class="nowrap">`으로 감싸지 않았기 때문. `계산 대행하는 법` 전체를 nowrap으로 묶어 해결하고, 673px(실제 PDF 인쇄 폭) 스크린샷으로 재검증 완료.
