# Day 49 — 2026-10-06

## 목표
`로드맵.md`에서 상태가 "대기"인 항목 중 Day 번호가 가장 작은 **Day49 — AI로 해외직구 관부가세 계산 대행하는 법 (전자책)** 을 제작한다. Day47~48(자동차 구매 비교 계산) 페어에 이어, "AI에게 조건만 알려주면 즉시 숫자로 답이 나오는 계산기 부업" 패턴을 해외직구 관부가세 도메인으로 확장하는 전자책이다. 실제 래피드/스레드 계정 등록·포스팅·결제는 하지 않고 콘텐츠 제작 + 기록까지만 진행한다.

## 진행 과정

### 1. 저장소 상태 점검 — 이번엔 detached HEAD 재발 없음
- `git status` 확인 결과 `On branch main`, `Your branch is up to date with 'origin/main'`로 정상 상태. Day42~48 진행일지에 반복 보고됐던 detached HEAD 패턴이 이번 세션에서는 재발하지 않음(로컬 main이 origin과 이미 일치).
- `로드맵.md`를 읽고 Day01~48이 모두 "완료", Day49가 가장 앞선 "대기" 항목임을 확인.

### 2. 참고 자료 파악 — Day47 전자책을 구조·디자인 템플릿으로 그대로 재사용
- `products/day47_ai-자동차구매비교-계산-대행/ebook/manuscript.md`·`ebook.html`을 정독해 "11가지 방법(방법1~11) + 시작전 준비 + 바로쓰는 프롬프트15선(A~D 4카테고리) + 실전체크리스트" 15섹션 구조와, `ebook.html`의 CSS 디자인 시스템(색상 토큰, Gowun Batang+Noto Sans KR+Nanum Gothic Coding 폰트, `.prompt-grid`/`.checklist-group`/`.worksheet-note` 등 클래스 컨벤션)을 그대로 재사용하기로 결정 — Day01부터 이어진 시리즈 룩앤필 통일을 위해 신규 디자인 시도 없이 전체 CSS를 복사.
- `products/day48_.../marketing/sales_page.md`·`threads_posts.md`를 참고해 마케팅 문서 톤·구조(상품명/부제/가격제안/상세카피/FAQ, 발행순서표+7종 홍보글+댓글답글템플릿)도 동일 패턴으로 재사용.

### 3. 해외직구 관부가세 규정 리서치 (WebSearch)
주제가 세금 계산 계열이라 정확한 최신 규정 확인이 중요해서 2026년 기준 아래 내용을 웹 검색으로 확인:
- **면세 기준**: 미국 200달러, 그 외 국가 150달러. 자가사용물품(본인 명의·본인 사용 목적)일 때만 목록통관 면세 적용.
- **면세 기준 초과 구조**: 1달러라도 초과하면 "초과분"이 아니라 "전체 금액"에 관세·부가세가 부과됨 — 흔히 오해하는 지점이라 방법1·방법6·흔한실수 표에서 반복 강조하기로 결정.
- **합산과세**: 2026년에도 "상품이 국내로 들어오는 날"이 아니라 "구매일(결제일)" 기준으로 같은 판매자에게 같은 날 구매한 건을 합산해 면세 기준 초과 여부를 판단. 구매 날짜가 다르면 합산 대상에서 제외.
- **과세환율**: 관세청 과세환율은 전주(월~금) 평균 환율을 다음 한 주 동안 고정 적용하는 방식 — 시중 환율과 다르므로 AI가 임의 추정하지 말고 사용자가 직접 확인한 값을 입력하도록 설계(방법2).
- **관세·부가세 계산식**: 관세 = 과세가격(CIF, 물품가+국제운송비+보험료) × 관세율(간이세율 또는 HS코드별 일반세율), 부가세 = (과세가격+관세) × 10%.
- **개인통관고유부호**: 2026년부터 갱신 제도 변경 — 신규 발급자는 발급일 기준 1년, 기존 발급자는 2027년 본인 생일이 만료일로 전환되는 과도기 규정. 방법7에서 이 변경사항을 명시적으로 반영.
- 품목별 변수(주류 주세·교육세 추가, 건강기능식품 식약처 통관보류 가능성, 전자기기 전파인증 KC 대상 여부)는 방법8에서 별도 장으로 분리 — Day47의 "전기차 감면 재계산" 장과 같은 역할(기본 계산만으로 끝나지 않는 예외 케이스를 별도로 짚어주는 장).

### 4. manuscript.md 작성 (Day47과 동일한 15섹션 구조)
- 시작하며 → 목차 → 방법1~11(왜필요한가/준비물/면세판단/환율환산/관세계산/부가세계산/합산과세판단/시나리오비교/통관고유부호/품목별주의사항/대행수익화) → 흔한실수(표) → 대행시스템구축 → 프롬프트15선(A.면세·합산판단 4개/B.환율·관세·부가세계산 4개/C.시나리오·품목별변수 4개/D.대행서비스화 3개) → 실전체크리스트(오늘30분/이번주1차완성/이번달확장) 순서로 작성.
- 모든 세율·규정 수치에 "추정치, 실제 적용 전 관세청 유니패스·관세사 확인 필요" 안내 문구(`<div class="note">`)를 각 장마다 포함 — Day47의 세율 변동 안내 패턴을 그대로 세금 영역에 적용.

### 5. ebook.html 제작 — Day47 CSS 디자인 시스템 1:1 재사용
- Day47 `ebook.html`의 `<style>` 전체(색상 토큰 `--paper`/`--gold`/`--cat-a~d`, 다크모드 대응, `.cover`/`.toc`/`.prompt-grid`/`.checklist-group` 등 전 클래스)를 그대로 복사하고 본문 콘텐츠만 Day49 manuscript 기준으로 전면 교체.
- 표지 제목 "그 직구, 관세청 문자 받기 전에 AI한테 먼저 계산받으세요"는 Day47보다 길어서 `clamp(2.0rem, 6vw, 3.1rem)`로 폰트 크기를 소폭 낮추고 `line-height:1.3`으로 조정해 3줄 구성에서도 673px 인쇄폭 기준 줄바꿈이 자연스럽게 되도록 함(아래 검증 참고).
- 프롬프트 카테고리 컬러는 Day47과 동일하게 A(골드)/B(테라코타)/C(틸)/D(올리브) 4색 매핑 사용.

### 6. 표지 인쇄 폭(673px) 검증
- `scripts/screenshot_element_cloud.js`로 `.cover`를 673×950px 뷰포트에서 캡처해 육안 확인.
- 제목이 "그 직구, 관세청 문자 / 받기 전에 / AI한테 먼저 계산받으세요" 3줄로 자연스럽게 나뉘고, 숫자+단위("11가지 방법", "15개 프롬프트", "3단계 체크리스트")는 모두 각 지표 카드 안에서 줄바꿈 없이 들어감 — 1차 캡처에서 추가 수정 없이 통과.

### 7. PDF 렌더링 및 페이지 여백 검증
- `scripts/render_pdf_cloud.js`로 A4(margin 18mm/16mm) PDF 렌더링 → `그직구_AI한테먼저계산받으세요.pdf` 생성, 총 **14페이지**.
- `pip install pillow numpy`(이번 컨테이너에도 미설치 상태라 즉석 설치) 후 `pdftoppm -r 150`으로 전 페이지 PNG 변환 → `scripts/scan_page_margins.py`로 정량 스캔: 표지(1페이지, 38.6%)와 마지막 에필로그 페이지(14페이지, 54.4%)만 "확인 필요" 플래그, 나머지 12개 본문 페이지는 전부 17.3% 이하(대부분 7~10%대)로 임계값(30%) 이내.
- Read 도구로 표지·목차·프롬프트 그리드(12페이지)·체크리스트(13페이지)·에필로그(14페이지) 페이지를 육안 재확인 — 14장(프롬프트15선) 페이지에서 A~D 4개 카테고리 색상 블록이 2단 그리드로 리듬감 있게 배치되고 카드 밀림 없이 자연스럽게 렌더링됨을 확인. 표지·에필로그의 높은 여백 비율은 Day47~48과 동일하게 의도된 정상 패턴(독립 페이지 관례).

### 8. 썸네일 캡처
- `.cover` 요소를 1000×1000 뷰포트, `deviceScaleFactor:2`로 캡처해 `marketing/thumbnail.png` 생성(실제 저장 크기 1560×1318px, Day47의 1560×1266px과 유사한 비율 — `.cover` 요소 전체 높이를 그대로 캡처하는 방식이라 정사각형이 아니라 책 표지 비율 그대로 저장됨, Day47·48과 동일한 방식).
- 책 표지와 동일한 디자인(여백 넉넉한 세리프 타이틀 + 골드 포인트 라인)을 그대로 사용, 클립아트·네온 스타일 없음.

## 이슈/트러블슈팅
- **detached HEAD 이슈 미재발** — Day42~48에서 5회 연속 보고됐던 패턴이 이번 세션에서는 발생하지 않음. 세션마다 컨테이너 초기화 상태가 다를 수 있으므로 계속 모니터링 필요하나, 이번엔 추가 조치 없이 바로 작업 진행 가능했음.
- `pip install pillow numpy`가 이번 컨테이너에도 사전 설치돼 있지 않아 `scan_page_margins.py` 실행 전 즉석 설치 필요 — Day43·45·47·48에 이미 보고된 것과 동일한 상황으로, 매 세션 컨테이너가 새로 시작되는 한 계속 반복될 것으로 예상됨.
- 표지 제목이 Day47보다 길어서(3줄 구성) 폰트 크기를 `clamp(2.2rem,6.5vw,3.4rem)` → `clamp(2.0rem,6vw,3.1rem)`로 소폭 낮췄으나, 이 조정이 전체 디자인 비율에 영향을 주는지 다른 섹션과 함께 재확인 — 본문 섹션 폰트 크기는 변경하지 않았으므로 표지와 본문 간 비율 불일치 없음을 확인.
- 그 외 특별한 이슈 없이 Day47~48에서 확립된 템플릿·검증 절차를 그대로 재사용해 추가 수정 사이클 없이 1차 작업에서 전체 검증(표지 줄바꿈·페이지 여백·카테고리 색상 리듬)을 통과함.
