1. 왜 지금 AI로 계산 대행인가 / 2. 준비물 3가지 / 3. 평균임금 산정·기준값 정리 / 4. 피보험단위기간 180일 점검 / 5. 이직사유(자발/비자발) 수급자격 판정 / 6. 일일 구직급여액 계산(평균임금 60%+상한·하한) / 7. 소정급여일수 산정(연령·가입기간표) / 8. 총수급액·수급기간 계산(대기기간 포함) / 9. 조기재취업수당 계산 / 10. 수급기간 연장 사유 점검 / 11. 퇴직금·다른 소득과의 관계 점검 / 12. 대행 부업 수익화 / 13. 흔한 실수 5가지 / 14. 대행 시스템 구축 / 15. 프롬프트 15선(A.기준값·자격확인 B.급여액·일수계산 C.조기재취업·연장·중복수급점검 D.대행서비스화, 각 4·4·4·3개) / 16. 실전 체크리스트(오늘/이번주/이번달 3단계)

### 6. PDF 렌더링 및 검증
- `NODE_PATH=/opt/node22/lib/node_modules node scripts/render_pdf_cloud.js`로 PDF 생성(A4, 여백 18mm/16mm) → 16페이지.
- `scripts/screenshot_element_cloud.js`로 `.cover`를 673×950(PDF 실제 인쇄 폭) 뷰포트로 캡처해 육안 확인 — "실업급여(구직급여)", "계산 대행하는 법", "실업급여 프롬프트 15개" 등 숫자+단위 조합이 `nowrap` 처리되어 어색하게 끊기는 곳 없음.
- `pdftoppm -png -r 150`으로 페이지별 PNG 변환 후 `scripts/scan_page_margins.py`로 하단 여백 비율 정량 스캔.
  - **이슈**: `python3 -m pip install --break-system-packages pillow`로 설치했는데도 `ImportError: cannot import name '_imaging'` 발생 — apt로 깔린 시스템 pillow(`/usr/lib/python3/dist-packages`)와 pip 설치본이 같은 경로에서 충돌해 네이티브 확장 모듈이 깨진 상태였음. `python3 -m pip install --break-system-packages --force-reinstall --no-deps --ignore-installed pillow`로 해당 경로를 완전히 덮어써서 해결 (pillow 13.0.0로 갱신). numpy는 처음부터 미설치 상태라 별도로 `python3 -m pip install --break-system-packages numpy`로 설치.
  - 스캔 결과: 1페이지(표지) 38.6%, 16페이지(에필로그) 78.8%만 30% 초과 — 둘 다 설계상 의도된 독립 페이지(표지·책 마지막 페이지)라 정상. 나머지 14개 본문 페이지는 모두 6.9~19.4%로 과도한 빈 공간 없음.
  - Read 툴로 PDF를 브라우저 뷰어로 연 페이지 캡처(`scripts/screenshot_pdf_pages_cloud.js`)를 통해 4페이지(방법1~2 전환부), 13페이지(방법14→프롬프트15선 전환부, 2단 그리드 A카테고리), 16페이지(에필로그)를 직접 육안 확인 — 카테고리별 색상 구분·2단 그리드·배지가 의도대로 렌더링되고, 챕터 전환도 끊김 없이 자연스럽게 이어짐.
- `scripts/screenshot_element_cloud.js`로 `.cover`를 1000×1000(scale 2)로 캡처해 `marketing/thumbnail.png`로 저장(실제 저장 크기 1560×1188px, Day61 썸네일 1560×1250px과 유사한 비율) — 별도 AI 이미지 생성 도구를 쓰지 않고 책 표지 디자인을 그대로 재사용.

## 이슈/트러블슈팅
- `scan_page_margins.py` 실행 시 `ImportError: cannot import name '_imaging' from 'PIL'` — Day61에서 겪었던 `ModuleNotFoundError`와는 다른 증상(이번엔 모듈 자체는 있으나 네이티브 확장이 깨짐). apt의 `python3-pil`과 pip 설치본이 같은 `dist-packages` 경로를 두고 충돌한 것으로 추정. `--force-reinstall --no-deps --ignore-installed` 옵션으로 강제 재설치해 해결. **다음 Day 작업 시 참고**: 이 클라우드 세션은 매번 새 컨테이너로 시작되므로 pillow/numpy가 매번 새로 깨질 수 있다. `ModuleNotFoundError`든 `ImportError: _imaging`이든 증상에 상관없이 `python3 -m pip install --break-system-packages --force-reinstall --no-deps --ignore-installed pillow numpy`를 먼저 시도하는 것이 더 안전하다.
- WebSearch로 소정급여일수 상세표(연령×가입기간)를 직접 확인하지 못해, 고용보험법 제정 이후 널리 알려진 통상 표를 기준값으로 사용 — 리포트 전체에 "실제 적용 값은 고용노동부 고시로 재확인하라"는 고지를 반복 배치해 리스크를 낮춤.
- 반복수급 감액·대기기간 연장 등 국회 계류 중인 개정안은 혼란을 피하기 위해 본문에 포함하지 않음(2026년 10월 기준 미시행 확인) — 추후 실제 시행되면 관련 Day를 갱신하거나 신규 주제로 다룰 수 있음을 염두에 둘 것.
