## 이슈/트러블슈팅
- 세션 시작 시 `git` 작업트리가 detached HEAD 상태였음(Day65·66에서도 반복된 현상) — `git fetch` 후 origin/main과 로컬 HEAD SHA가 동일함을 확인해 데이터 손실 위험은 없었고, `git checkout main && git merge --ff-only origin/main`으로 정상 브랜치 상태로 복구 후 작업. 작업 도중 실수로 `day67-wip`라는 별도 브랜치를 만들었다가, 기존 모든 Day가 main에 직접 커밋해온 관례를 확인하고 즉시 main으로 되돌려 삭제 — 다음 실행 시에도 로드맵 작업은 반드시 `main` 브랜치에서 직접 진행할 것.
- `scripts/render_pdf_cloud.js`/`screenshot_element_cloud.js`가 기본으로 찾는 `/opt/pw-browsers/chromium-xxxx/chrome-linux/chrome` 경로가 이번 컨테이너에서는 `chrome-linux64`로 디렉터리명이 바뀌어 있어 기본 탐색이 실패함 — `/opt/pw-browsers/chromium` 심링크(정확한 실행파일을 가리킴)가 이미 존재하는 것을 확인하고 `PLAYWRIGHT_CHROMIUM_PATH=/opt/pw-browsers/chromium` 환경변수로 넘겨 해결. 공용 스크립트는 건드리지 않음 — 다음 실행에서 동일 에러가 나면 먼저 `ls /opt/pw-browsers/`로 실제 디렉터리명을 확인하고, `/opt/pw-browsers/chromium` 심링크 존재 여부부터 확인할 것.
- pillow/numpy 네이티브 확장 깨짐은 Day63·65 인수인계 메모대로 `--force-reinstall --no-deps --ignore-installed` 옵션을 선제적으로 사용해 한 번에 해결 — 이번에도 별도 디버깅 시간 소요 없었음.
