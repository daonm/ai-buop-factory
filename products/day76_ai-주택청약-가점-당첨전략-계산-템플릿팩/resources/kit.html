계산은 이미 다 만들어져 있습니다. 생년월일과 세대 조건만 넣으면 됩니다. 이 키트는 전자책 방법 1~9(무주택기간·부양가족수·가입기간 점수, 총점 합산, 가점제·추첨제 비율, 대체 전략, 특별공급 매칭, 부부 통장 합산, 제도 확인)를 이미 끝내둔 완성본입니다.

엑셀 계산기 3종·엑셀 가점제추첨제비교+전략체크리스트 1종·워드 템플릿 1종을 같은 톤으로 만들었습니다.

  1. 안내 시트 — "확정 당첨 결과가 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다.
  2. 계산기 시트 — 노란색 칸에 값을 입력하면 올리브색 칸에 결과가 바로 뜹니다.
  3. 이전 계산기 결과 이어받기 — A→B→C 순서로 무주택기간·부양가족수·가입기간 점수를 더해 총점까지 이어집니다.

사용법 — 아래 계산기·체크리스트별 빠른 참고표에서 원하는 것부터 확인하고, 실제 파일을 열어 본인(또는 의뢰인) 조건으로 한 번 테스트해본 뒤 의뢰 접수·고객 리포트 템플릿까지 이어서 진행하세요.

01계산기·체크리스트·템플릿 5종 빠른 참고표

각 파일의 입력값 예시, 결과값, 그리고 어떤 순서로 이어 쓰는지를 정리했습니다. 실제 파일에 그대로 입력해 결과를 재현할 수 있습니다. (예시 — 만 38세·7년 전 혼인, 무주택, 배우자+자녀 2명 부양, 청약통장 가입 15년)

A. 무주택기간 점수계산기 (최대 32점)
파일 — A_무주택기간_점수계산기.xlsx · 생년월일·혼인신고일·과거주택 보유이력을 입력하면 산정 기준일이 자동 확정되고, 신청일을 입력하면 무주택기간과 점수가 자동 계산됩니다
입력값결과값
생년월일 1988-05-14혼인 2019-03-02산정 기준일2018-05-14
과거주택 이력없음무주택기간 점수18점(8년~9년)

이런 상담에게 — "무주택기간은 나이에서 30 빼면 되는 거 아니에요?"라는 질문. 혼인신고일·과거 처분일이 기준일을 바꾼다는 걸 숫자로 바로 보여줄 수 있습니다.

B. 부양가족수 점수계산기 (최대 35점)
파일 — B_부양가족수_점수계산기.xlsx · 세대원 관계·나이·세대등재기간·혼인여부를 입력하면 배우자·직계존속·직계비속별 포함 여부가 자동 판정되고, 부양가족수 점수까지 자동 계산됩니다
입력값결과값
배우자+자녀 2명(미혼)부모 등재 2년포함 판정3명(부모 제외)
판정 기준등재 3년 미만부양가족수 점수20점(3명)

이런 상담에게 — "같이 안 살지만 부모님 생활비 드리는데 부양가족 아닌가요?"라는 질문. 생활비가 아니라 '세대등재 3년'이 기준이라는 걸 바로 보여줄 수 있습니다.

C. 가입기간·총점·당첨가능성 계산기 (최대 17점 + 84점 만점)
파일 — C_가입기간_총점_당첨가능성계산기.xlsx · 통장 최초 가입일을 입력하면 가입기간 점수가 자동 계산되고, A·B 결과를 더하면 총점이 나오며, 관심 단지 과거 당첨 가점과 비교한 당첨 가능성까지 자동 판정됩니다
입력값결과값
최초가입 2011-06-10가입기간 15.4년가입기간 점수17점(만점)
무주택18+부양25+가입17총점 66점당첨 가능성가능성 있음(최저 62점↑)

이런 상담에게 — "저 이 단지 가점 되는지 좀 봐주세요"라는 가장 흔한 요청. 숫자 몇 개만 넣으면 과거 당첨 가점 대비 가능성을 바로 판정해줍니다.

D. 가점제추첨제비교 + 전략체크리스트
파일 — D_가점제추첨제비교_전략체크리스트.xlsx · 주택형별 공급세대수·가점제비율을 입력하면 가점제·추첨제 물량이 자동 계산되고, 총점과 커트라인을 비교한 권장 전략 + 가점 상승 예상일까지 자동 계산되는 '가점제추첨제비교' 시트 + 특별공급·부부전략·제도확인 14개 항목을 준비상태 드롭다운으로 정리한 '전략체크리스트' 시트
입력값결과값
84㎡ 150세대·가점제80%총점76/커트라인72권장 전략가점제 물량 신청
현재 가입기간15.1년다음 상승이미 만점 도달

이런 상담에게 — "지금 가점으로 이 단지 되나요, 추첨제로 넣을까요?"라는 질문. 물량 세대수까지 숫자로 보여주며 전략을 바로 제시할 수 있습니다.

E. 의뢰접수·고객리포트 템플릿
파일 — 의뢰접수_고객리포트_템플릿.docx · 의뢰 접수 질문지(14문항) + 기준값·한도 체크(5개) + 고객용 당첨 전략 리포트 템플릿(9단계) + 서비스 안내·가격 템플릿까지 대괄호만 바꿔서 바로 쓰는 문서
구성내용구성내용
의뢰 접수 질문지14개 문항고객용 리포트9단계 요약 양식
기준값·한도 체크5개 확인 항목서비스 안내·가격표6단계 패키지

이런 상담에게 — 의뢰가 들어오면 바로 접수할 수 있는 양식이 없어 매번 새로 질문을 만들던 상황. 질문지 한 장으로 빠짐없이 받고, 리포트 양식 그대로 전달하면 됩니다.

1단계검증

  • Worksheet 2로 계산기 A·B·C 모두 내(또는 가상의) 조건으로 테스트하기
  • 청약홈 청약가점 계산기와 대조해 배점·인정 한도 최신 기준 확인하기
  • 계산기 시트에 확인한 참고 기준과 확인 날짜 메모 남기기

2단계다듬기

  • 입력 셀(노란색) 옆에 "여기에 값을 입력하세요" 안내 문구 확인하기
  • "참고용 추정치이며 실제 당첨 여부는 경쟁률과 청약홈 최종 발표에 따라 달라질 수 있고 규제·요건 변경사항은 청약홈에서 재확인이 필요하다"는 경계 문구가 각 파일에 붙어있는지 확인하기
  • 파일명·시트명에 오탈자 없는지 최종 점검하기

3단계등록

  • Worksheet 1로 패키지·가격 확정하기
  • 래피드에 상품명 "계산기", "주택청약", "가점", "당첨전략" 단어 포함해 등록하기
  • Day75 전자책과 세트 상품(업셀) 옵션도 함께 등록하기

4단계갱신 관리

  • 가점제·추첨제 비율·특별공급 요건·규제지역 지정 현황은 공고·정책에 따라 자주 바뀌므로, 새 의뢰가 들어올 때마다 최신 기준으로 재확인해 반영하기
  • 기존 상담 고객 연락처/알림 목록 만들어두기(공고·정책 변경·후속 문의 시 재안내용)
  • 기준값 변경 시 참고표만 교체 후 Worksheet 2 검증 다시 거치기
