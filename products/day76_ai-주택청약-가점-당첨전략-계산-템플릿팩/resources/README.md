# AI 주택청약 가점·당첨 전략 계산 대행 — 계산기 + 전략 체크리스트 템플릿팩 사용 가이드

『청약 넣기 전에, AI한테 당첨 가능성부터 물어보세요』(Day75 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~9(무주택기간 점수 계산, 부양가족수 점수 계산, 청약통장 가입기간 점수 계산, 총점 합산·당첨 커트라인 비교, 가점제·추첨제 적용 비율 확인, 가점이 낮을 때 대체 전략, 특별공급 자격 매칭, 부부 통장 합산·중복청약 점검, 매년 바뀌는 제도 기준 확인)을 이미 끝내둔 완성본 엑셀 계산기 3종·엑셀 가점제추첨제비교+전략체크리스트 1종·워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 구성 파일

| 파일 | 내용 |

| `B_부양가족수_점수계산기.xlsx` | 세대원의 관계·나이·세대등재기간·혼인여부를 입력하면 배우자·직계존속·직계비속별 포함 여부가 자동 판정되고, 부양가족수 점수(최대 35점)까지 자동 계산되는 계산기 |
| `C_가입기간_총점_당첨가능성계산기.xlsx` | 청약통장 최초 가입일(+미성년 가입이력)을 입력하면 가입기간 점수(최대 17점)가 자동 계산되고, A·B 결과를 더하면 총점(84점 만점)이 나오며, 관심 단지의 과거 당첨 최저·평균 가점과 비교한 당첨 가능성까지 자동 판정 |

| `의뢰접수_고객리포트_템플릿.docx` | 의뢰 접수 질문지(14문항) + 기준값·한도 체크(5개) + 고객용 당첨 전략 리포트 템플릿(9단계) + 서비스 안내·가격 템플릿까지 대괄호만 바꿔서 바로 쓰는 문서 |

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 당첨 결과가 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 날짜·숫자·여부를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`A_무주택기간_점수계산기.xlsx`는 생년월일·혼인신고일·과거 주택 처분 이력으로 산정 기준일을 확정한 뒤 신청일까지의 기간을 점수로 환산하고, `B_부양가족수_점수계산기.xlsx`는 세대원별 관계·나이·세대등재기간으로 포함 여부를 판정해 부양가족수 점수를 계산하며, `C_가입기간_총점_당첨가능성계산기.xlsx`는 가입기간 점수를 계산한 뒤 A·B 점수를 입력받아 총점을 합산하고 관심 단지 통계와 비교하고, `D_가점제추첨제비교_전략체크리스트.xlsx`는 총점·커트라인을 입력받아 가점제·추첨제 전략과 가점 상승 시점을 계산하는 시트, 그리고 특별공급·부부전략·제도확인 체크리스트 시트로 구성되고, `의뢰접수_고객리포트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 쓰는 문서입니다.

## 계산기·체크리스트·템플릿을 잇는 순서

1. **A_무주택기간_점수계산기**로 생년월일·혼인신고일·과거 주택 이력을 입력해 무주택기간 점수를 확정합니다.
2. **B_부양가족수_점수계산기**로 세대원 명단을 입력해 부양가족수 점수를 확정합니다.
3. **C_가입기간_총점_당첨가능성계산기**로 넘어가 청약통장 가입일을 입력해 가입기간 점수를 구하고, A·B 점수를 옮겨 입력해 총점과 당첨 가능성을 확인합니다.
4. **D_가점제추첨제비교_전략체크리스트**로 관심 단지의 주택형별 가점제·추첨제 물량을 비교하고, 가점이 오르는 다음 시점과 특별공급·부부 전략까지 점검합니다.
5. **의뢰접수_고객리포트_템플릿**으로 의뢰를 접수하고, 계산 결과를 고객용 리포트로 정리해 전달합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·체크리스트·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 생년월일·세대 조건·통장 가입일을 넣어보고, 청약홈(applyhome.co.kr)의 청약가점 계산기·청약 통계 메뉴와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "주택청약", "가점", "당첨전략"이라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 당첨 결과가 아니라 **참고용 추정 계산 도구**입니다. 무주택기간·부양가족수·가입기간 배점표의 큰 틀은 「주택공급에 관한 규칙」에 따라 오랫동안 유지돼 왔지만, 가점제·추첨제 적용 비율, 특별공급 유형별 요건, 규제지역(투기과열지구·조정대상지역) 지정 현황, 미성년자 가입기간 인정 한도는 공고와 정책에 따라 수시로 바뀌므로, 이 계산기를 만든 시점 기준의 예시값일 뿐이며 실제 청약 신청 전에는 반드시 청약홈(applyhome.co.kr)의 해당 단지 입주자모집공고와 청약가점 계산기로 최신 기준을 재확인해야 합니다. 이 부업은 분양권 매매 중개나 부동산 중개업, 청약 당첨을 보장하는 영업이 아니라 공개된 배점 규칙과 입력된 조건을 조합한 계산 정리 대행이라는 점을 상담 시작 전 항상 명확히 안내해, 당첨을 보장하는 서비스로 오인되지 않도록 서비스 범위를 벗어나지 않게 운영하세요.
