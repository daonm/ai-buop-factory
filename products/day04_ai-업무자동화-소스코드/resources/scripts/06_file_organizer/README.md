# 06. 파일 · 폴더 정리 자동화 스크립트

전자책 『야근 없는 사무실』 **방법 9 — 파일 · 폴더 정리 자동화**에 대응하는 실제 동작 코드입니다.
외부 라이브러리 없이 파이썬 표준 기능만으로 동작합니다 (설치 필요 없음).

## 무엇을 하나요
- 폴더 안의 파일들을 이미지/문서/스프레드시트/압축파일/동영상/음악/기타 확장자 그룹별 하위 폴더로 **이동**
- `--year-first`를 붙이면 수정연도 폴더 → 확장자 폴더 순서로 2단 분류
- **삭제는 절대 하지 않습니다.** 이동 중 같은 이름 파일이 있으면 덮어쓰지 않고 `_1`, `_2`처럼 번호를 붙여 보존
- `--preview`로 먼저 계획만 보고, 결과가 맞을 때만 실제로 실행하는 걸 권장합니다

## 사용법
```bash
python organize_files.py ~/Downloads --preview   # 1) 먼저 미리보기
python organize_files.py ~/Downloads              # 2) 결과가 맞으면 실제 실행
python organize_files.py ~/Downloads --year-first  # 연도별 → 확장자별 2단 분류
```

## 분류 그룹 커스터마이징
파일 상단의 `EXT_GROUPS` 딕셔너리에서 그룹과 확장자를 자유롭게 바꿀 수 있습니다. 클로드에게 이렇게 요청해도 됩니다.

> 이 스크립트의 EXT_GROUPS에 "코드파일" 그룹을 추가하고 .py, .js, .html 확장자를 넣어줘.

## 조심할 점 (전자책 방법 9 참고)
- 처음 실행할 때는 **반드시 `--preview`로 먼저 확인**하세요.
- 자동 삭제 기능은 이 스크립트에 없습니다. "이동"만 하도록 설계된 건 의도된 것이며, 삭제가 필요하면 몇 주간 이동 결과를 신뢰한 뒤 직접 처리하는 걸 권장합니다.
