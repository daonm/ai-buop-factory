# 01. 구글 시트 주간 보고서 자동 이메일 발송 (Google Apps Script)

전자책 『야근 없는 사무실』 **방법 2 — 구글 시트 + Apps Script로 보고서 자동화**에 대응하는 실제 동작 코드입니다.

## 설치 방법
1. 보고서로 만들 스프레드시트를 연다.
2. 상단 메뉴 `확장 프로그램 → Apps Script`를 클릭한다.
3. 기본 생성된 코드를 지우고 `Code.gs` 전체를 붙여넣는다.
4. 파일 상단의 `CONFIG` 값을 내 시트 구조에 맞게 수정한다 (시트 이름, 날짜/금액 컬럼, 받는 이메일).
5. 함수 목록에서 `testRunNow`를 선택해 한 번 수동 실행 → 처음엔 구글이 "권한 승인"을 요구합니다. 본인 계정이 맞는지 확인 후 승인하세요.
6. 왼쪽 메뉴 시계 아이콘(트리거) → 트리거 추가 → `sendWeeklyReport`, 시간 기반 트리거, "주 단위 타이머" → "월요일" → "오전 9시~10시"로 설정.

## 조심할 점 (전자책 방법 2 참고)
- 이메일 발송은 개인 구글 계정 기준 **하루 약 100통** 제한이 있습니다. 대량 발송이 필요하면 노코드 툴(방법 4) 조합을 고려하세요.
- `DATE_COL`에는 실제 날짜(Date) 형식이 들어있어야 최근 7일 필터가 정상 동작합니다.

## 에러가 날 때
Apps Script 편집기 하단 "실행 로그"에 뜨는 에러 메시지를 그대로 복사해서 클로드에게 붙여넣으세요.

> 다음 에러 메시지가 떴어: [에러 내용]. 위 Code.gs의 어느 부분이 문제인지 원인과 수정 코드를 알려줘.

## 커스터마이징 아이디어
- 여러 시트(지점별)를 합산하고 싶다면 `SHEET_NAME`을 배열로 바꿔 반복 처리하도록 요청하세요.
- 이메일 대신 슬랙으로 보내고 싶다면 `05_slack_notifier`와 조합해달라고 클로드에게 요청하세요.
