# 07. GitHub Actions로 스크립트 정기 실행 (스케줄링 · 크론)

전자책 『야근 없는 사무실』 **방법 10 — 정기 실행 자동화(스케줄링 · 크론)**에 대응하는 실제 동작 코드입니다.
컴퓨터를 켜놓지 않아도 GitHub 서버에서 정해진 시간에 대신 실행해줍니다 (무료 저장소도 매달 일정량 무료 제공).

## 설치 방법
1. 스크립트를 관리하는(또는 새로 만든) GitHub 저장소를 준비합니다.
2. `scheduled_run.yml`을 저장소의 `.github/workflows/scheduled_run.yml` 경로로 저장합니다.
3. 파일 안의 cron 시간, 설치할 requirements 경로, 실행할 스크립트 경로를 내 상황에 맞게 수정합니다.
4. `main` 브랜치에 푸시하면 자동으로 등록됩니다.
5. 저장소 상단 **Actions** 탭에서 실행 로그(성공/실패 여부)를 확인할 수 있습니다.

## cron 시간 계산 주의
GitHub Actions의 cron은 **UTC 기준**입니다. 한국시간(KST)은 UTC+9이므로, 한국시간 오전 9시에 실행하려면 `cron: "0 0 * * *"`(UTC 0시)로 설정해야 합니다.

| 원하는 한국시간 | cron (UTC) |
|---|---|
| 매일 오전 9시 | `0 0 * * *` |
| 매일 오후 6시 | `0 9 * * *` |
| 매주 월요일 오전 9시 | `0 0 * * 1` |

## 조심할 점 (전자책 방법 10 참고)
- **이미 손으로 여러 번 실행해서 검증이 끝난 스크립트만** 여기 등록하세요. 검증 안 된 스크립트를 자동 반복시키면 실수도 그만큼 반복됩니다.
- 처음 1~2주는 Actions 탭의 실행 로그를 꼭 직접 확인하는 습관을 들이세요.
- 결과 파일을 저장소에 커밋하는 마지막 단계는 선택사항입니다. 필요 없으면 해당 step을 지우세요.

## 다른 스크립트로 바꾸기
`Script 실행` 단계의 명령어만 이 패키지의 다른 스크립트(01, 06 등)로 바꾸면 됩니다. 클로드에게 이렇게 요청해도 됩니다.
