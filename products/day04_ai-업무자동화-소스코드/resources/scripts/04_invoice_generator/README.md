# 04. 견적서 · 인보이스 자동 생성 스크립트

전자책 『야근 없는 사무실』 **방법 6 — 견적서 · 인보이스 자동 생성**에 대응하는 실제 동작 코드입니다.
외부 라이브러리 없이 파이썬 표준 기능만으로 동작합니다 (설치 필요 없음).

## 무엇을 하나요
- `고객명,품목,수량,단가` 컬럼을 가진 CSV 하나로 **고객별 HTML 인보이스**를 자동 생성
- 같은 고객의 여러 품목 행은 자동으로 한 인보이스에 합산
- 합계 금액까지 자동 계산
- 생성된 HTML을 브라우저에서 열어 **인쇄(Ctrl+P) → PDF로 저장**하면 바로 발송 가능

## 사용법
```bash
python generate_invoice.py sample_clients.csv --company "내 회사명" --out invoices/
```
`invoices/` 폴더 안에 고객별로 `{고객명}_invoice.html` 파일이 생성됩니다.

## 내 데이터로 확장하기
- 매달 갱신되는 고객 CSV만 바꿔서 재실행하면 됩니다.
- 발행일을 특정 날짜로 고정하고 싶으면 코드의 `date.today()` 부분을 원하는 날짜로 바꾸세요.
- 결제 기한 리마인드 자동 발송까지 연결하고 싶다면(전자책 방법 6 "확장 아이디어"), 클로드에게 이렇게 요청하세요.

> 이 스크립트로 만든 인보이스에 결제 기한을 추가하고, 기한이 지나면 이메일로 리마인드를 보내는 기능을 추가해줘.

## PDF로 자동 저장까지 하고 싶다면
브라우저 인쇄 대신 자동으로 PDF까지 뽑고 싶다면, 이 저장소의 `scripts/render_pdf_cloud.js`처럼 Playwright를 사용하는 방식을 클로드에게 요청해 붙일 수 있습니다 (구조가 똑같이 "HTML → PDF 렌더링"이기 때문입니다).
