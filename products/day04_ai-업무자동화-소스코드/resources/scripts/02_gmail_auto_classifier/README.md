# 02. Gmail 문의 메일 자동 분류 + 매일 요약 (Google Apps Script)

전자책 『야근 없는 사무실』 **방법 3 — 이메일 자동 분류 · 요약**에 대응하는 실제 동작 코드입니다.

## 무엇을 하나요
- 받은 편지함의 안 읽은 메일을 제목/본문 키워드로 자동 분류해서 라벨을 붙임 (문의/주문/스팸의심 등)
- 규칙에 안 걸리는 메일은 삭제하거나 숨기지 않고 **"확인필요" 라벨**로 모아서 사람이 직접 봄 (전자책의 "확실한 것만 자동, 애매한 건 사람이" 원칙)
- 매일 아침 라벨별 건수를 요약해서 메일로 발송

## 설치 방법
1. https://script.google.com 에서 새 프로젝트 생성
2. `Code.gs` 전체를 붙여넣기
3. 상단 `RULES`, `SUMMARY_RECIPIENT`를 내 상황에 맞게 수정
4. `classifyInbox` 함수를 한 번 수동 실행 → Gmail 접근 권한 승인
5. 트리거(시계 아이콘) → `classifyInbox`를 분 단위 타이머(10~15분)로 등록
6. 매일 요약이 필요하면 `sendDailySummary`도 별도 트리거(매일, 오전 8~9시)로 등록

## 분류 규칙 수정하기
`RULES` 배열의 `keywords`를 실제 내 문의 메일 패턴에 맞게 바꾸세요. 클로드에게 이렇게 요청하면 됩니다.

> 최근 받은 메일 제목이야: [목록]. 이 목록을 참고해서 RULES 배열의 키워드를 다시 짜줘.

## 조심할 점
- 완벽한 분류를 처음부터 노리지 마세요. `FALLBACK_LABEL`("확인필요")로 빠지는 메일이 많다면 그 메일들을 보고 키워드를 점진적으로 추가하는 방식이 실패율이 훨씬 낮습니다.
- `newer_than:1d`로 최근 메일만 검사하므로, 이미 지난 오래된 메일에는 소급 적용되지 않습니다. 과거 메일까지 정리하려면 검색 조건을 클로드에게 요청해 바꾸세요.
