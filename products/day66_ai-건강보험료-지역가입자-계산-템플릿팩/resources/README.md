# AI 건강보험료(지역가입자) 계산 대행 — 계산기 + 전환대응 체크리스트 템플릿팩 사용 가이드

『건강보험료 고지서 받기 전에, AI한테 먼저 물어보세요』(Day65 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~12(피부양자 자격 점검, 소득보험료·재산보험료·장기요양보험료 계산, 상한액 적용, 고지 반영 지연 점검, 전환 시나리오 비교, 임의계속가입 활용, 보험료 절감 전략)를 이미 끝내둔 완성본 엑셀 계산기 3종·엑셀 전환대응 체크리스트 1종·워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 보험료가 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`건강보험_전환대응_체크리스트.xlsx`는 D-day계산기 시트(고지서 수령일 입력→이의신청 기한·D-day 자동 계산)와 전환대응체크리스트 시트(전환 계기별 점검 항목 드롭다운)로 구성되고, `의뢰접수_고객리포트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 쓰는 문서입니다.

## 계산기·체크리스트·템플릿을 잇는 순서

1. **피부양자_자격판정_계산기**로 소득·재산 기준부터 확인해, 피부양자 유지가 가능한지 지역가입자 전환 대상인지부터 판정합니다.
2. 전환 대상이라면 **지역가입자_건강보험료_계산기**로 넘어가 소득보험료·재산보험료·장기요양보험료를 더한 월 총 납부액까지 계산합니다.
3. 전환 계기가 퇴사(실업)라면 **임의계속가입_유불리_비교_계산기**로 자격·유불리·신청기한을 추가로 비교합니다.
4. **건강보험_전환대응_체크리스트**로 이의신청 D-day와 전환 계기별 체크포인트를 점검합니다.
5. **의뢰접수_고객리포트_템플릿**으로 의뢰를 접수하고, 계산 결과를 고객용 리포트로 정리해 전달합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·체크리스트·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 소득·재산·재직 이력을 넣어보고, 국민건강보험공단(nhis.or.kr)의 '지역보험료 모의계산'·'자격득실확인서' 결과와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "건강보험료", "지역가입자", "전환대응"이라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 보험료가 아니라 **참고용 추정 계산 도구**입니다. 피부양자 소득·재산 기준, 보험료율, 점수당 금액, 상한액은 매년(또는 수시) 공단 고시로 바뀌므로, 실제 적용 전 반드시 국민건강보험공단(nhis.or.kr)·1577-1000으로 최신 값을 재확인하세요. 피부양자 자격의 최종 심사, 보험료의 최종 고지, 이의신청의 심사는 공단의 고유 권한이며 이 계산기는 추정 판정까지만 다룹니다. 임의계속가입은 퇴직일 이전 18개월 중 직장가입자 보험료 납부 기간이 통산 1년 이상이어야 신청할 수 있고, 신청기한은 퇴직일이 아니라 지역가입자로서 최초로 고지받은 보험료 납부기한으로부터 2개월 이내라는 점을 반드시 안내해야 합니다. 이 부업은 공단의 고유 업무(피부양자 자격 최종 심사, 보험료 최종 고지, 이의신청 심사, 실제 신청서 대리 작성)를 대신하는 것이 아니라 사전 계산과 안내라는 점을 상담 시작 전 항상 명확히 안내해 오해를 예방해야 합니다.
