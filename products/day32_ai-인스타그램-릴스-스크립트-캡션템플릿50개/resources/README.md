# AI 인스타그램 릴스 — 스크립트 + 캡션 템플릿 50개 사용 가이드

『계정은 있는데, 릴스가 없습니다』(Day31 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다.

## 구성 파일

| 파일 | 내용 |
|---|---|
| `kit.html` | 업종 5개 카테고리 빠른 참고표 + 템플릿 50종 중 대표 샘플 + 커스터마이징 프롬프트 10선 + 사용법 체크리스트를 한눈에 보기 좋게 디자인한 버전 (브라우저로 열거나 PDF로 인쇄) |
| `릴스_스크립트_캡션_템플릿_50개_다_있습니다.pdf` | `kit.html`을 인쇄한 PDF 버전 (오프라인·인쇄용) |
| `릴스_스크립트_캡션_템플릿_50종.md` | 카페·음식점 / 옷가게·쇼핑몰 / 학원·교육 / 부동산·인테리어 / 병원·뷰티샵 5개 업종, 업종당 10개씩 총 50개의 훅-본론-CTA 대본 + 캡션 + 해시태그 3단 세트. 대괄호만 바꿔서 그대로 촬영·게시하는 용도 |
| `업종별_커스터마이징_프롬프트_10선.md` | 50개 템플릿을 내 실제 클라이언트·계정 정보에 맞게 다듬는 프롬프트 10개. Day31 전자책 프롬프트 16개와 겹치지 않는 신규 구성 |

## 4단계 사용법

1. **내 업종 찾기** — `릴스_스크립트_캡션_템플릿_50종.md`에서 5개 업종(카페·음식점 / 옷가게·쇼핑몰 / 학원·교육 / 부동산·인테리어 / 병원·뷰티샵) 중 내 업종을 찾습니다.
2. **콘텐츠 유형 고르기** — 해당 업종 안의 10개 콘텐츠 유형(반박형·정보형·질문형·비포애프터형·비하인드형·리스트형·Q&A형·챌린지형·스토리텔링형·시즌형) 중 이번 주에 쓸 것을 고릅니다. 순서대로 써도 되고, Day31 전자책 방법 9(성과 분석)로 반응 좋았던 유형부터 써도 됩니다.
3. **정보 채우기** — 대괄호 `[ ]` 안의 가게명·메뉴명·상품명·기간·지역 정보를 실제 정보로 바꿉니다. 클라이언트 정보가 많거나 톤을 더 다듬고 싶다면 `업종별_커스터마이징_프롬프트_10선.md`의 프롬프트를 씁니다.
4. **그대로 제작·게시** — 훅(3초)-본론(20초)-CTA(7초) 순서 그대로 촬영/편집하고, 캡션과 해시태그는 복사해서 그대로 붙여넣습니다.

매주 3개씩 순환하면 업종 하나당 10주 분량의 콘텐츠 캘린더가 자동으로 완성됩니다. 이 키트는 "무엇을 찍고 뭐라고 쓸지"를 담당합니다 — "어떤 도구로 어떻게 편집할지"는 Day31 전자책 방법 5~6과 함께 보세요.
