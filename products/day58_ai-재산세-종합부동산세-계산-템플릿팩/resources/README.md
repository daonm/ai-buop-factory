# AI 재산세·종합부동산세 계산 대행 — 계산기 + 절세 체크리스트 템플릿팩 사용 가이드

『고지서 받기 전에, AI한테 재산세부터 물어보세요』(Day57 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~9(재산세 과세표준·세율·1세대1주택 특례·도시지역분·지방교육세·세부담상한, 종부세 과세대상·과세표준·세율·고령자·장기보유 세액공제·이중과세조정)를 이미 끝내둔 완성본 엑셀 계산기 3종·엑셀 절세 체크리스트 1종·워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 고지액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자(또는 목록에서 선택)를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`재산세_종부세_절세체크리스트.xlsx`는 주요일정계산기 시트(입력→결과 자동 계산)와 절세체크리스트 시트(항목별 완료여부 드롭다운)로 구성되고, `의뢰접수_고객리포트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 쓰는 문서입니다.

## 계산기·체크리스트·템플릿을 잇는 순서

1. **재산세_종부세_절세체크리스트**의 주요일정계산기로 다음 납부기한 D-day부터 확인하고, 절세체크리스트로 놓치기 쉬운 절세 포인트를 점검합니다.
2. **재산세_계산기**로 보유 주택의 재산세를 계산하고, 세대 전체 공시가격 합계가 공제금액을 넘을 것 같으면 **종합부동산세_계산기**로 넘어갑니다.
3. "공동명의로 바꾸면 세금이 줄어들까" 고민이 있다면 **단독명의_vs_공동명의_절세비교_계산기**로 두 시나리오의 세금을 비교합니다.
4. **의뢰접수_고객리포트_템플릿**으로 의뢰를 접수하고, 계산 결과를 고객용 리포트로 정리해 전달합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·체크리스트·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 공시가격·보유 조건을 넣어보고, 위택스(wetax.go.kr)·국세청 홈택스(hometax.go.kr)의 모의계산과 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "재산세", "종합부동산세"라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 고지액이 아니라 **참고용 추정 계산 도구**입니다. 재산세·종합부동산세의 공정시장가액비율·세율표·공제금액·세부담상한 비율은 세제개편 논의(2026년 종부세 공제금액 확대·세율 조정 등 진행 중)에 따라 바뀔 수 있으므로, 실제 적용 전 반드시 위택스(wetax.go.kr), 국세청 홈택스(hometax.go.kr)의 모의계산이나 세무사 확인으로 최신 값을 재확인하세요. 1세대1주택 특례 요건, 도시지역분 부과 여부(지자체별 상이), 공동명의 전환 시 취득세·증여세 등 다른 세목에 미치는 영향처럼 계산기에 단순화되어 있거나 반영되지 않은 예외 규정은 해당 사례가 있을 때 반드시 수동으로 재확인해야 합니다. 이 부업은 세무사 업무(세무 신고 대리, 이의신청 대행 등)를 대신하는 것이 아니라 사전 계산과 안내라는 점을 상담 시작 전 항상 명확히 안내해 오해를 예방해야 합니다.
