계산기는 다 만들어놨습니다. 이제 물건 정보만 넣으면 됩니다. 이 키트는 전자책 방법 1~8(감가상각 공식·시세 밴드·등록가 산정·판매 카피·플랫폼별 최적화·가격 재조정)을 이미 끝낸 완성본입니다.

엑셀 파일 5개 모두 같은 구조로 만들었습니다.

  1. 안내 시트 — "감정평가·판매 보장이 아니라 참고용 리서치·계산 도구"라는 경계를 첫 화면에 명시합니다.
  2. 계산기·템플릿 시트 — 노란색 칸에 값을 입력하면 올리브색 칸에 결과가 바로 뜹니다.
  3. 참고표(해당 파일만) — 카테고리별 감가율처럼 반복해서 쓰는 기준을 계산기 시트 상단에 함께 정리해뒀습니다.

사용법 — 아래 계산기별 참고표에서 원하는 것부터 확인하고, 실제 파일을 열어 본인(또는 의뢰인) 물건 조건으로 한 번 테스트해본 뒤 판매카피 템플릿까지 이어서 진행하세요.

01계산기·템플릿 5종 빠른 참고표

각 파일의 입력값 예시, 결과값, 그리고 어떤 순서로 이어 쓰는지를 정리했습니다. 실제 파일에 그대로 입력해 결과를 재현할 수 있습니다.

A. 카테고리별 감가율·적정가 계산기
파일 — 카테고리별_감가율_적정가_계산기.xlsx · 카테고리별 감가율 참고표에서 확인한 감가율과 기준가·상태감점·구성품감점·희소성가점을 입력하면 최종 적정가와 네고 여지 포함 등록가를 계산합니다
입력값결과값
노트북 150만원 / 감가율 35%상태감점 8% / 구성품감점 3%최종 적정가약 866,700원
위 적정가 기준네고 여지 +7.5%네고 포함 등록가약 931,700원

이런 상담에게 — "얼마에 올려야 할지" 감이 전혀 없는 첫 중고거래 의뢰인. 감가율·상태·구성품을 숫자로 쪼개서 보여주면 "왜 이 가격인지" 설득력이 생깁니다.

B. 시세밴드·등록가 계산기
파일 — 시세밴드_등록가_계산기.xlsx · 실제 검색한 거래완료가 최대 10건을 입력하면 최저·최고·평균·중간값과 이상치 여부를 계산하고, 목표 실수령가 기준 3가지 등록가 시나리오를 제안합니다
입력값결과값
거래완료가 7건 입력47~61만원대시세 밴드(평균)약 517,900원
목표 실수령가 50만원적정가 우선(+7.5%)등록가 / 마지노선537,500원 / 475,000원

이런 상담에게 — "판매중 호가만 보고 시세를 착각하는" 의뢰인. 반드시 거래완료가 기준으로 밴드를 잡아야 실제 팔릴 가격에 가까워진다는 걸 보여줄 수 있습니다.

C. 플랫폼별 판매카피 템플릿
파일 — 플랫폼별_판매카피_템플릿.xlsx · 물건 정보를 한 번 입력하면 당근마켓·번개장터·중고나라 시트에 제목 후보가 자동으로 채워지고, 5단 구조로 판매글을 옮겨 적는 템플릿입니다
시트강조 포인트제목 자동 미리보기
당근마켓동네 인증·직거래"갤럭시북4 프로 팝니다 (상태 상)"
번개장터번개페이·검수·택배"갤럭시북4 프로 판매 (번개페이 안전결제 가능…)"

이런 상담에게 — 같은 판매글을 세 플랫폼에 그대로 복사해서 반응이 떨어진 의뢰인. 플랫폼마다 다른 강조 포인트를 구조적으로 나눠주면 클릭률이 달라집니다.

D. 가격재조정·끌올 판단표
파일 — 가격재조정_끌올_판단표.xlsx · 경과일수·조회수·채팅·찜 수를 입력하면 가격 저항·관심 대비 전환 부족·노출 부족 신호를 판정하고, 현재 등록가 기준 단계적 인하가를 계산합니다
입력값결과값
경과 10일 / 조회 45채팅 0건 / 찜 12개신호 판정가격 저항 의심 + 전환 부족
현재 등록가 55만원1차 인하(−7.5%)1차 인하가 / 마지노선508,750원 / 467,500원

이런 상담에게 — 안 팔리는 매물을 감으로 방치하거나 감으로 확 내리는 의뢰인. 신호를 근거로 "왜 지금 내려야 하는지"를 숫자로 설명할 수 있습니다.

04판매 준비 체크리스트

브리프부터 등록까지, 순서대로 체크하며 진행하세요.

1단계검증

  • Worksheet 2로 계산기 A·B·D 모두 내(또는 지인의) 실제 물건 조건으로 테스트하기
  • 당근마켓 가격 렌즈·실제 거래완료가와 대조해 오차 확인하기
  • 계산기 시트에 확인한 감가율·시세와 확인 날짜 메모 남기기

2단계다듬기

  • 입력 셀(노란색) 옆에 "여기에 값을 입력하세요" 안내 문구 확인하기
  • "참고용 리서치·계산 도구이며 판매를 보장하지 않는다"는 경계 문구가 각 파일에 붙어있는지 확인하기
  • 파일명·시트명에 오탈자 없는지 최종 점검하기

3단계등록

  • Worksheet 1로 패키지·가격 확정하기
  • 래피드에 상품명 "계산기/중고거래/적정가" 단어 포함해 등록하기
  • Day41 전자책과 세트 상품(업셀) 옵션도 함께 등록하기

4단계갱신 관리

  • 카테고리별 감가율 감각·플랫폼 수수료 정책 분기마다 확인해 캘린더에 표시해두기
  • 기존 상담 고객 연락처/알림 목록 만들어두기(다음 물건 의뢰 안내용)
  • 플랫폼 정책 변경 시 계산기 C의 강조 포인트 문구만 교체 후 Worksheet 2 검증 다시 거치기
