# AI 중고거래 적정가 계산 · 판매카피 대행 — 계산기 + 카피 템플릿팩 사용 가이드

『그 가격, AI한테 먼저 물어보고 올리세요』(Day41 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~8(감가상각 공식·시세 밴드·등록가 산정·판매 카피·플랫폼별 최적화·가격 재조정)을 이미 끝내둔 완성본 엑셀 계산기·템플릿 5종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 엑셀 파일 공통 구조

계산기·판단표 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "감정평가·판매 보장이 아니라 참고용 리서치·계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자(또는 텍스트)를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`플랫폼별_판매카피_템플릿.xlsx`는 계산 파일이 아니라 AI가 써준 판매글을 옮겨 적는 빈 양식(제목만 자동 미리보기)입니다. `의뢰접수_상담진행_체크리스트.xlsx`도 계산 파일이 아니라 접수·진행 관리용 표입니다. 완료 열(노란 칸)에 O를 적어가며 사용하세요.

## 계산기·템플릿을 잇는 순서

1. **카테고리별 감가율·적정가 계산기**로 물건의 1차 참고 적정가부터 계산합니다.
2. **시세밴드·등록가 계산기**로 실제 거래완료가를 리서치해 1차 계산값을 검증하고, 최종 등록가 시나리오를 확정합니다.
3. **플랫폼별 판매카피 템플릿**으로 확정된 가격과 물건 정보를 바탕으로 당근마켓·번개장터·중고나라용 판매글을 완성합니다.
4. 게시 후 반응이 없다면 **가격재조정·끌올 판단표**로 인하 시점과 폭을 신호 기반으로 판단합니다.
5. 전체 과정은 **의뢰접수·상담진행 체크리스트**로 순서대로 진행하며 빠뜨리는 단계가 없도록 관리합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 물건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 물건 조건을 넣어보고, 중고거래 앱에서 직접 검색한 거래완료가와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "중고거래", "적정가"라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 판매를 보장하는 감정평가가 아니라 **참고용 리서치·계산 도구**입니다. 카테고리별 감가율과 플랫폼 관행(수수료·검수 서비스 조건)은 시장 상황에 따라 자주 바뀌므로, 실제 상담이나 판매에 사용하기 전 반드시 최신 정보로 재확인하세요. 최종 등록가와 판매 여부는 항상 고객 본인의 몫으로 남겨두어야 합니다.
