『구독자가 없어도, 유튜브 채널 기획은 대신 해드릴 수 있습니다』를 읽은 다음날 바로 펼치는 실행용 워크북입니다.

계산기는 다 만들어놨습니다. 이제 니치와 조건만 넣으면 됩니다. 이 키트는 전자책 방법 2·5·6·7·8(니치별 수익성 진단·채널 기획서·영상 아이디어·수익 다각화·YPP 로드맵)을 이미 끝낸 완성본입니다.

엑셀 파일 5개 모두 같은 구조로 만들었습니다.

  1. 안내 시트 — "조회수·수익을 보장하지 않는 참고용 진단 도구"라는 경계를 첫 화면에 명시합니다.
  2. 기준값(해당 파일만) — YPP 가입 조건처럼 자주 바뀌는 기준을 계산기 시트 안에 따로 모아뒀습니다.
  3. 계산기·템플릿 시트 — 노란색 칸에 값을 입력하면 올리브색 칸에 결과가 바로 뜹니다.

사용법 — 아래 계산기별 참고표에서 원하는 것부터 확인하고, 실제 파일을 열어 본인(또는 상담 대상) 조건으로 한 번 테스트해본 뒤 채널 기획 템플릿까지 이어서 진행하세요.

01계산기·템플릿 5종 빠른 참고표

각 파일의 입력값 예시, 결과값, 그리고 어떤 순서로 이어 쓰는지를 정리했습니다. 실제 파일에 그대로 입력해 결과를 재현할 수 있습니다.

A. 니치별 RPM·수익성 진단 계산기
파일 — 니치별_RPM_수익성_계산기.xlsx · 니치별 RPM 하단/상단을 입력하면 월 조회수 1만/10만/100만 구간별 예상 광고수익과 니치 간 배율을 계산합니다
입력값결과값
재테크 RPM 3,000~8,000원월 10만 조회예상 광고수익300,000~800,000원
브이로그 RPM 800~1,500원같은 10만 조회재테크 대비 배율약 5.3배

이런 상담에게 — "무슨 주제로 시작해야 돈이 될지" 니치부터 못 정한 지망생. 같은 조회수라도 니치에 따라 광고 수익이 몇 배씩 갈린다는 걸 숫자로 먼저 보여주면 방향이 명확해집니다.

B. YPP 달성 로드맵 계산기
파일 — YPP_달성_로드맵_계산기.xlsx · 주당 업로드·평균 조회수·시청 지속시간·구독 전환율을 입력하면 펜 펀딩·전체 광고수익 조건 도달까지 예상 개월수를 역산합니다
입력값결과값
주 2회 업로드 / 평균 3천회시청 4분 / 전환 0.5%구독자 500명 도달약 3.9개월
쇼츠 주 5회 / 평균 8천회쇼츠 경로쇼츠 300만 회 도달약 17.4개월

이런 상담에게 — "언제부터 수익화가 되는지" 막막한 신규 크리에이터. 롱폼·쇼츠 두 경로를 나란히 계산해 더 빠른 쪽을 전략으로 제안할 수 있습니다.

C. 협찬단가·제휴수익 계산기
파일 — 협찬단가_제휴수익_계산기.xlsx · 구독자·평균 조회수·참여율·기준 단가를 입력하면 영상 유형별(언급형·전용리뷰형·콜라보형) 협찬 단가와 월 제휴마케팅 예상 수익을 계산합니다
입력값결과값
구독자 5천 / 평균 4천회참여율 4.0%전용리뷰형 협찬 단가약 110,400원
월 4편 관련 영상클릭 3% / 전환 5%월 제휴마케팅 수익약 72,000원

이런 상담에게 — 협찬 제안을 처음 받아 단가를 어떻게 불러야 할지 모르는 크리에이터. 조회수만이 아니라 참여율까지 반영한 근거 있는 단가표를 함께 보여주면 협상에서 밀리지 않습니다.

D. 채널기획서·4주캘린더·영상아이디어 템플릿
파일 — 채널기획서_4주캘린더_영상아이디어30개.xlsx · 채널명·시리즈·업로드 캘린더·영상 아이디어 30개를 빈 칸에 채우면 난이도 분포까지 자동 집계되는 완성형 기획 문서
시트구성자동 집계값
채널기획서채널명 후보 3 / 페르소나 3 / 시리즈 4—수기 확정
영상아이디어30개번호·시리즈·제목후보·썸네일문구난이도 분포COUNTIF 자동 갱신

이런 상담에게 — 기획서는 받았는데 "그래서 뭘 먼저 찍어야 하는지" 막막한 신규 크리에이터. 30개 아이디어를 난이도순으로 미리 배치해주면 시작하자마자 멈추지 않습니다.

04판매 준비 체크리스트

브리프부터 등록까지, 순서대로 체크하며 진행하세요.

1단계검증

  • Worksheet 2로 계산기 3종 모두 내(또는 지인의) 실제 조건으로 테스트하기
  • 실제 애드센스·유튜브 스튜디오 데이터와 대조해 오차 확인하기
  • 계산기 시트에 확인한 RPM·YPP 조건과 확인 날짜 메모 남기기

2단계다듬기

  • 입력 셀(노란색) 옆에 "여기에 숫자를 입력하세요" 안내 문구 확인하기
  • "조회수·수익을 보장하지 않는 참고용 진단"이라는 경계 문구가 각 파일에 붙어있는지 확인하기
  • 파일명·시트명에 오탈자 없는지 최종 점검하기

3단계등록

  • Worksheet 1로 패키지·가격 확정하기
  • 래피드에 상품명 "계산기/유튜브/채널기획" 단어 포함해 등록하기
  • Day39 전자책과 세트 상품(업셀) 옵션도 함께 등록하기

4단계갱신 관리

  • YPP 가입 조건(2027년 2월 상향 예고)·니치별 RPM 시세 변경 공지 분기마다 확인해 캘린더에 표시해두기
  • 기존 상담 고객 연락처/알림 목록 만들어두기(다음 진단·갱신 시점 안내용)
