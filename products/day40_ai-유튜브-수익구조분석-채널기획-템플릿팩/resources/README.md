# AI 유튜브 수익 구조 분석 — 수익 계산기 + 채널 기획 템플릿팩 사용 가이드

『구독자가 없어도, 유튜브 채널 기획은 대신 해드릴 수 있습니다』(Day39 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 2·5·6·7·8(니치별 수익성 진단·채널 기획서·영상 아이디어·수익 다각화·YPP 로드맵)을 이미 끝내둔 완성본 엑셀 계산기 3종 + 채널 기획 템플릿 + 상담 진행 체크리스트를 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 구성 파일

| 파일 | 내용 |
|---|---|
| `kit.html` | 계산기·템플릿 5종 빠른 참고표(입력·결과 예시) + 패키지·검증 워크시트 + 상담 진행 체크리스트 + 판매 준비 체크리스트를 한눈에 보기 좋게 디자인한 버전 (브라우저로 열거나 PDF로 인쇄) |
| `조건만_넣으면_진단서가_나옵니다.pdf` | `kit.html`을 인쇄한 PDF 버전 (오프라인·인쇄용) |
| `니치별_RPM_수익성_계산기.xlsx` | 후보 니치별 RPM(1,000회 조회당 수익) 하단/상단을 입력하면 월 조회수 1만/10만/100만 구간별 예상 광고수익과 니치 간 배율, 목표 수익 달성에 필요한 조회수까지 자동 계산 |
| `YPP_달성_로드맵_계산기.xlsx` | 주당 업로드 편수·평균 조회수·시청 지속시간·구독 전환율(롱폼), 쇼츠 업로드·조회수(쇼츠 경로)를 입력하면 펜 펀딩·전체 광고수익 단계 도달까지 예상 개월수를 역산 |
| `협찬단가_제휴수익_계산기.xlsx` | 구독자·평균 조회수·참여율·기준 단가를 입력하면 영상 유형별(언급형·전용리뷰형·콜라보형) 협찬 단가 참고값과 월 예상 제휴마케팅 수익을 계산, 채널 성장 단계별 수익원 도입 로드맵 포함 |
| `채널기획서_4주캘린더_영상아이디어30개.xlsx` | 채널명 후보·타깃 페르소나·핵심 시리즈를 정리하는 채널기획서, 주차별 업로드 캘린더, 영상 아이디어 30개(제목 후보·썸네일 문구·난이도)를 채워 넣는 템플릿. 난이도 분포는 COUNTIF로 자동 집계 |
| `상담_진행_체크리스트.xlsx` | 온보딩·진단 7단계, 채널 기획 7단계, 납품·마무리 4단계 — 총 18단계를 순서대로 정리한 진행 관리표 |

## 엑셀 파일 공통 구조

계산기 3종(니치별 RPM·YPP 로드맵·협찬단가) 모두 같은 구조로 만들었습니다.

1. **안내 시트** — "조회수·수익을 보장하지 않는 참고용 진단 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **기준값(YPP 로드맵 계산기 안에 포함)** — YPP 가입 조건처럼 자주 바뀌는 정보를 계산기 시트 안에 함께 정리했습니다(2026년 9월 확인 기준, 2027년 2월 조건 상향 예고). 기준이 바뀌면 해당 표만 새로 갱신하면 됩니다.
3. **계산기 시트** — 노란색 칸에 숫자를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`채널기획서_4주캘린더_영상아이디어30개.xlsx`는 계산 파일이 아니라 AI 리서치 결과를 옮겨 적는 빈 양식입니다. `상담_진행_체크리스트.xlsx`도 계산 파일이 아니라 진행 체크용 표입니다. 완료 열(노란 칸)에 O나 완료일을 적어가며 사용하세요.

## 계산기·템플릿을 잇는 순서

1. **니치별 RPM·수익성 계산기**로 후보 니치의 광고 수익성부터 비교합니다.
2. **YPP 달성 로드맵 계산기**로 확정한 업로드 주기·조회수 기준 수익화 시작 시점을 역산합니다.
3. **협찬단가·제휴수익 계산기**로 광고 수익 외 부가 수익원(협찬·제휴)까지 함께 설계합니다.
4. 진단이 끝났다면 **채널기획서_4주캘린더_영상아이디어30개**를 채워 실제 운영 가능한 기획서로 완성합니다.
5. 전체 과정은 **상담_진행_체크리스트**로 순서대로 진행하며 빠뜨리는 단계가 없도록 관리합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 상담 대상) 조건으로 직접 테스트하기** — `kit.html`의 Worksheet 2(교차검증)를 참고해 실제 엑셀 파일에 실제 채널 조건을 넣어보고, 실제 애드센스·유튜브 스튜디오 데이터와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트/상담 가격을 정한 뒤, 상품명에 "계산기", "유튜브", "채널기획"이라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 채널 성장을 보장하는 컨설팅이 아니라 **참고용 진단·기획 도구**입니다. RPM 시세·YPP 가입 조건·협찬 단가는 정책과 시장 상황에 따라 자주 바뀌므로, 실제 상담이나 판매에 사용하기 전 반드시 최신 정보로 재확인하세요. 최종 의사결정(채널 시작 여부, 니치 선택)은 항상 고객 본인의 몫으로 남겨두어야 합니다.
