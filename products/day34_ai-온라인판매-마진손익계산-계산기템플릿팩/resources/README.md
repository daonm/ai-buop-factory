# AI 온라인 판매 마진·손익 계산 자동화 — 마진 계산기 + BEP 계산기 템플릿팩 사용 가이드

『팔았는데 왜 남는 게 없죠』(Day33 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 5·6·7·9(상품별 마진 계산기 만들기·손익분기점 계산하기·광고비 반영 실질마진·다상품 비교)를 이미 끝내둔 완성본 엑셀 계산기 4종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 구성 파일

## 엑셀 파일 공통 구조

네 파일 모두 같은 구조로 만들었습니다.

1. **안내 시트** — "참고용 계산 도구이며 세무·회계 상담을 대신하지 않는다"는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **기준표 시트(상품 마진 계산기만 해당)** — 플랫폼별 수수료 구조처럼 자주 바뀌는 정보를 따로 모아뒀습니다(2026년 9월 확인 기준). 수수료율이 바뀌면 이 시트를 참고해 계산기의 입력값만 새로 넣으면 됩니다.
3. **계산기 시트** — 노란색 칸에 숫자를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

## 계산기 4종을 잇는 순서

1. **상품 마진 계산기**로 상품 1개의 개당 순마진을 먼저 구합니다.
2. 그 값을 **손익분기점(BEP) 계산기**의 "개당 순마진" 칸에 옮겨 넣어, 몇 개를 팔아야 본전인지 확인합니다.
3. 광고를 쓰는 상품이라면 **광고비 반영 실질마진 계산기**로 CPA를 반영한 "진짜" 마진을 다시 확인합니다.
4. 상품이 여러 개라면 **다상품 마진 비교 계산기**에 상품별 매출·마진액을 모아 넣어, 매출이 아니라 마진 기준으로 우선순위를 정합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기 4종 훑어보기** — 어떤 계산기가 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인 상품으로 직접 테스트하기** — `kit.html`의 Worksheet 2(교차검증)를 참고해 실제 엑셀 파일에 본인 상품의 판매가·원가·수수료 정보를 넣어보고, 실제 정산 내역·광고 관리자 데이터와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트/묶음 가격을 정한 뒤, 상품명에 "계산기", "BEP", "마진"이라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.
