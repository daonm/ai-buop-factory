# AI 이사비용·중개수수료 계산 대행 — 계산기 + 체크리스트 템플릿팩 사용 가이드

『그 견적서, AI한테 먼저 검증받으세요』(Day43 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~8(이사비용 구성 원리·평수별 계산·날짜 프리미엄·견적서 비교·중개수수료 요율·협상·행정 체크리스트)을 이미 끝내둔 완성본 엑셀 계산기·체크리스트 5종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 구성 파일

| 파일 | 내용 |
|---|---|

| `그_견적서_AI한테_먼저_검증받으세요_실행키트.pdf` | `kit.html`을 인쇄한 PDF 버전 (오프라인·인쇄용) |
| `이사비용_계산기.xlsx` | 평수 구간별 기준가 참고표 + 이사 방식·거리·엘리베이터·사다리차·날짜 유형·성수기 여부를 입력하면 할증 항목별 금액과 최종 예상 비용 범위를 자동 계산 |

| `전입신고_확정일자_전월세신고_체크리스트.xlsx` | 이사일·계약일·보증금·월세를 입력하면 전입신고·전월세신고 법정 마감일과 대상 여부를 자동 계산, 이사 당일~+30일 타임라인 체크리스트로 관리 |
| `의뢰접수_상담진행_체크리스트.xlsx` | 의뢰인에게 받아야 할 정보를 빠짐없이 받는 접수 질문지 + 접수→리서치→계산→검증→행정→납품→사후관리 16단계 진행 체크리스트(진행률 자동 집계) |

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 견적·감정이 아니라 참고용 리서치·계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자(또는 텍스트)를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`견적서_비교_검증표.xlsx`와 `전입신고_확정일자_전월세신고_체크리스트.xlsx`도 입력 조건에 따라 자동 계산되는 결과가 있지만, 동시에 체크리스트(완료 O 표시) 성격도 함께 가지고 있습니다. `의뢰접수_상담진행_체크리스트.xlsx`는 계산 파일이 아니라 접수·진행 관리용 표입니다. 완료 열(노란 칸)에 O를 적어가며 사용하세요.

## 계산기·체크리스트를 잇는 순서

1. **이사비용 계산기**로 평수·거리·날짜 조건에 맞는 예상 이사 비용 범위부터 계산합니다.
2. **중개수수료 계산기**로 거래 조건(매매/전세/월세)에 맞는 법정 상한 중개수수료를 계산합니다.
3. 실제 받은 이사 견적서가 있다면 **견적서 비교 검증표**로 업체별 항목을 대조하고 과다 항목·협상 여지를 확인합니다.
4. **전입신고·확정일자·전월세신고 체크리스트**로 비용 계산 이후 놓치기 쉬운 행정 절차의 법정 기한을 확정합니다.
5. 전체 과정은 **의뢰접수·상담진행 체크리스트**로 순서대로 진행하며 빠뜨리는 단계가 없도록 관리합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·체크리스트 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 이사·계약 조건을 넣어보고, 받은 견적서나 myhome.go.kr 공식 계산기와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "이사비용", "중개수수료"라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 견적이나 감정평가가 아니라 **참고용 리서치·계산 도구**입니다. 평수별 기준가, 날짜 할증 감각, 법정 중개수수료 요율은 시장 상황과 제도에 따라 자주 바뀌므로, 실제 상담이나 거래에 사용하기 전 반드시 최신 정보(myhome.go.kr 등 공식 자료)로 재확인하세요. 특히 저가 구간의 중개수수료는 요율 상한 외에 별도 한도액(정액 상한)이 적용될 수 있으니, 공식 계산기와 함께 반드시 교차검증해야 합니다. 최종 비용과 거래 여부는 항상 고객 본인의 몫으로 남겨두어야 합니다.
