# AI 온라인 강의 커리큘럼 설계 — 8주 커리큘럼 템플릿 5종 사용 가이드

『그 지식, 아직 커리큘럼이 아닙니다』(Day19 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다.

## 구성 파일

| 파일 | 내용 |
|---|---|
| `kit.html` | 도메인 5개의 8주 커리큘럼 요약표 + 학습목표 + 워크시트 + 설계 체크리스트를 한눈에 보기 좋게 디자인한 버전 (브라우저로 열거나 PDF로 인쇄) |
| `8주_커리큘럼_템플릿_전체모음.md` | 마케터 / 요가 강사 / 재테크 유튜버 / 백엔드 개발자 / 홈베이커 — 도메인별 8주 전체 상세안(학습목표·주차별 핵심개념·실습과제·예상 소요시간). 복사해서 내 주제로 바꿔 쓰는 용도 |
| `학습목표_난이도곡선_워크시트.md` | 내 주제에 맞게 학습목표·난이도곡선·인터뷰 원료를 정리하는 빈칸 워크시트 3종 |
| `커리큘럼_설계_체크리스트.md` | 인터뷰 → 목표·모듈 설계 → 회차 상세 → 심사·등록까지 순서대로 확인하는 4단계 체크리스트 |

## 3단계 사용법

1. **가장 비슷한 도메인 고르기** — `8주_커리큘럼_템플릿_전체모음.md`에서 내 고객(또는 나)의 분야·플랫폼과 가장 가까운 도메인 하나를 고릅니다. 실무형이면 마케터·백엔드 개발자 예시를, 취미·라이프스타일이면 요가 강사·홈베이커 예시를, 자기계발이면 재테크 유튜버 예시를 참고하세요.
2. **워크시트로 내 주제에 맞게 다듬기** — `학습목표_난이도곡선_워크시트.md`로 학습목표 5개와 난이도 곡선을 내 주제 기준으로 다시 정리합니다.
3. **8주 모듈에 그대로 이식하기** — 고른 도메인의 8주 표를 복사해, 모듈 제목·핵심개념·실습과제만 실제 전문가 인터뷰 내용으로 교체합니다. 8주 순서(입문 → 심화 → 실습 프로젝트)는 그대로 유지하는 것을 권장합니다.

전체 진행 순서를 놓치지 않으려면 `커리큘럼_설계_체크리스트.md`를 인터뷰 시작 전부터 펼쳐두고 순서대로 체크하세요.
