# 커리큘럼 설계 프로세스 체크리스트

인터뷰부터 플랫폼 등록까지, 순서대로 체크하며 진행하세요. 『그 지식, 아직 커리큘럼이 아닙니다』(Day19)의 방법 1~12를 실행 순서로 압축한 버전입니다.

## 1단계 — 인터뷰 · 원료 수집

- [ ] 연습용 전문가(본인 또는 지인) 1명, 주제 1개 정하기
- [ ] AI로 심층 인터뷰 질문 10개 뽑아 인터뷰 가이드로 사용하기
- [ ] 인터뷰 진행 및 녹음/받아적기 (원문 그대로 보관)
- [ ] 인터뷰 답변을 AI로 주제별 분류해 지식 원료 목록 만들기
- [ ] 타깃 수강생 페르소나 3명(입문자/중급자/실무자) 정의하기

## 2단계 — 목표 · 모듈 설계

- [ ] 학습목표 5개를 동사형으로 확정하기 (Worksheet 1)
- [ ] 8주 모듈 구조를 난이도 순으로 배치하기
- [ ] 앞 모듈이 뒤 모듈의 전제 지식이 되는지 순서 검증하기
- [ ] 난이도 곡선 점검하기 (Worksheet 2) — 급격히 튀는 구간 조정
- [ ] 선수지식과 대체 자료 정리하기

## 3단계 — 회차 상세 · 실습 설계

- [ ] 회차별 학습목표/핵심개념/실습과제/예상 소요시간 상세안 작성하기
- [ ] 회차 제목에 전문가만의 표현(인터뷰 원문) 살려 넣기
- [ ] 실습과제를 난이도별로 2~3개씩 배치하기
- [ ] 이탈이 잦은 지점(보통 3~4회차)에 체크포인트 질문 추가하기
- [ ] 마지막 회차에 완성 프로젝트 배치하기

## 4단계 — 심사 · 등록 준비

- [ ] 플랫폼별 기획안 형식 확인하기 (심사형: 클래스101·탈잉 / 자유업로드형: 인프런·유데미)
- [ ] 강의소개 카피 후킹형/신뢰형 2버전 작성하기
- [ ] 구매 망설임 해소용 FAQ 6개 정리하기
- [ ] 파일럿 수강생 3~5명 피드백 반영하기
- [ ] 패키지 3단계(컨설팅/상세설계/풀패키지)와 가격 확정하기
