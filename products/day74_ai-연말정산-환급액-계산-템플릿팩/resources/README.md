# AI 연말정산 환급액 계산 대행 — 계산기 + 공제서류 체크리스트 템플릿팩 사용 가이드

『연말정산 서류 제출하기 전에, AI한테 환급액부터 물어보세요』(Day73 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~8(근로소득금액 계산, 인적공제 정리, 특별소득공제 계산, 과세표준·산출세액, 세액공제 항목 정리, 결정세액·환급액 계산, 간소화 서비스 점검, 경정청구)을 이미 끝내둔 완성본 엑셀 계산기 3종·엑셀 공제서류체크리스트+경정청구D-day계산기 1종·워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 구성 파일

| 파일 | 내용 |
|---|---|
| `kit.html` | 계산기·체크리스트·템플릿 5종 빠른 참고표(입력·결과 예시) + 검증 워크시트 + 상담 진행 체크리스트 + 판매 준비 체크리스트를 한눈에 보기 좋게 디자인한 버전 (브라우저로 열거나 PDF로 인쇄) |
| `연말정산환급액계산대행_실행키트.pdf` | `kit.html`을 인쇄한 PDF 버전 (오프라인·인쇄용) |
| `A_소득공제_과세표준_계산기.xlsx` | 연봉·비과세소득을 입력하면 총급여·근로소득금액이 자동 계산되고, 부양가족 인원과 보험료·주택자금 지출을 입력하면 인적공제·특별소득공제까지 반영한 과세표준이 자동 계산되는 계산기 |
| `B_산출세액_세액공제_계산기.xlsx` | 과세표준을 입력하면 8단계 누진세율표를 적용한 산출세액이 자동 계산되고, 자녀·연금계좌·특별세액공제(보험료·의료비·교육비·기부금)·신용카드 등 사용액을 입력하면 세액공제 합계까지 자동 계산 |
| `C_결정세액_환급액_계산기.xlsx` | 산출세액과 세액공제 합계를 입력하면 결정세액과 기납부세액을 비교한 환급(또는 추가납부)액이 자동 판정. '가족비교' 시트로 부부 등 최대 3인을 나란히 비교 가능 |
| `D_공제서류체크리스트_경정청구Dday_계산기.xlsx` | 귀속연도를 입력하면 경정청구 가능 마감일(법정신고기한으로부터 5년)과 남은 일수를 자동 계산하는 'D-day계산기' 시트 + 간소화 서비스 증빙자료 20종을 준비상태 드롭다운으로 정리한 '체크리스트' 시트 |
| `의뢰접수_고객리포트_템플릿.docx` | 의뢰 접수 질문지(14문항) + 기준값·한도 체크(5개) + 고객용 예상 연말정산 환급액 리포트 템플릿(9단계) + 서비스 안내·가격 템플릿까지 대괄호만 바꿔서 바로 쓰는 문서 |

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 환급액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자(또는 인원수)를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`A_소득공제_과세표준_계산기.xlsx`는 근로소득금액 계산 → 인적공제 계산 → 특별소득공제 계산 → 과세표준 확정 순서로 4개 구역을 이어서 계산하고, `B_산출세액_세액공제_계산기.xlsx`는 A계산기의 과세표준·총급여 결과값을 이어받아 산출세액과 7개 세액공제 항목을 계산하며, `C_결정세액_환급액_계산기.xlsx`는 B계산기의 산출세액·세액공제 합계를 이어받아 최종 환급(또는 추가납부)액을 판정하고, `D_공제서류체크리스트_경정청구Dday_계산기.xlsx`는 D-day계산기 시트(귀속연도 1개 입력 → 경정청구 기한 자동 계산)와 체크리스트 시트(증빙서류 20종, 준비상태 드롭다운)로 구성되고, `의뢰접수_고객리포트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 쓰는 문서입니다.

## 계산기·체크리스트·템플릿을 잇는 순서

1. **A_소득공제_과세표준_계산기**로 연봉·비과세소득, 부양가족, 보험료·주택자금 지출을 입력해 과세표준을 확정합니다.
2. **B_산출세액_세액공제_계산기**로 넘어가 A계산기의 과세표준·총급여 값을 입력하고, 세율표 적용 산출세액과 세액공제 항목을 계산합니다.
3. **C_결정세액_환급액_계산기**로 B계산기의 산출세액·세액공제 합계를 입력해 최종 환급(또는 추가납부)액을 확인합니다.
4. **D_공제서류체크리스트_경정청구Dday_계산기**로 간소화 서비스에서 챙겨야 할 증빙서류 20종을 점검하고, 과거 연도 누락 공제가 있다면 경정청구 가능 기한을 확인합니다.
5. **의뢰접수_고객리포트_템플릿**으로 의뢰를 접수하고, 계산 결과를 고객용 리포트로 정리해 전달합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·체크리스트·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 급여·지출 내역으로 직접 테스트하기** — 실제 엑셀 파일에 실제 급여·지출 내역을 넣어보고, 국세청 홈택스(hometax.go.kr) 연말정산 미리보기 서비스·회사에서 실제 처리한 연말정산 결과와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "연말정산", "환급액", "세액공제"라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 환급액이 아니라 **참고용 추정 계산 도구**입니다. 소득세 누진세율표(6~45%, 2023년 개정 이후 8단계 구조), 각종 공제 한도·공제율, 경정청구 기한(5년)은 이 계산기를 만든 시점 기준의 예시값이며, 세법 개정으로 바뀔 수 있으므로 실제 적용 전 반드시 국세청 홈택스(hometax.go.kr) 연말정산 간소화 서비스·연말정산 미리보기 서비스로 최신 기준을 재확인하세요. 특히 연봉과 총급여(비과세소득 제외)를 혼동하지 않아야 하고, 의료비·신용카드 공제는 총급여 대비 초과 기준선을 넘는 지출분만 대상이며, 환급액은 기납부세액을 초과할 수 없고, 부양가족 자료는 당사자가 간소화 서비스에 "자료제공 동의"를 해야 조회된다는 점을 의뢰인에게 항상 명확히 안내해야 합니다. 이 부업은 회사의 원천징수 업무나 세무사의 고유 업무(세무대리, 세무조정, 과세관청 상대 대응)를 대신하는 것이 아니라 계산 정리 대행이라는 점을 상담 시작 전 항상 명확히 안내해, 세무사법 위반(비세무사의 세무대리) 소지가 없도록 서비스 범위를 벗어나지 않게 운영하세요.
