# AI 국민연금·개인연금 노후 수령액 계산 대행 — 계산기 + 연금설계 체크리스트 템플릿팩 사용 가이드

『연금 신청 전에, AI한테 수령액부터 물어보세요』(Day61 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~12(국민연금 기준값 조회, 조기·연기수령 가산율 적용, 손익분기 나이 비교, 개인연금 세액공제·수령액 추정, 합산 노후소득 설계, 생활비 부족분 진단, 건강보험 피부양자 점검)를 이미 끝내둔 완성본 엑셀 계산기 3종·엑셀 연금설계 체크리스트 1종·워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 구성 파일

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 수령액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`연금설계_체크리스트.xlsx`는 수급연령계산기 시트(생년월일 입력→정상 수급 개시 연령·D-day 자동 계산)와 연금설계체크리스트 시트(항목별 준비 상태 드롭다운)로 구성되고, `의뢰접수_고객리포트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 쓰는 문서입니다.

## 계산기·체크리스트·템플릿을 잇는 순서

1. **연금설계_체크리스트**의 수급연령계산기로 정상 수급 개시 연령과 D-day부터 확인하고, 연금설계체크리스트로 빠뜨리기 쉬운 점검 항목을 짚습니다.
2. **국민연금_조기연기수령_비교계산기**로 조기·정상·연기수령 시나리오와 손익분기 나이부터 계산하고, **개인연금_세액공제_수령액_계산기**로 넘어가 세액공제 환급액과 노후 수령액을 계산합니다.
3. 두 계산이 끝나면 **노후소득_합산진단_계산기**로 합산 월소득, 생활비 부족분, 건강보험 피부양자 기준 대비까지 한 번에 진단합니다.
4. **의뢰접수_고객리포트_템플릿**으로 의뢰를 접수하고, 계산 결과를 고객용 리포트로 정리해 전달합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·체크리스트·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 출생연도·가입기간·납입액 조건을 넣어보고, 국민연금공단(nps.or.kr)의 '내 연금 알아보기'·국세청 연말정산 자료와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "국민연금", "개인연금", "노후수령액"이라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 수령액이 아니라 **참고용 추정 계산 도구**입니다. 국민연금 수급 개시 연령·조기·연기 가산율, 개인연금 세액공제 한도·공제율·연금소득세율, 건강보험 피부양자 기준은 정책·세법 개편으로 자주 바뀌므로, 실제 적용 전 반드시 국민연금공단(nps.or.kr)·국세청·건강보험공단(1577-1000)으로 최신 값을 재확인하세요. 조기수령으로 줄어든 비율은 평생 고정되며 이후 복구되지 않는다는 점, 연기수령 기간 동안은 연금을 전혀 받지 못한다는 점, 국민연금과 개인연금의 수령 시작 나이가 다르면 소득 공백(크레바스) 구간이 생길 수 있다는 점은 계산기에 단순화되어 있는 만큼 상담 시 반드시 별도로 안내해야 합니다. 이 부업은 재무설계사·세무사·건강보험공단의 고유 업무(실제 투자 자문, 세무 신고 대행, 건강보험료 이의신청)를 대신하는 것이 아니라 사전 계산과 안내라는 점을 상담 시작 전 항상 명확히 안내해 오해를 예방해야 합니다.
