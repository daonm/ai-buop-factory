# AI 해외직구 관부가세 계산 대행 — 계산기 + 사이트별 가이드 템플릿팩 사용 가이드

『그 직구, 관세청 문자 받기 전에 AI한테 먼저 계산받으세요』(Day49 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~9(목록통관 면세 기준·자가사용 판단, 과세환율 적용, 품목별 관세율(간이세율) 계산, 부가세 포함 총 관부가세 계산, 합산과세 판단, 면세 한도 초과 시나리오 비교, 개인통관고유부호 안내, 품목별 주의사항 반영, 대행 부업 수익화)를 이미 끝내둔 완성본 엑셀 계산기 3종·엑셀 가이드 1종·워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 세액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자(또는 목록에서 선택)를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`사이트별_직구_가이드.xlsx`는 계산 파일이 아니라 참고용 비교표이고, `의뢰접수_고객리포트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 복사해 쓰는 문서입니다.

## 계산기·가이드·템플릿을 잇는 순서

1. **사이트별_직구_가이드**에서 의뢰인이 주문한 사이트의 통관 특이사항(배송비 합산, 분할배송, 인보이스 이슈)을 먼저 확인합니다.
2. **면세판단_관부가세_계산기**로 목록통관 면세 여부부터 관세·부가세 포함 총 관부가세를 계산합니다.
3. 같은 날 같은 판매자에게 다른 주문이 있다면 **합산과세_시나리오비교_계산기**로 합산 대상 여부와 면세 한도 근처 시나리오를 비교합니다.
4. 품목이 주류·건강기능식품·전자기기라면 **품목별_추가세금_계산기**로 주세·교육세나 통관 주의사항을 추가로 확인합니다.
5. **의뢰접수_고객리포트_템플릿**으로 의뢰를 접수하고, 계산 결과를 고객용 리포트로 정리해 전달합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·가이드·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 주문 조건을 넣어보고, 관세청 유니패스(unipass.customs.go.kr)의 관부가세 계산기와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "해외직구", "관부가세"라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 세액이 아니라 **참고용 추정 계산 도구**입니다. 면세 기준·관세청 과세환율·품목별 간이세율은 관세청 고시와 정책에 따라 수시로 바뀌므로, 실제 통관 전 반드시 관세청 유니패스(unipass.customs.go.kr)의 관부가세 계산기나 관세사 확인으로 최신 값을 재확인하세요. 주류의 주세율·교육세율·1인당 반입 한도, 건강기능식품·전자기기의 통관 규정도 주종·정책에 따라 달라지는 참고치이며, 실제 적용 전 관세청·식약처·국립전파연구원 공지로 다시 확인해야 합니다. 사이트별 통관 특이사항은 일반적으로 알려진 내용을 정리한 참고 자료로, 쇼핑몰 운영 정책 변경에 따라 달라질 수 있습니다. 이 부업은 관세사 업무(통관 대리, 신고서 작성 등)를 대신하는 것이 아니라 계산과 사전 안내라는 점을 상담 시작 전 항상 명확히 안내해 오해를 예방해야 합니다.
