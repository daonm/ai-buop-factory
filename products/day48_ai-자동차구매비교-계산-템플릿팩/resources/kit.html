계산은 다 만들어놨습니다. 이제 조건만 넣으면 됩니다. 이 키트는 전자책 방법 1~9(할부·리스·현금 기본 구조·2026년 취득세·개별소비세 계산·할부 조건별 비교·리스 조건별 비교·현금 기회비용·5년 TCO 비교·사업자 절세효과)를 이미 끝낸 완성본입니다.

엑셀 계산기 4종과 워드 템플릿 1종을 같은 톤으로 만들었습니다.

  1. 안내 시트 — "확정 세액·보장 금액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다.
  2. 계산기 시트 — 노란색 칸에 값을 입력하면 올리브색 칸에 결과가 바로 뜹니다.
  3. 참고표(해당 파일만) — 취득세율·할부 금리 구간처럼 반복해서 쓰는 기준을 계산기 시트 상단에 함께 정리해뒀습니다.

사용법 — 아래 계산기별 참고표에서 원하는 것부터 확인하고, 실제 파일을 열어 본인(또는 의뢰인) 조건으로 한 번 테스트해본 뒤 견적 비교·의뢰 접수 템플릿까지 이어서 진행하세요.

입력값결과값

입력값결과값

04판매 준비 체크리스트

브리프부터 등록까지, 순서대로 체크하며 진행하세요.

1단계검증

  • Worksheet 2로 계산기 A·B·D 모두 내(또는 지인의) 실제 조건으로 테스트하기
  • 위택스·국세청 공지와 대조해 세율·감면 한도 오차 확인하기
  • 계산기 시트에 확인한 세율·금리와 확인 날짜 메모 남기기

2단계다듬기

  • 입력 셀(노란색) 옆에 "여기에 값을 입력하세요" 안내 문구 확인하기
  • "참고용 추정치이며 보장된 금액이 아니다"는 경계 문구가 각 파일에 붙어있는지 확인하기
  • 파일명·시트명에 오탈자 없는지 최종 점검하기

3단계등록

  • Worksheet 1로 패키지·가격 확정하기
  • 래피드에 상품명 "계산기/자동차/할부리스비교" 단어 포함해 등록하기
  • Day47 전자책과 세트 상품(업셀) 옵션도 함께 등록하기

4단계갱신 관리

  • 개별소비세 탄력세율·전기차 감면 일몰 시점 분기마다 확인해 캘린더에 표시해두기
  • 기존 상담 고객 연락처/알림 목록 만들어두기(다음 차량 교체 시즌 안내용)
  • 세율·감면 한도 변경 시 계산기 A·D의 참고표만 교체 후 Worksheet 2 검증 다시 거치기
