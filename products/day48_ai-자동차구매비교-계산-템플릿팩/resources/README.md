# AI 자동차 구매 비교 계산 대행 — 계산기 + 견적 비교 템플릿팩 사용 가이드

『그 차, AI한테 먼저 계산받으세요』(Day47 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~9(할부·리스·현금 기본 구조·2026년 취득세·개별소비세 계산·할부 조건별 비교·리스 조건별 비교·현금 기회비용·5년 TCO 비교·사업자 절세효과)를 이미 끝내둔 완성본 엑셀 계산기 4종과 워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 세액·보장 금액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자(또는 텍스트)를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`견적비교_의뢰접수_템플릿.docx`는 계산 파일이 아니라 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 복사해 쓰는 문서입니다.

## 계산기·템플릿을 잇는 순서

1. **실구매가·취득세 계산기**로 차량의 총 실구매가(세금 포함)부터 계산합니다.
2. 할부·리스 중 고려 중인 방식이 있으면 **할부·리스 비교 계산기**로 월 납입금과 총 이자(또는 만기 처리 비용)를 계산합니다.
3. **5년 총비용(TCO) 비교 계산기**에 위 두 계산기의 결과와 자동차세·보험료·정비비를 입력해 할부·리스·현금 세 방식의 5년 총비용을 한눈에 비교합니다.
4. 의뢰인이 사업자·법인이라면 **사업자 절세효과 계산기**로 할부 대비 리스의 절세효과 차이를 추가로 계산합니다.
5. **견적비교_의뢰접수_템플릿**으로 영업사원 견적서를 비교하고, 의뢰 접수부터 고객용 리포트 작성까지 마무리합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 차량가·금리·조건을 넣어보고, 위택스(wetax.go.kr) 취득세 안내·금융사 정식 견적과 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "자동차", "할부리스비교"라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 세액·보장 금액이 아니라 **참고용 추정 계산 도구**입니다. 개별소비세 탄력세율·전기차 취득세 감면 한도·일몰 시점은 정부 정책에 따라 바뀔 수 있으므로, 실제 계약 전 반드시 위택스(wetax.go.kr) 지방세 안내와 국세청 개별소비세 공지로 최신 세율을 재확인하세요. 할부 금리·리스 보증금·잔존가치율은 금융사·리스사·신용등급에 따라 실제 적용치가 달라지는 추정치이며, 정확한 조건은 반드시 해당 금융사·리스사의 정식 견적으로 확인해야 합니다. 사업자 절세효과 계산기의 감가상각 한도·업무용승용차 관련비용 손금 한도는 세법 개정에 따라 바뀔 수 있어 실제 적용 전 세무사 확인이 반드시 필요합니다. 이 부업은 금융상품을 판매하거나 가입을 알선하는 것이 아니라 계산·비교·견적 검증이라는 점을 상담 시작 전 항상 명확히 안내해 오해를 예방해야 합니다.
