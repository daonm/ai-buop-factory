# AI 1세대1주택 비과세·부동산 양도소득세 계산 대행 — 계산기 + 서류 체크리스트 템플릿팩 사용 가이드

『집 팔기 전에, AI한테 비과세 되는지부터 물어보세요』(Day77 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~9(1세대1주택 비과세 요건 확인, 고가주택 여부 판단, 양도차익 계산, 장기보유특별공제 계산, 기본공제·세율 적용 최종 세액 계산, 일시적 2주택 비과세 특례 판단, 주택수 판정의 특수 케이스 점검, 비과세 안 될 때 다주택자 세금 비교, 매년 바뀌는 양도세 기준 확인)을 이미 끝내둔 완성본 엑셀 계산기 3종·엑셀 일시적2주택특례판정+다주택비교+전략체크리스트 1종·워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 세액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 날짜·금액·여부를 입력하면 올리브색·금색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`A_비과세요건_주택수판정_계산기.xlsx`는 보유·거주기간 요건을 판정한 뒤 상속주택·분양권·입주권·농어촌주택 특수 케이스를 반영해 최종 세대주택수와 비과세 기본요건을 확정하고, `B_양도차익_장기보유특별공제_계산기.xlsx`는 고가주택 여부와 과세대상 양도차익을 계산한 뒤 보유·거주기간별 장기보유특별공제율을 적용하며, `C_최종세액_계산기.xlsx`는 양도소득 기본공제를 뺀 과세표준에 누진세율을 적용해 최종 납부세액을 산출하고, `D_일시적2주택특례_다주택비교_전략체크리스트.xlsx`는 처분기한 준수 여부를 판정하는 시트와 다주택자 양도 순서를 비교하는 시트, 그리고 제도확인 체크리스트 시트로 구성되며, `의뢰접수_고객리포트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 쓰는 문서입니다.

## 계산기·체크리스트·템플릿을 잇는 순서

1. **A_비과세요건_주택수판정_계산기**로 취득일·거주기간·조정대상지역 여부와 특수 케이스 정보를 입력해 1세대1주택 비과세 기본요건을 확정합니다.
2. **B_양도차익_장기보유특별공제_계산기**로 넘어가 A의 판정 결과와 양도가액·취득가액·필요경비를 입력해 과세대상 양도차익과 장기보유특별공제액을 확정합니다.
3. **C_최종세액_계산기**로 넘어가 B의 결과를 옮겨 입력해 과세표준과 최종 납부세액을 확인합니다.
4. **D_일시적2주택특례_다주택비교_전략체크리스트**로 이사 등으로 일시적 2주택이 됐다면 특례 적용 여부를, 다주택 상태로 양도해야 한다면 양도 순서를 비교하고, 제도확인 14개 항목을 점검합니다.
5. **의뢰접수_고객리포트_템플릿**으로 의뢰를 접수하고, 계산 결과를 고객용 리포트로 정리해 전달합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·체크리스트·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 취득일·양도가액·거주 이력을 넣어보고, 국세청 홈택스(hometax.go.kr)의 양도소득세 모의계산과 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "1세대1주택", "비과세", "양도소득세"라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 세액이 아니라 **참고용 추정 계산 도구**입니다. 양도소득세의 계산 구조(양도차익 → 장기보유특별공제 → 기본공제 → 세율) 자체는 오랫동안 유지돼 왔지만, 비과세 기준금액(12억 원), 조정대상지역 지정 현황, 일시적 2주택 처분기한, 분양권·입주권 주택수 포함 기준일, 상속·농어촌주택 특례 요건, 장기보유특별공제율표, 세율구간·누진공제액은 세법 개정과 정책에 따라 수시로 바뀌므로, 이 계산기를 만든 시점 기준의 예시값일 뿐이며 실제 양도 전에는 반드시 국세청 홈택스(hometax.go.kr)의 양도소득세 모의계산과 세무 전문가 확인을 거쳐야 합니다. 이 부업은 세무사의 세무대리·양도소득세 신고 대리 업무나 공인중개사의 중개 업무가 아니라 공개된 세법 조항과 입력된 조건을 조합한 계산 정리 대행이라는 점을 상담 시작 전 항상 명확히 안내해, 세무대리 서비스로 오인되지 않도록 서비스 범위를 벗어나지 않게 운영하세요.
