# AI 실업급여(구직급여) 계산 대행 — 계산기 + 신청서류 체크리스트 템플릿팩 사용 가이드

『퇴사 전에, AI한테 실업급여부터 물어보세요』(Day63 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~12(평균임금 산정, 피보험단위기간 180일 확인, 이직사유 판정, 1일 구직급여액·소정급여일수·총수급액 계산, 조기재취업수당, 수급기간 연장, 중복수급 점검)를 이미 끝내둔 완성본 엑셀 계산기 3종·엑셀 신청서류 체크리스트 1종·워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 구성 파일

| 파일 | 내용 |
|---|---|

| `퇴사전에_AI한테실업급여부터물어보세요_실행키트.pdf` | `kit.html`을 인쇄한 PDF 버전 (오프라인·인쇄용) |
| `평균임금_1일구직급여액_계산기.xlsx` | 이직일과 최근 3개월 급여·상여금·통상시급을 입력하면 1일 평균임금을 계산하고, 통상임금과 비교해 더 높은 값을 적용한 뒤 2026년 기준 상한액(68,100원)·하한액(66,048원)을 적용한 최종 1일 구직급여액까지 자동 계산 |
| `소정급여일수_총수급액_계산기.xlsx` | 회사별 재직기간을 입력하면 피보험단위기간 180일 충족 여부를 확인하고, 연령·가입기간으로 소정급여일수를 산정한 뒤, 1일 구직급여액을 입력하면 총수급액과 대기기간 7일을 반영한 4주 단위 수급 구간표까지 자동 계산 |

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 수급액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`실업급여_신청서류_체크리스트.xlsx`는 D-day계산기 시트(이직일 입력→수급기간 만료일·D-day 자동 계산)와 신청서류체크리스트 시트(항목별 준비 상태 드롭다운)로 구성되고, `의뢰접수_고객리포트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 쓰는 문서입니다.

## 계산기·체크리스트·템플릿을 잇는 순서

1. **실업급여_신청서류_체크리스트**의 D-day계산기로 수급기간 만료일과 D-day부터 확인하고, 신청서류체크리스트로 빠뜨리기 쉬운 서류를 짚습니다.
2. **평균임금_1일구직급여액_계산기**로 1일 평균임금과 최종 1일 구직급여액부터 계산하고, **소정급여일수_총수급액_계산기**로 넘어가 피보험단위기간 충족 여부·소정급여일수·총수급액·수급 일정까지 계산합니다.
3. 재취업 시점이 정해졌다면 **조기재취업수당_계산기**로 예상 조기재취업수당까지 확인합니다.
4. **의뢰접수_고객리포트_템플릿**으로 의뢰를 접수하고, 계산 결과를 고객용 리포트로 정리해 전달합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·체크리스트·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 이직일·재직 이력·급여 조건을 넣어보고, 고용24(work24.go.kr)의 '실업급여 모의계산'·'고용보험 가입 이력 조회' 결과와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "실업급여", "구직급여", "신청서류"라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 수급액이 아니라 **참고용 추정 계산 도구**입니다. 1일 상한·하한액, 소정급여일수표, 대기기간·수급기간 기준은 고용보험법 개정과 최저임금 변동으로 자주 바뀌므로, 실제 적용 전 반드시 고용24(work24.go.kr)·관할 고용센터로 최신 값을 재확인하세요. 이직사유의 최종 판정, 수급자격의 최종 인정, 실업 인정은 고용센터의 고유 권한이며 이 계산기는 추정 판정까지만 다룹니다. 조기재취업수당은 12개월 이상 계속 고용(또는 사업 유지)이 확인되지 않으면 지급되지 않을 수 있고, 동일 사업장 재고용·특수관계인 사업장 취업 등은 지급이 제한될 수 있다는 점도 상담 시 함께 안내해야 합니다. 이 부업은 고용센터의 고유 업무(이직사유 최종 심사, 수급자격 최종 인정, 실업 인정, 실제 신청서 대리 작성)를 대신하는 것이 아니라 사전 계산과 안내라는 점을 상담 시작 전 항상 명확히 안내해 오해를 예방해야 합니다.
