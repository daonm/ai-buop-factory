# AI 육아휴직급여·출산휴가급여 계산 대행 — 계산기 + 신청서류 체크리스트 템플릿팩 사용 가이드

『신청 전에, AI한테 육아휴직급여부터 물어보세요』(Day59 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~9(통상임금 산정, 출산전후휴가급여 상한액 적용, 배우자 출산휴가급여, 육아휴직급여 기본구조·구간별 상한액·하한액, 6+6 부모육아휴직제 특례, 한부모·장애아 특례, 기간연장 판단)를 이미 끝내둔 완성본 엑셀 계산기 3종·엑셀 신청일정 체크리스트 1종·워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 지급액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자(또는 목록에서 선택)를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`신청일정_체크리스트.xlsx`는 주요일정계산기 시트(입력→결과 자동 계산)와 신청서류체크리스트 시트(항목별 준비 상태 드롭다운)로 구성되고, `의뢰접수_고객리포트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 쓰는 문서입니다.

## 계산기·체크리스트·템플릿을 잇는 순서

1. **신청일정_체크리스트**의 주요일정계산기로 신청 마감 D-day부터 확인하고, 신청서류체크리스트로 빠뜨리기 쉬운 서류를 점검합니다.
2. **출산전후휴가_배우자출산휴가_급여계산기**로 출산 전후 급여부터 계산하고, 육아휴직으로 이어지면 **육아휴직급여_계산기**로 넘어갑니다.
3. "6+6 특례나 한부모·장애아 특례가 적용될까" 또는 "기간을 늘리면 얼마나 더 받을까" 고민이 있다면 **특례적용_재계산기**로 4가지 시나리오를 비교합니다.
4. **의뢰접수_고객리포트_템플릿**으로 의뢰를 접수하고, 계산 결과를 고객용 리포트로 정리해 전달합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·체크리스트·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 통상임금·휴직 조건을 넣어보고, 고용24(work24.go.kr)의 모의계산·고시 기준과 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "육아휴직급여", "출산휴가급여"라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 지급액이 아니라 **참고용 추정 계산 도구**입니다. 출산전후휴가급여·육아휴직급여의 지급률·상한액·하한액·6+6 특례·한부모·장애아 특례 조건은 저출생 대책 등 정책 개편으로 자주 바뀌므로, 실제 적용 전 반드시 고용24(work24.go.kr), 고용노동부 고시로 최신 값을 재확인하세요. 통상임금 포함 항목 판단, 우선지원대상기업 여부, 6+6 특례의 "부모 각각 사용" 조건, 기간연장의 "부모 각각 3개월 이상" 조건처럼 계산기에 단순화되어 있거나 반영되지 않은 예외 규정은 해당 사례가 있을 때 반드시 수동으로 재확인해야 합니다. 이 부업은 고용센터·노무사의 고유 업무(실제 신청서 접수 대행, 이의신청 대행)를 대신하는 것이 아니라 사전 계산과 안내라는 점을 상담 시작 전 항상 명확히 안내해 오해를 예방해야 합니다.
