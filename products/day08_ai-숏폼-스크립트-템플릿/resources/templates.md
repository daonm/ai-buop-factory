# 숏폼/유튜브 스크립트 템플릿 30개

『그 영상, 3초 만에 넘겨졌습니다』를 읽은 다음날 바로 채우는 실전 워크북입니다. 5개 카테고리 × 6개씩, 대괄호 부분만 내 소재로 바꿔서 그대로 대본으로 쓰세요.

## 사용법
1. 이번 영상에 어울리는 카테고리 1개를 고른다 (아래 "카테고리 고르는 법" 참고).
2. 카테고리 안에서 소재에 맞는 템플릿 1개를 고른다.
3. 대괄호 `[ ]` 부분을 내 소재로 채운다.
4. 소리 내어 읽어보고 어색한 문장만 다듬는다. (전체를 새로 쓸 필요 없음)

### 카테고리 고르는 법
| 상황 | 추천 카테고리 |
|---|---|
| 정보/노하우를 정리해서 보여주고 싶다 | A. 정보·리스트형 |
| 내 경험이나 사례로 공감을 얻고 싶다 | B. 스토리텔링형 |
| 방법을 순서대로 따라하게 하고 싶다 | C. 튜토리얼형 |
| 흔한 통념을 뒤집어 주목받고 싶다 | D. 반박·논쟁형 |
| 댓글/질문에 답하며 소통하고 싶다 | E. Q&A·댓글형 |

## A. 정보·리스트형 (분석·정리가 강점일 때)

### A1. 넘버링 리스트형
적합 소재: 방법/이유/팁을 여러 개 나열할 때
```
[훅 0-3초] [주제] 딱 3가지만 알면 됩니다
[전환] 하나씩 보여드릴게요
[본론 1] 첫 번째, [항목1] — [한 줄 설명]
[본론 2] 두 번째, [항목2] — [한 줄 설명]
[본론 3] 세 번째, [항목3] — [한 줄 설명]
[CTA] 이 중에 오늘 하나만 적용해보세요, 팔로우하면 나머지도 이어집니다
```

### A2. 랭킹형
적합 소재: 여러 옵션 중 순위를 매길 수 있을 때
```
[훅] [주제] 순위, 3위부터 공개합니다
[본론-3위] 3위는 [항목] — 이유는 [근거]
[본론-2위] 2위는 [항목] — 이유는 [근거]
[본론-1위] 1위는 [항목] — 이유는 [근거], (여기서 살짝 텀을 둔다)
[CTA] 여러분 순위는 다를 수 있어요, 댓글로 알려주세요
```

### A3. 비교표형
적합 소재: A vs B를 명확히 대조할 때
```
[훅] [A]랑 [B], 뭐가 다른지 30초 만에 정리했습니다
[본론 1] 가격 — [A는 얼마], [B는 얼마]
[본론 2] [비교 기준 2] — [A vs B]
[본론 3] 결론 — [어떤 상황엔 A, 어떤 상황엔 B]
[CTA] 나는 어느 쪽인지 댓글로 남겨주세요
```

### A4. 단계별 가이드형
적합 소재: 순서가 명확한 절차를 설명할 때
```
[훅] [결과]까지 딱 3단계입니다
[본론-1단계] [행동1] — [소요시간/주의점]
[본론-2단계] [행동2] — [소요시간/주의점]
[본론-3단계] [행동3] — [소요시간/주의점]
[CTA] 오늘 1단계만 지금 바로 해보세요
```

### A5. Before/After 수치형
적합 소재: 구체적 변화량(숫자)이 있을 때
```
[훅] [과거 수치] → [현재 수치], 뭘 바꿨는지 알려드립니다
[본론 1] 원래는 [Before 상황]이었습니다
[본론 2] 이걸 [핵심 변화 1개]로 바꿨습니다
[본론 3] 그 결과 [After 수치/결과]가 됐습니다
[CTA] 방법이 궁금하면 팔로우, 다음 편에서 자세히 다룹니다
```

### A6. 실수 모음형
적합 소재: 초보자가 자주 하는 실수를 짚을 때
```
[훅] [주제]할 때 다들 이 실수 하나씩은 합니다
[본론 1] 첫 번째 실수 — [실수1], 이러면 [부작용]
[본론 2] 두 번째 실수 — [실수2], 이러면 [부작용]
[본론 3] 세 번째 실수 — [실수3], 이러면 [부작용]
[CTA] 세 개 중에 해당하는 거 있으면 댓글로 몇 번인지 남겨주세요
```

## B. 스토리텔링형 (경험·서사가 강점일 때)

### B1. 실패담 반전형
적합 소재: 실패에서 배운 교훈이 있을 때
```
[훅] 저 이것 때문에 [위기 상황] 겪었습니다
[본론 1] 처음엔 [무엇을 잘못했는지] 이렇게 하고 있었어요
[본론 2] 그러다 [전환점이 된 사건/발견]
[본론 3] 그래서 [바꾼 행동], 결과는 [반전 결과]
[CTA] 저처럼 헤매지 마시고 이 방법부터 해보세요
```

### B2. 하루 압축형
적합 소재: 루틴/일상을 짧게 보여줄 때
```
[훅] 제 [직업/역할]의 하루, 30초로 압축했습니다
[본론-아침] [시간대1] — [행동/장면]
[본론-낮] [시간대2] — [행동/장면]
[본론-저녁] [시간대3] — [행동/장면]
[CTA] 이런 하루가 궁금하시면 팔로우, 매주 올립니다
```

### B3. 고객 사례형
적합 소재: 실제 사례(본인 동의 후)를 공유할 때
```
[훅] 실제로 이런 분이 계셨습니다
[본론 1] [고객/사례자]가 겪던 문제는 [문제 상황]
[본론 2] 함께 [진행한 과정 요약]
[본론 3] 결과는 [구체적 결과]
[CTA] 비슷한 고민이면 프로필 링크에서 확인해보세요
```

### B4. 과거의 나에게형
적합 소재: 시행착오를 겪고 지금은 노하우가 쌓였을 때
```
[훅] 1년 전 저에게 이걸 알려주고 싶습니다
[본론 1] 그때 저는 [과거 상황]이었어요
[본론 2] 근데 아무도 [지금 알려줄 핵심 정보]를 안 알려줬어요
[본론 3] 그래서 지금 저처럼 되기까지 [걸린 시간/과정]
[CTA] 지금 시작하는 분들은 저보다 빨리 가시면 좋겠어요, 팔로우하고 같이 가요
```

### B5. 갈등-해결형
적합 소재: 문제 상황과 해결 과정을 극적으로 보여줄 때
```
[훅] [문제 상황] 때문에 진짜 힘들었습니다
[본론 1] 원인을 찾아보니 [원인]이었어요
[본론 2] [시도한 해결책 1] 해봤는데 [결과]
[본론 3] 결국 [진짜 해결책]으로 해결했습니다
[CTA] 같은 문제 겪고 계시면 댓글 남겨주세요, 하나씩 답해드릴게요
```

### B6. 비하인드 공개형
적합 소재: 결과물이 나오기까지의 과정을 보여줄 때
```
[훅] [결과물], 사실 이렇게 만들어졌습니다
[본론 1] 처음 아이디어는 [시작점]
[본론 2] 만드는 중에 [예상 못한 어려움]
[본론 3] 그래서 [해결 방법], 완성까지 [소요 기간]
[CTA] 완성본은 프로필 링크에서 확인하실 수 있어요
```

## C. 튜토리얼형 (방법·노하우를 순서대로 보여줄 때)

### C1. 화면녹화 따라하기형
적합 소재: 앱/툴 사용법
```
[훅] 이 화면 그대로만 따라 누르시면 됩니다
[본론-1] 먼저 [메뉴/버튼 위치]를 누릅니다 (자막: 여기 클릭)
[본론-2] 그다음 [설정값/입력값]을 넣습니다 (자막: 이렇게 입력)
[본론-3] 마지막으로 [실행 버튼]을 누르면 끝입니다
[CTA] 안 되시는 분은 댓글에 어느 단계인지 남겨주세요
```

### C2. 도구 추천+사용법형
적합 소재: 특정 도구/앱을 소개할 때
```
[훅] 이 도구 하나면 [문제]가 해결됩니다
[본론 1] [도구명] 소개 — [핵심 기능 1줄]
[본론 2] 사용법은 이렇게 [핵심 사용 단계 2~3개]
[본론 3] 무료/유료 구간은 [가격 정보]
[CTA] 링크는 프로필에 있습니다
```

### C3. 실수 방지 체크형
적합 소재: 시작 전에 반드시 확인해야 할 것이 있을 때
```
[훅] [행동] 하기 전에 이것부터 확인하세요
[본론 1] 첫 번째 확인 — [체크포인트1]
[본론 2] 두 번째 확인 — [체크포인트2]
[본론 3] 이거 놓치면 [발생할 문제]
[CTA] 확인 다 하셨으면 이제 시작해도 됩니다, 다음 편에서 이어갈게요
```

### C4. 5분 완성형
적합 소재: 짧은 시간 안에 끝낼 수 있는 작업
```
[훅] 5분 안에 [결과물] 완성하는 법
[본론-0~2분] [단계1]
[본론-2~4분] [단계2]
[본론-4~5분] [단계3], 완성
[CTA] 저장해두고 따라해보세요
```

### C5. 초보자용 A-Z형
적합 소재: 아예 모르는 사람을 위한 전체 흐름 안내
```
[훅] [주제], 하나도 모르는 분들을 위해 처음부터 정리했습니다
[본론-준비] 시작 전 필요한 건 [준비물/조건]
[본론-실행] 실행 순서는 [핵심 흐름 요약]
[본론-완성] 완성 기준은 [완료 조건]
[CTA] 저장하고 하나씩 따라오세요, 궁금한 건 댓글로
```

### C6. 시간 단축 꿀팁형
적합 소재: 기존 방법보다 빠른 방법이 있을 때
```
[훅] 이거 하나로 [작업]하는 시간 반으로 줄었습니다
[본론 1] 원래 방법은 [기존 방식], [소요 시간]
[본론 2] 바꾼 방법은 [새 방식]
[본론 3] 결과는 [단축된 시간/효율]
[CTA] 방법 궁금하시면 링크 눌러보세요
```

## D. 반박·논쟁형 (통념을 뒤집어 주목을 끌 때)

### D1. 통념 반박형
적합 소재: 흔히 알려진 상식이 틀렸을 때
```
[훅] [흔한 상식], 사실은 틀렸습니다
[본론 1] 다들 [통념 내용]이라고 알고 있죠
[본론 2] 근데 실제로는 [반박 근거/데이터]
[본론 3] 맞는 방법은 [올바른 정보]
[CTA] 이거 모르고 계셨던 분, 좋아요 눌러주세요
```

### D2. 경고형
적합 소재: 위험/손해를 미리 알려줄 때
```
[훅] [행동] 하기 전에 이것부터 보세요
[본론 1] 이렇게 하면 [위험/손해]가 생깁니다
[본론 2] 이유는 [원인 설명]
[본론 3] 대신 [대안 행동]을 하세요
[CTA] 이미 하고 계셨다면 지금 확인해보세요
```

### D3. 찬반 비교형
적합 소재: 논쟁이 있는 주제를 다룰 때
```
[훅] [주제], 해야 할까요 말아야 할까요
[본론-찬성] 찬성 쪽 근거는 [근거1]
[본론-반대] 반대 쪽 근거는 [근거2]
[본론-결론] 제 결론은 [입장], 이유는 [핵심 근거]
[CTA] 여러분 생각은 다를 수 있어요, 댓글로 알려주세요
```

### D4. 전문가 vs 일반인형
적합 소재: 전문가와 일반인의 접근이 다를 때
```
[훅] [분야] 전문가는 이거 절대 안 합니다
[본론 1] 일반인은 보통 [일반적 행동]을 합니다
[본론 2] 근데 전문가는 [다른 접근]을 합니다
[본론 3] 차이는 [핵심 이유]에서 나옵니다
[CTA] 오늘부터 전문가처럼 해보세요
```

### D5. 트렌드 비판형
적합 소재: 요즘 유행하는 방식의 위험성을 짚을 때
```
[훅] 요즘 다들 이렇게 하는데, 사실 위험합니다
[본론 1] 최근 유행하는 방식은 [트렌드 내용]
[본론 2] 문제는 [위험 요소/부작용]
[본론 3] 안전하게 하려면 [대안]
[CTA] 하고 계셨다면 이 부분만 바꿔보세요
```

### D6. 오해 바로잡기형
적합 소재: 흔한 오해 때문에 손해 보는 사람이 많을 때
```
[훅] 이 오해 때문에 [손해/시간낭비] 하시는 분 많습니다
[본론 1] 흔한 오해는 [오해 내용]
[본론 2] 실제로는 [진실]
[본론 3] 그래서 이렇게 하시면 됩니다 [올바른 행동]
[CTA] 주변에 이거 모르는 분 있으면 공유해주세요
```

## E. Q&A·댓글형 (소통·시리즈 지속에 강점일 때)

### E1. 댓글 답변형
적합 소재: 실제로 받은 질문에 답할 때
```
[훅] 이 질문 진짜 많이 받았어요 — "[질문 원문]"
[본론 1] 결론부터 말씀드리면 [핵심 답변]
[본론 2] 자세히는 [부연 설명]
[본론 3] 예외가 있다면 [예외 상황]
[CTA] 다른 질문 있으면 댓글 남겨주세요, 다음 편에서 다룹니다
```

### E2. 자주 묻는 질문 모음형
적합 소재: 반복되는 질문 여러 개를 한 번에 정리할 때
```
[훅] 가장 많이 물어보시는 3가지, 한 번에 정리합니다
[본론-Q1] "[질문1]?" → [답변1]
[본론-Q2] "[질문2]?" → [답변2]
[본론-Q3] "[질문3]?" → [답변3]
[CTA] 더 궁금한 거 있으면 댓글로 물어봐주세요
```

### E3. 팔로워 고민 상담형
적합 소재: 특정 고민을 가진 사람들에게 직접 말을 걸 때
```
[훅] [고민 상황] 있으신 분?
[본론 1] 저도 똑같이 [공감 포인트] 겪어봤어요
[본론 2] 제가 한 방법은 [해결 방법]
```

## 실전 체크리스트

**오늘, 30분**
- [ ] 카테고리 고르는 법 표 보고 오늘 영상에 맞는 카테고리 1개 정하기
- [ ] 그 안에서 소재에 맞는 템플릿 1개 선택
- [ ] 대괄호 채워서 초안 1개 완성

**이번 주, 1차 완성**
- [ ] 완성한 대본을 소리 내어 읽고 시간 재보기
- [ ] 맞는 길이(15/30/60초) 워크시트에 씬 나누기
- [ ] 촬영·편집 후 업로드

**이번 달, 확장**
- [ ] 반응 좋았던 템플릿 카테고리를 파악해서 다음 소재도 같은 카테고리로 우선 시도
- [ ] 5개 카테고리를 최소 한 번씩은 다 써보고 내 채널에 맞는 톤 찾기
- [ ] 반응 좋은 템플릿 2~3개를 골라 시리즈로 묶어 반복 사용
