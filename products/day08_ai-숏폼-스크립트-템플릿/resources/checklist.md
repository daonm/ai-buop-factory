# 숏폼 스크립트 실전 체크리스트

> `templates.md`와 `prompt_pack.md`를 실제로 촬영·업로드까지 끌고 가는 순서표입니다. 오늘 30분 → 이번 주 1차 완성 → 이번 달 확장, 3단계로 나눴습니다.

## 오늘 · 30분

- [ ] "카테고리 고르는 법" 표 보고 오늘 영상에 맞는 카테고리 1개 정하기 (`templates.md`)
- [ ] 그 안에서 소재에 맞는 템플릿 1개 선택
- [ ] `prompt_pack.md`의 P0 또는 해당 카테고리 프롬프트로 대괄호 채워서 초안 1개 완성

## 이번 주 · 1차 완성

- [ ] 완성한 대본을 소리 내어 읽고 실제 발화 시간 재보기 (F-P1 프롬프트로 다듬기)
- [ ] 길이에 맞는 촬영 워크시트(15초/30초/60초)에 씬별 시간·화면 지시 채우기
- [ ] 무료 편집 도구(캡컷, 브루 등) 1개로 촬영·편집
- [ ] 첫 프레임/제목이 대본의 훅 문구와 어긋나지 않는지 확인 후 업로드

## 이번 달 · 확장

- [ ] 5개 카테고리(정보·스토리·튜토리얼·반박·Q&A)를 최소 한 번씩 다 써보고 내 채널에 맞는 톤 찾기
- [ ] 반응(조회수·저장·댓글)이 좋았던 템플릿을 파악해서 다음 소재도 같은 카테고리로 우선 시도
- [ ] 반응 좋은 템플릿 2~3개를 골라 시리즈로 묶어 반복 사용

---

## 참고 — 씬 시간 배분 기준

```
15초 — 훅(0-3) → 본론(3-11) → CTA(11-15)
30초 — 훅(0-3) → 전환(3-5) → 본론 1(5-14) → 본론 2(14-23) → CTA(23-30)
60초 — 훅(0-3) → 전환(3-6) → 본론 1(6-22) → 본론 2(22-38) → 본론 3(38-54) → CTA(54-60)
```

훅은 길이와 상관없이 항상 3초 이내로 고정하세요. 늘어나면 그 순간 이탈이 시작됩니다.

디자인된 버전은 `kit.html`을 열어보세요.
