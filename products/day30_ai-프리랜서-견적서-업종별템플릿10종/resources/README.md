# AI 프리랜서 견적서 — 업종별 템플릿 10종 사용 가이드

『일은 잘하는데, 견적은 못 냅니다』(Day29 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다.

## 구성 파일

| 파일 | 내용 |
|---|---|
| `kit.html` | 업종 5개 카테고리 빠른 참고표 + 견적서 템플릿 10종 + 커스터마이징 프롬프트 10선 + 사용법 체크리스트를 한눈에 보기 좋게 디자인한 버전 (브라우저로 열거나 PDF로 인쇄) |
| `복사만_하면_되는_견적서_10장.pdf` | `kit.html`을 인쇄한 PDF 버전 (오프라인·인쇄용) |
| `업종별_견적서_템플릿_10종.md` | 디자인·개발·콘텐츠·마케팅·컨설팅 5개 카테고리, 업종 10개의 견적서 뼈대. 각 업종의 강조 포인트·흔한 실수·라인아이템·참고 단가 레인지 포함, 표 그대로 복사해 엑셀·노션에 붙여넣는 용도 |
| `업종별_커스터마이징_프롬프트_10선.md` | 업종별 뼈대를 내 실제 프로젝트에 맞게 다듬는 프롬프트 10개. Day29 전자책 프롬프트 16개와 겹치지 않는 신규 구성 |

## 4단계 사용법

1. **내 업종 템플릿 찾기** — `업종별_견적서_템플릿_10종.md`에서 5개 카테고리(크리에이티브·디자인 / 개발·기술 / 콘텐츠·언어 / 마케팅·비주얼 / 컨설팅·문서) 중 내 업종에 해당하는 표를 찾습니다. 겸업 중이라면 해당하는 표를 모두 확인하세요.
2. **표를 그대로 복사하기** — 표 전체를 엑셀·구글시트·노션 중 평소 쓰는 도구에 붙여넣습니다. "작업 항목"과 "비고"는 이미 업종에 맞게 채워져 있으니, "수량/일정"·"단가" 빈칸만 Day29 방법 4(단가 산정)에서 정한 내 기준으로 채웁니다.
3. **프롬프트로 다듬기** — `업종별_커스터마이징_프롬프트_10선.md`에서 같은 업종의 프롬프트를 찾아 실제 프로젝트 정보를 채워 넣고, AI에게 세부 문구(범위, 조건, 단가 산정 근거)를 다듬게 합니다.
4. **기본값 고정하기** — VAT·원천세·결제 조건처럼 프로젝트마다 크게 달라지지 않는 항목은 한 번 정한 기본값을 모든 견적서에 동일하게 적용해, 매번 새로 고민하지 않게 합니다.

전체 흐름을 놓치지 않으려면 `kit.html`의 체크리스트(업종 확인→표 복사→프롬프트 다듬기→기본값 고정→발송 4단계)를 견적서 작성 전부터 펼쳐두고 순서대로 체크하세요. 이 키트는 "업종별 뼈대"를 담당합니다 — "단가를 어떻게 정하고 어떻게 협상할지"는 Day29 전자책과 함께 보세요.
