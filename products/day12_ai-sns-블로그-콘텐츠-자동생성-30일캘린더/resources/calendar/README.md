# 30일 콘텐츠 캘린더 — 사용법

『그 글, AI가 대신 씁니다』(Day11 전자책)에서 소개한 12가지 방법을 실제 30일 일정으로 옮긴 실행용 스프레드시트입니다. 빈 채로 시작하지 않도록 채널·포맷·톤·목적까지 매일 칸을 미리 채워뒀고, "주제/후킹 문장"과 "상태", "조회수·반응"만 직접 채우면 됩니다.

## 1. 가져오기

- **구글 시트**: 새 스프레드시트 → 파일 → 가져오기 → `30일_콘텐츠_캘린더.csv` 업로드
- **엑셀**: 파일을 더블클릭하면 바로 열립니다 (UTF-8 CSV)
- **노션**: 아무 페이지 → `/csv` → CSV 가져오기 → 이 파일 선택 → 데이터베이스로 자동 변환

## 2. 열(컬럼) 설명

| 열 | 의미 |
|---|---|
| Day / 요일 / 주차 | 30일 고정 스케줄. 실제 시작일에 맞춰 "요일" 열만 필요하면 재배치하세요 |
| 채널 | 블로그 / 스레드 / 인스타그램 / 숏폼 / 뉴스레터 |
| 포맷 | 어떤 형태의 콘텐츠인지 (SEO 원문, 카드뉴스 대본, 요약 글 등) |
| 톤/유형 | 방법 4(SNS 톤 7가지)와 방법 6(후킹 패턴)에서 가져온 유형 |
| 목적 | 인지(도달) / 관심(참여) / 전환(구매·클릭) — 하루 콘텐츠가 어떤 역할인지 |
| 주제/후킹 문장 | **직접 채우는 칸.** 그 주 실제로 다룰 주제나 뽑아낸 후킹 문장을 적습니다 |
| 상태 | 초안 / 예약 / 발행완료 |
| 조회수·반응 | 발행 후 조회수/좋아요/댓글 수 — 방법 8(피드백 루프)의 원자재 |
| 다음 액션 | 반응을 보고 다음에 뭘 할지 (재발행, 톤 변경, 다음 캘린더 반영 등) |

## 3. 4주 흐름

1. **1주차 — 세팅**: 원소스 하나를 정해서 포맷별로 쪼개보는 주. 블로그 SEO 원문 하나로 시작해 스레드·카드뉴스로 리퍼포징합니다.
2. **2주차 — SNS 톤 순환**: 스레드 홍보 글을 7가지 톤으로 하루 하나씩 순환 발행합니다.
3. **3주차 — 블로그·SEO**: 검색 유입을 노리는 자산형 콘텐츠에 집중하고, 후킹 문장을 A/B로 실험합니다.
4. **4주차 — 분석·확장**: 반응 데이터를 모아 잘된 패턴을 재발행하고, 월간 회고로 다음 달 캘린더를 새로 설계합니다.

## 4. 막힐 때

이 캘린더의 각 칸은 `../../ebook 대신 kit.html`의 "프롬프트 30선"과 짝지어 설계했습니다. 예를 들어 "주제/후킹 문장" 칸이 안 채워지면 `kit.html`의 **B그룹(SNS 톤·후킹)** 프롬프트를 그대로 복사해서 클로드에 붙여넣으세요.
