# AI 창업 초기비용·손익분기점 계산 대행 — 계산기 + 사업자등록 체크리스트 템플릿팩 사용 가이드

『회계사가 아니어도, 창업 손익분기점은 계산해드립니다』(Day37 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 2·3·4·5·6·7(초기비용 견적·손익분기점·목표순이익 역산·인건비/4대보험·대출상환 현금흐름·사업자유형 비교)을 이미 끝내둔 완성본 엑셀 계산기 4종 + 사업자등록 체크리스트를 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 엑셀 파일 공통 구조

계산기 4종 모두 같은 구조로 만들었습니다.

1. **안내 시트** — "참고용 계산 도구이며 사업 성공을 보장하는 자문을 대신하지 않는다"는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **기준표(사업자유형 비교 계산기 안에 포함)** — 종합소득세 누진세율표처럼 자주 바뀌는 정보를 계산기 시트 안에 함께 정리했습니다(2026년 9월 확인 기준). 기준이 바뀌면 해당 표만 새로 갱신하면 됩니다.
3. **계산기 시트** — 노란색 칸에 숫자를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`사업자등록_체크리스트.xlsx`는 계산 파일이 아니라 진행 체크용 표입니다. 완료 열(노란 칸)에 O나 완료일을 적어가며 사용하세요.

## 계산기 4종을 잇는 순서

1. **초기비용 견적 계산기**로 상담 대상의 업종에 맞는 총 초기비용(예비비·운영자금 포함)을 먼저 뽑습니다.
2. **손익분기점·목표매출 계산기**로 하루 얼마를 팔아야 본전인지, 목표 순이익을 위해 얼마를 팔아야 하는지 보여줍니다. 이때 ①의 총 초기비용을 투자금 회수기간 계산에 그대로 입력합니다.
3. 직원을 고용하거나 대출을 낀 상황이라면 **인건비·대출상환 현금흐름표**로 진짜 고정비를 다시 계산하고, 그 값을 ②의 월 고정비에 다시 넣어 새 손익분기점을 구합니다.
4. 사업자 유형을 아직 정하지 못했다면 **사업자유형 비교 계산기**로 세금·설립비용 차이를 보여줍니다.
5. 등록을 진행할 단계가 되면 **사업자등록 체크리스트**를 펼쳐 순서대로 진행합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기 4종 훑어보기** — 어떤 계산기가 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 상담 대상) 조건으로 직접 테스트하기** — `kit.html`의 Worksheet 2(교차검증)를 참고해 실제 엑셀 파일에 실제 창업 조건을 넣어보고, 실제 견적서·홈택스 고시 세율과 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트/상담 가격을 정한 뒤, 상품명에 "계산기", "손익분기점", "창업"이라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 사업·세무·법률 자문이 아니라 **참고용 계산 도구**입니다. 세율·요율·간이과세 기준금액·법인 설립비용은 정책과 지역에 따라 자주 바뀌므로, 실제 상담이나 판매에 사용하기 전 반드시 최신 정보로 재확인하세요. 최종 의사결정(창업 여부, 사업자 유형 선택)은 항상 고객 본인의 몫으로 남겨두어야 합니다.
