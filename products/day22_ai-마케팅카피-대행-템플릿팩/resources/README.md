# AI 마케팅 카피 대행 — 업종별 카피 템플릿팩 사용 가이드

『팔리는 문장, 재능이 아니라 공정입니다』(Day21 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다.

## 구성 파일

| 파일 | 내용 |
|---|---|
| `kit.html` | 업종 5개의 상세페이지·SNS·이메일 카피 예시 + 브리프 인터뷰·톤앤매너 워크시트 + 검수·납품 체크리스트를 한눈에 보기 좋게 디자인한 버전 (브라우저로 열거나 PDF로 인쇄) |

| `카피_검수_납품_체크리스트.md` | 브리프 → 채널별 초안 생성 → 검수 → 납품·사후관리까지 순서대로 확인하는 4단계 체크리스트 |

## 3단계 사용법

1. **가장 비슷한 업종 고르기** — `업종별_카피_템플릿_전체모음.md`에서 내 클라이언트(또는 내가 운영하는 매장)와 가장 가까운 업종 하나를 고릅니다. 업종 5개는 2026년 크몽이 우선 전문관으로 도입한 병원·뷰티·오픈마켓·자사몰과 향후 확대 예정인 F&B 분야를 기준으로 소상공인 카피 의뢰가 많은 업종을 골랐습니다. 5개에 없는 업종은 문서 맨 아래 매칭표를 참고하세요.
2. **구조는 그대로, 내용만 교체** — 상세페이지 4단계(문제 제기 → 해결 → 근거 → 행동 유도) 구조와 SNS·이메일의 후킹 방식은 그대로 두고, 숫자와 구체적 디테일만 클라이언트 정보로 바꿔치기합니다.
3. **브리프 인터뷰로 디테일 채우기** — `브리프인터뷰_톤앤매너_워크시트.md`로 클라이언트를 인터뷰한 내용을 채워 넣으면 예시 카피가 실제 납품용 카피로 바뀝니다.

전체 진행 순서를 놓치지 않으려면 `카피_검수_납품_체크리스트.md`를 브리프 인터뷰 시작 전부터 펼쳐두고 순서대로 체크하세요.
