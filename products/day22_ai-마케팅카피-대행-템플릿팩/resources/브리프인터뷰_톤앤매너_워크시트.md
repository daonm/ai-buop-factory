# 브리프 인터뷰 & 톤앤매너 워크시트

예시 카피를 실제 납품용으로 바꾸기 전, 아래 3개 워크시트부터 채우세요. (`kit.html`에 채워 쓸 수 있는 디자인 버전이 있습니다.)

## Worksheet 1 — 클라이언트 브리프 인터뷰 시트

| 질문 | 클라이언트 답변 |
|---|---|
| 제품/서비스의 핵심 특징은? | |
| 가장 많이 받는 재구매·재방문 후기는? | |
| 경쟁사와 다른 점은? | |
| 지금 가장 팔고 싶은 상품/시즌 메뉴는? | |
| 고객이 구매를 망설이는 이유는? | |
| 내세울 수 있는 숫자(재구매율, 후기 수 등)는? | |
| 절대 쓰면 안 되는 표현/톤은? | |

답변은 클라이언트의 표현을 그대로 적으세요 — 그 말투가 카피의 진짜 재료입니다.

## Worksheet 3 — 패키지·견적 계산기

| 패키지 유형 | 가격대 | 내 견적 |
|---|---|---|
| 카피 1건 (SNS 캡션 또는 이메일 제목·본문) | 15,000~30,000원 | |
| 채널 세트 (상세페이지+SNS+이메일) | 50,000~90,000원 | |
| 브랜드 톤 진단 + 카피 세트 | 120,000~180,000원 | |
| 월 구독형 카피 관리 | 200,000원~/월 | |

첫 5건은 후기 확보 목적으로 표시가 대비 낮게 잡는 것도 방법입니다.
