# 템플릿 사용 순서

이 폴더에는 3개 파일이 있습니다. 다음 순서로 사용하세요.

1. **`업종별_핵심지표_정의표.csv`** — 먼저 엽니다. 엑셀·구글시트·노션에 바로 열립니다. 고객 업종에 맞는 행을 찾아 핵심지표·추천차트를 확인합니다.
2. **`리포트_표준_템플릿.md`** — 복사해서 `리포트_[고객명]_[연월].md`로 저장합니다. 1번에서 확인한 핵심지표를 "2. 핵심 지표" 표에 그대로 옮겨 시작합니다.
3. **`예시_리포트_카페매출.md`** — 표준 템플릿을 실제로 다 채우면 어떤 완성도가 되는지 보여주는 견본입니다. 2번 작업 중 막히면 참고하세요. 첫 고객에게 포트폴리오로 보여줘도 됩니다(가상 데이터임을 명시).

각 파일의 대괄호 `[ ]` 부분만 실제 데이터로 채우면 됩니다. 목차·순서는 절대 바꾸지 마세요 — 매번 목차가 바뀌면 다음 달에 "표준 템플릿에 새 데이터만 흘려보내는" 정기 리포트 자동화가 불가능해집니다.
