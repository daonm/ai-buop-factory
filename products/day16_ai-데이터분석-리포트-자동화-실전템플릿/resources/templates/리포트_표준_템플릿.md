# 데이터 분석 리포트 표준 템플릿

『그 엑셀, 아무도 안 읽습니다』방법 1~8을 그대로 문서 구조로 옮긴 표준 템플릿입니다.
새 고객이 들어올 때마다 이 파일을 복사해서 `[대괄호]` 부분만 채우세요. 목차·순서는 그대로 유지하는 것이 핵심입니다 — 목차가 매번 바뀌면 정기 리포트로 자동화할 수 없습니다.

---

## 사용 순서

1. 이 파일을 복사해 `리포트_[고객명]_[연월].md`로 저장한다.
2. 원본 데이터를 AI에게 주고 프롬프트 A1(원본 데이터 정리)로 정제한다.
3. 프롬프트 B1(핵심 지표 추출)로 아래 "2. 핵심 지표" 표를 채운다.
4. 프롬프트 C1(리포트 초안 생성)로 "4. 인사이트"와 "5. 액션 아이템"을 채운다.
5. 프롬프트 D1(검증)로 숫자를 교차 검토한 뒤 고객에게 전달한다.

각 프롬프트 번호는 `../marketing/../resources/kit.html`의 프롬프트팩과 동일한 번호 체계입니다.

---

## 표지

- 리포트 제목: [예: 2026년 9월 매출 리포트]
- 대상: [고객명/업체명]
- 리포트 유형: [매출 / 마케팅 성과 / 설문·피드백 / SNS·콘텐츠]
- 분석 기간: [YYYY-MM-DD ~ YYYY-MM-DD]
- 작성일: [YYYY-MM-DD]
- 데이터 출처: [POS 정산 엑셀 / 쇼핑몰 관리자 페이지 / 광고 성과표 등]

## 1. 한 줄 요약 (헤드라인)

> [숫자를 포함한 한 문장. 예: "9월 매출은 전월 대비 12% 늘었지만, 화요일 매출만 3주 연속 평균보다 낮았습니다."]

## 4. 인사이트 (왜 이런 숫자가 나왔는가)

각 인사이트는 **숫자 + 원인 추정 + 근거**의 3단 구조로 작성합니다.

1. [숫자] → [원인 추정] → [근거: 최근 N주/개월 동일 패턴 확인 등]
2. [숫자] → [원인 추정] → [근거]
3. [숫자] → [원인 추정] → [근거]

> 주의 — 데이터로 뒷받침되지 않는 추측은 "~로 추정됩니다", "추가 확인이 필요합니다"로 표현합니다. 확신을 과장하지 않습니다.
