# 카카오톡 챗봇 빌더 세팅 체크리스트

FAQ 스크립트가 준비된 다음, 실제 빌더 화면에 옮겨 심을 때 순서대로 체크하세요.

## 세팅 전 준비
- [ ] 카카오톡 채널 관리자센터 계정 로그인, 챗봇 관리 메뉴 진입
- [ ] 업종에 맞는 FAQ 스크립트 섹션 선택 (`FAQ_스크립트_전체모음.md`)
- [ ] `이관규칙_및_톤앤매너_워크시트.md` 로 원본 정보(가격/시간/정책) 확정
- [ ] `[ ]` 표시된 부분을 실제 값으로 전부 교체 완료

## 시나리오 등록
- [ ] 인사말 블록 생성 (버튼 3~4개: 카테고리별 진입점)
- [ ] 카테고리별 발화 블록 등록 (FAQ 15개 → 발화 15개, 카테고리로 그룹핑)
- [ ] 각 발화에 대응하는 응답 스크립트 붙여넣기 (3~4줄 유지)
- [ ] 응답 끝마다 "다음 행동 버튼" 연결 (추가 질문 / 상담원 연결 / 예약 링크)
- [ ] 이관 조건에 해당하는 발화는 "상담원 연결" 버튼으로 연결, 폴백 블록도 동일하게 설정

## 테스트 (오픈 전 필수)
- [ ] 본인 카카오톡 계정으로 인사말부터 끝까지 직접 대화해보기
- [ ] FAQ 문장을 오타·줄임말·반말로 다시 물어봐도 인식되는지 확인
- [ ] 시나리오에 없는 질문을 일부러 던져 상담원 이관 버튼이 정상적으로 뜨는지 확인
- [ ] 버튼 3단계를 끝까지 눌러보며 막다른 길(더 진행 안 되는 화면)이 없는지 점검
- [ ] 시나리오를 모르는 지인에게 테스트 요청 (본인은 정답을 알아서 오류를 못 봄)

## 오픈 후 운영
- [ ] 오픈 첫 며칠은 "챗봇 응답 + 사람 확인" 병행 운영
- [ ] 1~2주 후 실제 대화 로그 확인, 이탈 많은 분기 파악
- [ ] FAQ에 없던 반복 질문 발견 시 새 항목으로 추가
- [ ] 이관율이 유독 높은 항목의 스크립트 재점검·수정
- [ ] 개선 주기를 "오픈 후 2주, 이후 매달 1회"로 캘린더에 등록
