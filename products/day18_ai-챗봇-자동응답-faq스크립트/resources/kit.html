시나리오를 처음부터 설계하는 게 챗봇 세팅에서 가장 오래 걸리는 부분입니다. 이 키트는 그 부분을 이미 끝내둔 상태로 시작하게 해줍니다.

업종 5개(카페·음식점 / 온라인 쇼핑몰 / 학원·클래스 / 병원·전문 서비스 / 미용실·뷰티샵)의 FAQ와 응답 스크립트를 이미 완성해뒀습니다. 세팅 순서는 다음과 같습니다.

  1. 워크시트로 이관 규칙·톤 확정 — 내 업종의 이관 조건과 원본 정보(가격·시간·정책)를 정리합니다.
  2. 스크립트 복사 — 가장 가까운 업종 섹션을 찾아 [ ] 부분만 실제 값으로 바꿉니다.
  3. 체크리스트로 세팅 — 카카오톡 챗봇 빌더에 순서대로 옮기고 테스트합니다.

주의 — [ ] 부분은 반드시 사장님이 준 원본 정보로 채우세요. 가격·환불·영업시간처럼 틀리면 분쟁이 되는 정보를 AI가 추측해서 채우면 안 됩니다.

03카카오톡 빌더 세팅 체크리스트

FAQ 스크립트가 준비된 다음, 실제 빌더 화면에 옮겨 심을 때 순서대로 체크하세요.

준비세팅 전 준비

  • 카카오톡 채널 관리자센터 로그인, 챗봇 관리 메뉴 진입
  • 업종에 맞는 FAQ 스크립트 섹션 선택
  • 워크시트로 원본 정보(가격·시간·정책) 확정
  • [ ] 표시 부분을 실제 값으로 전부 교체

등록시나리오 등록

  • 인사말 블록 생성 (버튼 3~4개: 카테고리별 진입점)
  • 카테고리별 발화 블록 등록
  • 각 발화에 응답 스크립트 붙여넣기 (3~4줄 유지)
  • 응답 끝마다 다음 행동 버튼 연결
  • 이관 조건 발화 → 상담원 연결·폴백 블록 설정

테스트오픈 전 필수 테스트

  • 본인 계정으로 인사말부터 끝까지 직접 대화
  • 오타·줄임말·반말로 다시 물어봐도 인식되는지 확인
  • 시나리오에 없는 질문으로 이관 버튼 확인
  • 버튼 3단계 끝까지 눌러 막다른 길 점검
  • 시나리오 모르는 지인에게 테스트 요청

운영오픈 후 운영

  • 오픈 첫 며칠 "챗봇 응답 + 사람 확인" 병행
  • 1~2주 후 대화 로그 확인, 이탈 많은 분기 파악
  • 반복되는 새 질문 FAQ에 추가
  • 이관율 높은 항목 스크립트 재점검
  • 개선 주기(2주 후, 이후 매달 1회) 캘린더 등록
