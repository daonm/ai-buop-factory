# AI 챗봇/자동응답 FAQ 시나리오 스크립트 모음 — 사용 가이드

『문의는 24시간, 사장님은 아닙니다』(Day17 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다.

## 구성 파일

| 파일 | 내용 |
|---|---|
| `kit.html` | 5개 업종 FAQ 스크립트 + 워크시트 + 세팅 체크리스트를 한눈에 보기 좋게 디자인한 버전 (브라우저로 열거나 PDF로 인쇄) |
| `FAQ_스크립트_전체모음.md` | 카페·음식점 / 온라인 쇼핑몰 / 학원·클래스 / 병원·전문 서비스 / 미용실·뷰티샵 — 업종별 FAQ 15개, 대화 흐름도, 응답 스크립트, 이관 조건 (복사해서 바로 빌더에 붙여넣기용) |
| `이관규칙_및_톤앤매너_워크시트.md` | 내 업종에 맞게 이관 조건·톤앤매너·원본 정보를 정리하는 빈칸 워크시트 |
| `카카오톡_빌더_세팅_체크리스트.md` | 세팅 전 준비 → 시나리오 등록 → 테스트 → 오픈 후 운영까지 순서대로 확인하는 체크리스트 |

## 3단계 사용법

1. **워크시트 먼저** — `이관규칙_및_톤앤매너_워크시트.md`를 채워 내 업종의 이관 조건과 원본 정보(가격·시간·정책)를 확정합니다.
2. **스크립트 복사** — `FAQ_스크립트_전체모음.md`에서 가장 가까운 업종 섹션을 찾아 `[ ]` 부분을 1번에서 정리한 실제 값으로 교체합니다.
3. **체크리스트로 세팅** — `카카오톡_빌더_세팅_체크리스트.md` 순서대로 빌더에 옮기고 테스트합니다.

다른 업종(카페·쇼핑몰·학원·병원·미용실 외)이라면 구조가 가장 비슷한 섹션을 골라 카테고리 이름만 바꿔 쓰면 됩니다 — FAQ 구조(영업정보/상품·서비스/결제·환불/기타)는 업종과 무관하게 재사용 가능합니다.
