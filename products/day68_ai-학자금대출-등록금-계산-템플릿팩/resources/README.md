# AI 학자금대출·등록금 계산 대행 — 계산기 + 상환전략 템플릿팩 사용 가이드

『등록금 고지서 받기 전에, AI한테 먼저 물어보세요』(Day67 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~12(국가장학금 소득분위 추정, 대출 종류 비교, ICL·일반상환 상환액 계산, 등록금 반환·휴학 규정 점검, 총부채 시뮬레이션, 상환 유예·절감 전략)를 이미 끝내둔 완성본 엑셀 계산기 3종·엑셀 상환전략 체크리스트 1종·워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 구성 파일

| 파일 | 내용 |
|---|---|
| `kit.html` | 계산기·체크리스트·템플릿 5종 빠른 참고표(입력·결과 예시) + 검증 워크시트 + 상담 진행 체크리스트 + 판매 준비 체크리스트를 한눈에 보기 좋게 디자인한 버전 (브라우저로 열거나 PDF로 인쇄) |
| `등록금고지서받기전에_AI한테먼저물어보세요_실행키트.pdf` | `kit.html`을 인쇄한 PDF 버전 (오프라인·인쇄용) |
| `국가장학금_소득분위_등록금실부담액_계산기.xlsx` | 가구 월 소득인정액과 기준중위소득(4인가구 기준)을 입력하면 소득인정액 비율로 학자금 지원구간(1~10구간)을 추정 판정하고, 구간별 연간 지원 단가를 등록금 총액과 비교해 국가장학금 지원 추정액과 실부담 등록금까지 자동 계산 |
| `학자금대출_상환액_비교_계산기.xlsx` | 연간 소득을 입력하면 취업후상환학자금대출(ICL)의 상환기준소득(3,037만 원) 초과분×상환율(20%/25%)로 연간 의무상환액을, 대출총액·금리(1.7%)·상환기간을 입력하면 일반상환의 월 상환액·총이자를 각각 계산하고 현재 소득 기준 유불리까지 자동 비교 |
| `졸업시점_총학자금부채_시뮬레이션_계산기.xlsx` | 남은 학기 수와 학기당 등록금·생활비 대출 예정액을 입력하면 졸업 시점까지 쌓일 총 대출 예상액을 계산하고, 일반상환 기준 월 상환액·총이자까지 자동 추정 |
| `등록금반환_휴학복학_상환전략_체크리스트.xlsx` | 학기 개시일·반환사유 발생일을 입력하면 경과일수로 반환비율·예상 반환액을 자동 계산하고, 졸업(예정)일을 입력하면 연체정보 등록유예 D-day를 자동 계산하는 'D-day계산기' 시트 + 신입생·재학생대출·졸업예정자·반환휴학 시나리오 13개 항목을 준비 상태 드롭다운으로 정리한 '체크리스트' 시트 |
| `의뢰접수_고객리포트_템플릿.docx` | 의뢰 접수 질문지(14문항) + 기준값·한도 체크(5개) + 고객용 예상 학자금 리포트 템플릿(9단계) + 서비스 안내·가격 템플릿까지 대괄호만 바꿔서 바로 쓰는 문서 |

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 지원·상환액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`국가장학금_소득분위_등록금실부담액_계산기.xlsx`는 소득인정액 하한 기준 구간표(별도 시트)를 참조해 지원구간을 자동 판정하고, `등록금반환_휴학복학_상환전략_체크리스트.xlsx`는 D-day계산기 시트(학기 개시일·반환사유 발생일 입력→반환비율·반환액 자동 계산, 졸업일 입력→연체정보 등록유예 D-day 자동 계산)와 반환비율표 시트, 체크리스트 시트(시나리오별 점검 항목 드롭다운)로 구성되고, `의뢰접수_고객리포트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 쓰는 문서입니다.

## 계산기·체크리스트·템플릿을 잇는 순서

1. **국가장학금_소득분위_등록금실부담액_계산기**로 소득인정액과 등록금 총액부터 입력해, 추정 지원구간과 학기당 실부담 등록금을 확인합니다.
2. 실부담 등록금만으로 부족해 대출이 필요하다면 **학자금대출_상환액_비교_계산기**로 넘어가 ICL과 일반상환 중 현재 소득 기준 유불리를 비교합니다.
3. 여러 학기에 걸쳐 대출을 받을 계획이라면 **졸업시점_총학자금부채_시뮬레이션_계산기**로 남은 학기 수 기준 총 대출 예상액과 상환 시나리오까지 계산합니다.
4. 반환사유(자퇴·미등록)나 휴학 계획이 있다면, 또는 졸업을 앞두고 있다면 **등록금반환_휴학복학_상환전략_체크리스트**로 반환액·연체정보 등록유예 D-day와 시나리오별 체크포인트를 점검합니다.
5. **의뢰접수_고객리포트_템플릿**으로 의뢰를 접수하고, 계산 결과를 고객용 리포트로 정리해 전달합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·체크리스트·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 소득인정액·등록금·대출 조건을 넣어보고, 한국장학재단(studentloan.or.kr)의 '소득인정액 모의계산'·'학자금대출 상환 시뮬레이션' 결과와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "학자금대출", "등록금", "상환전략"이라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 지원·상환액이 아니라 **참고용 추정 계산 도구**입니다. 소득인정액 구간표(기준중위소득 대비 비율·경곗값)와 구간별 지원 단가, 상환기준소득, 대출금리, 반환비율표, 연체정보 등록유예 기간은 학기·연도별 고시와 학칙 개정으로 바뀌므로, 실제 적용 전 반드시 한국장학재단(studentloan.or.kr)·콜센터(1599-2000)·소속 학교 학칙 공지로 최신 값을 재확인하세요. 특히 소득인정액 산정에는 가구원 수, 재산의 소득환산액, 형제자매 수에 따른 공제까지 포함되어 단순 소득만으로는 정확히 추정되지 않으며, 등록금 반환비율의 세부 구간은 학교 학칙마다 다르게 운영될 수 있습니다. 이 부업은 한국장학재단·학교의 고유 업무(실제 대출 심사, 신용유의자 등록, 반환금 지급 처리)를 대신하는 것이 아니라 사전 계산과 안내라는 점을 상담 시작 전 항상 명확히 안내해 오해를 예방해야 합니다.
