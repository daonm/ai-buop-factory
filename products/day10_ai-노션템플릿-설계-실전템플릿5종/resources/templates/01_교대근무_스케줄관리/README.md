# 템플릿 1 — 교대근무자 불규칙 스케줄 관리

3교대·2교대 등 매주 근무 시간대가 바뀌는 사람을 위한 노션 데이터베이스입니다. 일반 캘린더 템플릿은 "매일 같은 패턴"을 가정하기 때문에, 교대근무자는 수면 계획·컨디션까지 함께 관리해야 실제로 도움이 됩니다.

## 1. 가져오기 (Import)

1. 노션에서 아무 페이지나 열고 `/csv` → **CSV 가져오기(Import)** 선택
2. 이 폴더의 `근무스케줄.csv` 선택 → 자동으로 데이터베이스 생성됨
3. 아래 "속성 타입 재설정"을 따라 각 열의 타입을 바로잡아줍니다 (CSV 가져오기는 모든 열을 텍스트로 만듭니다)

## 2. 속성 타입 재설정

| 속성명 | 변경할 타입 | 옵션 |
|---|---|---|
| 날짜 | 날짜(Date) | — |
| 요일 | 선택(Select) | 월~일 |
| 근무유형 | 선택(Select) | 주간(노랑) / 야간(보라) / 오프(회색) / 휴가(초록) |
| 시작시간 / 종료시간 | 텍스트 유지 또는 날짜의 "시간 포함"으로 별도 재구성 | — |
| 컨디션 | 숫자(Number) | 1~5 |

## 3. 추가할 수식(Formula) — 그대로 붙여넣기

**연속 야간 경고 뱃지** (새 속성 `야간경고`, 타입: 수식)
```
if(prop("근무유형") == "야간", "🌙 야간 — 카페인 주의", "")
```

**컨디션 상태 이모지** (새 속성 `컨디션표시`, 타입: 수식)
```
if(prop("컨디션") >= 4, "🟢 좋음", if(prop("컨디션") == 3, "🟡 보통", "🔴 낮음"))
```

**이번 주 야간 근무 일수 확인용 뷰**: 별도 수식 없이 필터(근무유형 = 야간, 날짜가 "이번 주")로 충분합니다. 아래 "뷰 구성"에서 안내합니다.

## 4. 뷰(View) 구성 — 3개 추천

1. **캘린더 뷰** — 기본. 근무유형별 색상이 한눈에 보이도록 위 선택 옵션 색상을 꼭 지정하세요.
2. **보드 뷰** (그룹 기준: 근무유형) — 이번 달 주간/야간/오프/휴가 비율을 한눈에 확인
3. **표 뷰** (필터: 컨디션 ≤ 2) — 컨디션이 나빴던 날만 모아서 패턴 분석 (예: "야간 3일차부터 항상 2점 이하")

## 5. 페이지 구조 제안

```
🏠 홈 (교대근무 대시보드)
 ├─ 이번 주 스케줄 (캘린더 뷰 임베드)
 ├─ 📊 이번 달 컨디션 추이 (표 뷰 임베드, 컨디션 낮은 순 정렬)
 └─ 📁 근무스케줄 (전체 데이터베이스)
```

홈 화면 최상단에는 "오늘 근무유형 + 컨디션 입력" 버튼(Notion 버튼 기능)을 두면 매일 여는 습관이 생깁니다.

## 6. 커스터마이징 프롬프트

- "야간 근무가 3일 이상 연속될 때 자동으로 경고 문구가 뜨는 수식을 만들어줘. 노션 수식 문법으로."
- "이 컨디션 데이터를 보고 내 회복 패턴을 분석하는 질문 리스트를 만들어줘: [최근 2주 컨디션 데이터]"
