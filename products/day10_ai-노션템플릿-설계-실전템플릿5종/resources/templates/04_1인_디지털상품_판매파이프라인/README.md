# 템플릿 4 — 1인 디지털 상품 판매 파이프라인 관리

전자책·템플릿·소스코드 등 여러 개의 디지털 상품을 동시에 굴리는 1인 판매자를 위한 파이프라인 관리 데이터베이스입니다. "어떤 상품이 지금 어느 단계인지, 다음에 뭘 해야 하는지"를 한 화면에서 파악하는 것이 목적입니다. (예시 데이터는 이 프로젝트 자체의 실제 상품 라인업을 참고해 구성했습니다.)

## 1. 가져오기 (Import)

1. 노션에서 `/csv` → CSV 가져오기 → `상품파이프라인.csv` 선택
2. 아래 표대로 속성 타입을 재설정합니다

## 2. 속성 타입 재설정

| 속성명 | 변경할 타입 | 옵션 |
|---|---|---|
| 단계 | 선택(Select) | 기획 / 제작중 / 디자인 / 등록대기 / 판매중 / 단종 |
| 유형 | 선택(Select) | 전자책 / 실습자료 / 템플릿 / 소스코드 |
| 채널 | 선택(Select) | 래피드 / 크몽 / 자체판매 등 |
| 가격 / 판매수 / 매출 | 숫자(Number) | 가격·매출은 통화 형식(원) 적용 |
| 등록일 | 날짜(Date) | — |

## 3. 추가할 수식(Formula)

**건당 매출 검증** (새 속성 `평균단가확인`, 타입: 수식) — 매출이 가격×판매수와 맞는지 자동 확인
```
if(prop("매출") == prop("가격") * prop("판매수"), "✅ 일치", "⚠️ 확인 필요")
```

**등록 후 경과일** (새 속성 `경과일`, 타입: 수식) — 오래 방치된 상품(홍보 소홀) 찾기
```
if(prop("등록일") != empty(), dateBetween(now(), prop("등록일"), "days"), 0)
```

**우선 조치 뱃지** (새 속성 `조치필요`, 타입: 수식) — 등록된 지 오래됐는데 판매가 0인 상품 표시
```
if(and(prop("경과일") > 7, prop("판매수") == 0), "🚨 홍보 재점검", "")
```

## 4. 뷰(View) 구성

1. **칸반 보드** (그룹 기준: 단계) — 기획→제작중→등록대기→판매중 흐름을 카드로 이동시키며 관리
2. **매출 랭킹 표** (정렬: 매출 내림차순) — 뭐가 잘 팔리는지 한눈에, 다음 상품 기획에 활용
3. **조치 필요 뷰** (필터: 조치필요 ≠ 빈 값) — 오늘 열었을 때 가장 먼저 봐야 할 목록

## 5. 페이지 구조 제안

```
🏠 홈 (오늘의 파이프라인)
 ├─ 🚨 조치 필요 (조치 필요 뷰 임베드)
 ├─ 📊 매출 랭킹 Top 5
 └─ 🗂 전체 파이프라인 (칸반 보드)
      └─ 각 상품 페이지 안에 "판매 페이지 카피", "홍보 로그" 하위 페이지 링크
```
