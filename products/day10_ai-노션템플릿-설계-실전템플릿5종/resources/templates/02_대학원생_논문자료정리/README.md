# 템플릿 2 — 논문·자료 정리 (대학원생용)

읽은 논문이 흩어지지 않고, "이 논문 어디서 봤더라"를 다시 찾지 않도록 만든 문헌 관리 데이터베이스입니다.

## 1. 가져오기 (Import)

1. 노션에서 `/csv` → CSV 가져오기 → `논문트래커.csv` 선택
2. 아래 표대로 속성 타입을 재설정합니다

## 2. 속성 타입 재설정

| 속성명 | 변경할 타입 | 옵션 |
|---|---|---|
| 발행연도 | 숫자(Number) | — |
| 키워드 | 다중 선택(Multi-select) | 세미콜론(;)으로 구분된 값이 자동 분리되지 않으므로, 가져온 후 각 행에서 한 번씩 다시 선택해줘야 합니다 |
| 읽음상태 | 선택(Select) | 읽을예정(회색) / 읽는중(노랑) / 완료(초록) |
| 중요도 | 숫자(Number) | 1~5 |
| 인용여부 | 체크박스(Checkbox) | 예→체크, 아니오→해제 |
| 링크 | URL | — |

## 3. 추가할 수식(Formula)

**우선순위 점수** (새 속성 `우선순위`, 타입: 수식) — 중요도가 높고 아직 안 읽은 논문을 위로 올리기
```
prop("중요도") * (if(prop("읽음상태") == "완료", 0, 1))
```

**서지 인용 텍스트 자동 생성** (새 속성 `인용텍스트`, 타입: 수식) — 참고문헌 초안용
```
prop("저자") + " (" + format(prop("발행연도")) + "). " + prop("제목") + "."
```

## 4. 뷰(View) 구성

1. **읽을 목록 뷰** (표, 필터: 읽음상태 ≠ 완료, 정렬: 우선순위 내림차순) — 오늘 뭘 읽을지 여기서 고름
2. **주제별 보드 뷰** (그룹 기준: 키워드) — 연구 주제별로 얼마나 읽었는지 한눈에 확인
3. **인용 목록 뷰** (표, 필터: 인용여부 = 체크됨) — 논문 쓸 때 참고문헌 정리용

## 5. 페이지 구조 제안

```
🏠 홈 (연구 대시보드)
 ├─ 📌 이번 주 읽을 논문 (읽을 목록 뷰, 상위 5개만 임베드)
 ├─ 🗂 주제별 현황 (주제별 보드 뷰)
 └─ 📚 전체 논문 데이터베이스
      └─ 각 논문 페이지 안에 "핵심 문장 인용", "내 연구에 어떻게 쓸지" 하위 섹션 미리 만들어두기
```

## 6. 커스터마이징 프롬프트

- "이 논문 초록을 읽고 3줄 요약과 핵심 키워드 5개를 뽑아줘: [초록 붙여넣기]"
- "내 연구 주제는 [주제]야. 이 논문이 내 연구와 어떻게 연결되는지 한 문단으로 정리해줘: [논문 요약]"
- "다음 논문 목록을 참고문헌 형식(APA)으로 정리해줘: [저자, 연도, 제목 목록]"
- "이 데이터베이스에 '재현 가능 여부(코드 공개 여부)' 속성을 추가하고 싶어. 어떤 타입이 적절한지, 관련 수식도 함께 제안해줘."
