# 템플릿 3 — ADHD 성향을 고려한 초저마찰 습관판

일반 습관 트래커는 "매일 30분 운동" 같은 큰 목표를 기준으로 만들어져서, 실행 문턱이 높으면 며칠 만에 방치됩니다. 이 템플릿은 **"최소단위"** 속성을 핵심으로 두어, 목표를 의도적으로 아주 작게 쪼갠 뒤 "했다/안 했다"만 가볍게 기록하는 구조입니다.

## 1. 가져오기 (Import)

1. 노션에서 `/csv` → CSV 가져오기 → `습관트래커.csv` 선택
2. 아래 표대로 속성 타입을 재설정합니다

## 2. 속성 타입 재설정

| 속성명 | 변경할 타입 | 옵션 |
|---|---|---|
| 카테고리 | 선택(Select) | 건강 / 공간 / 정서 / 학습 등 |
| 요일 | 선택(Select) | 매일 / 월수금 / 주말 등 원하는 패턴 |
| 완료 | 체크박스(Checkbox) | — |
| 연속일수 | 숫자(Number) | — |

> 이 템플릿은 "습관 1개 = 행 1개"가 아니라 **매일 반복되는 카드**로 씁니다. 아래 4번 "매일 리셋" 자동화를 꼭 설정하세요 — 그래야 매일 새로 체크할 수 있습니다.

## 3. 추가할 수식(Formula)

**연속 기록 상태 표시** (새 속성 `상태뱃지`, 타입: 수식)
```
if(prop("연속일수") >= 21, "🔥 습관화 완료(21일+)", if(prop("연속일수") >= 7, "✨ 1주 돌파", if(prop("연속일수") >= 1, "🌱 시작함", "⬜ 아직")))
```

**오늘 해야 할 습관만 필터링용 수식** (새 속성 `오늘여부`, 타입: 수식) — 매일 속성이 "매일"이거나 오늘 요일이 포함된 습관만 true
```
prop("요일") == "매일"
```
(월수금 등 특정 요일은 노션 수식으로 오늘 요일과 자동 비교가 번거로우므로, 실전에서는 뷰 필터에서 수동으로 그룹을 나누는 것을 권장합니다 — 아래 뷰 구성 참고)

## 4. 매일 리셋 자동화 (버튼/자동화 기능)

노션 데이터베이스 자동화(Automation) 기능으로 "매일 자정, 완료 체크박스를 전부 해제"하도록 설정하면 다음 날 다시 체크할 수 있습니다. (자동화 → 새 자동화 → 조건: 매일 반복 → 작업: 완료 속성을 해제로 업데이트)

## 5. 뷰(View) 구성

1. **오늘의 습관 보드** (보드 뷰, 그룹 기준: 완료) — 완료/미완료 두 칼럼만 보이게. 카드 수가 적어야 부담이 없습니다.
2. **연속기록 표 뷰** (정렬: 연속일수 내림차순) — 가장 오래 지킨 습관을 보며 동기부여
3. **카테고리별 갤러리 뷰** — 카드 형태로 보상 문구가 눈에 띄게 배치

## 6. 페이지 구조 제안

```
🏠 홈 (오늘 딱 이것만)
 ├─ ✅ 오늘의 습관 보드 (완료/미완료 2칸만)
 └─ 🔥 연속기록 순위 (표 뷰, 상위 3개만 임베드)
```

**설계 원칙** — 홈 화면에 통계·그래프·긴 목록을 절대 넣지 않습니다. ADHD 성향 사용자는 정보량이 많으면 여는 것 자체가 부담이 되어 오히려 안 열게 됩니다. "오늘 뭘 체크해야 하는지"만 크게 보이면 충분합니다.

## 7. 커스터마이징 프롬프트

- "[하고 싶은 습관, 예: 책 읽기]을 ADHD 성향인 사람도 부담 없이 시작할 수 있는 최소단위로 쪼개줘. 예시 3단계로."
- "연속일수가 끊겼을 때 자책하지 않고 다시 시작하게 도와주는 짧은 응원 문구 10개를 만들어줘."
- "이 습관 목록에 맞는 보상(작고 즉각적인 것)을 5개 제안해줘: [습관 목록]"
