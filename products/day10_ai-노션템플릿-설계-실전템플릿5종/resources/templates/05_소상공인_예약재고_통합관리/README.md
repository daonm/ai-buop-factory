# 템플릿 5 — 1인 카페·스튜디오 예약 + 재고 통합관리

미용실, 네일샵, 소규모 스튜디오처럼 "예약 관리"와 "재고 관리"를 동시에 손으로 하고 있는 소상공인을 위한 2-데이터베이스 세트입니다. 두 데이터베이스를 관계형(Relation)으로 연결해서, 예약이 잡히면 관련 소모품 재고까지 한눈에 확인할 수 있게 만듭니다.

## 1. 가져오기 (Import)

1. `예약목록.csv`와 `재고목록.csv`를 각각 `/csv` → CSV 가져오기로 두 개의 별도 데이터베이스로 생성
2. 아래 표대로 속성 타입을 재설정합니다

### 예약목록 속성 재설정

| 속성명 | 변경할 타입 | 옵션 |
|---|---|---|
| 연락처 | 전화번호(Phone) | — |
| 예약일시 | 날짜(Date, 시간 포함 켜기) | — |
| 서비스 | 선택(Select) | 헤어커트 / 펌 / 염색 / 클리닉 등 |
| 상태 | 선택(Select) | 예약확정(파랑) / 완료(초록) / 노쇼(빨강) / 취소(회색) |

### 재고목록 속성 재설정

| 속성명 | 변경할 타입 | 옵션 |
|---|---|---|
| 카테고리 | 선택(Select) | 소모품 / 판매상품 |
| 현재수량 / 최소수량 / 단가 | 숫자(Number) | 단가는 통화(원) 형식 |
| 재주문여부 | 체크박스(Checkbox) | — |

## 2. 두 데이터베이스 연결하기

1. `예약목록`에 새 속성 추가 → 타입 **관계형(Relation)** → 대상: `재고목록`
2. 각 예약 행에서 이 예약에 쓰인 소모품(예: 염색약)을 연결
3. `재고목록`에 자동으로 생겨나는 역관계 속성에서 "이 소모품이 어떤 예약에 쓰였는지" 확인 가능

## 3. 추가할 수식(Formula)

**재고 부족 자동 경고** (재고목록에 새 속성 `재주문필요`, 타입: 수식)
```
if(prop("현재수량") <= prop("최소수량"), "🔴 재주문 필요", "🟢 충분")
```

**노쇼율 추적용 뷰**: 별도 수식 없이 예약목록에서 필터(상태 = 노쇼)로 개수를 세면 됩니다. 아래 뷰 구성 참고.

**소모품 총 재고가치** (재고목록에 새 속성 `재고가치`, 타입: 수식)
```
prop("현재수량") * prop("단가")
```

## 4. 뷰(View) 구성

**예약목록**
1. **오늘의 예약** (표 뷰, 필터: 예약일시 = 오늘, 정렬: 예약일시 오름차순)
2. **노쇼 이력** (표 뷰, 필터: 상태 = 노쇼) — 반복 노쇼 고객 파악용

**재고목록**
1. **재주문 필요 뷰** (필터: 재주문필요 = "🔴 재주문 필요") — 문 열자마자 확인하는 목록
2. **재고가치 표** (정렬: 재고가치 내림차순) — 자금이 어디 묶여있는지 파악

## 5. 페이지 구조 제안

```
🏠 홈 (오늘 운영 대시보드)
 ├─ 📅 오늘의 예약 (오늘의 예약 뷰 임베드)
 ├─ 📦 재주문 필요 재고 (재주문 필요 뷰 임베드)
 └─ 📁 전체 데이터
      ├─ 예약목록
      └─ 재고목록
```

## 6. 커스터마이징 프롬프트

- "우리 가게는 [업종]이야. 예약목록에 필요한 속성을 추가로 제안해줘. 지금은 고객명/연락처/일시/서비스/상태만 있어."
- "재고 최소수량을 정하는 기준을 어떻게 잡으면 좋을지, 우리 가게 상황([공급 주기, 사용량])을 참고해서 제안해줘."
- "노쇼가 반복되는 고객에게 보낼 정중한 예약 확인 문자 템플릿을 만들어줘."
- "이번 달 예약/재고 데이터를 정리했어: [데이터]. 다음 달 발주량과 예약 정책 개선점을 제안해줘."
