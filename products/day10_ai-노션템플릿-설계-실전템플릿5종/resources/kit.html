노션 템플릿 5종 실전 키트

복제해서 바로 쓰는 CSV 임포트 파일 5세트, 수식 레시피, 뷰 설계까지 — 오늘 안에 내 상품으로 만드는 실행판

5템플릿
12개 수식
19개 프롬프트
『그 노션, 저장만 하고 안 씁니다』를 읽은 다음날 바로 복제하는 실행용 자료입니다.

전자책에서 "니치를 좁혀라"고 했다면, 이 키트는 좁힌 니치 5개를 실제로 완성해서 드립니다.

각 템플릿 폴더에는 노션에 바로 가져올 수 있는 CSV 파일과, 속성 타입 재설정·수식·뷰·페이지 구조까지 담은 README가 들어있습니다. CSV를 가져온 뒤 이 문서의 수식을 그대로 붙여넣으면 30분 안에 판매 가능한 수준의 템플릿이 완성됩니다.

  1. 템플릿 5종 — 교대근무자·대학원생·ADHD 습관관리·1인 상품 파이프라인·소상공인 예약재고, 서로 다른 니치를 그대로 재현 가능한 구조로 제공합니다.
  2. 수식 12개 — 노션 수식 문법 그대로, 복사해서 붙여넣으면 바로 작동합니다.
  3. 커스터마이징 프롬프트 19개 — 내 상황에 맞게 구조를 바꿀 때 그대로 쓰는 질문입니다.

사용법 — 5개를 다 쓸 필요는 없습니다. 내가 가장 잘 아는 니치 하나를 골라 CSV를 가져오고, 나머지는 "이런 구조도 가능하구나"를 배우는 참고 자료로 훑어보세요.

02공통 설치 3단계

5개 템플릿 모두 같은 순서로 설치합니다. 한 번 익히면 다음 니치도 5분 안에 복제할 수 있습니다.

  1. CSV 가져오기 — 노션에서 새 페이지 → /csv 입력 → CSV 가져오기 → 해당 폴더의 CSV 선택. 자동으로 데이터베이스가 생성됩니다.
  2. 속성 타입 재설정 — CSV 가져오기는 모든 열을 텍스트로 만듭니다. 각 템플릿 README의 표대로 선택/숫자/날짜/체크박스로 바꿔줍니다.
  3. 수식·뷰 추가 — 아래 03장의 수식을 그대로 복사해서 새 속성(타입: 수식)에 붙여넣고, 04장 대신 각 템플릿 README의 뷰 구성을 따라 뷰를 만듭니다.

03수식 레시피 12선

노션 수식 문법 그대로입니다. 새 속성을 만들고 타입을 "수식"으로 지정한 뒤 그대로 붙여넣으세요.

템플릿 1 · 교대근무 스케줄
야간경고 뱃지
if(prop("근무유형") == "야간", "🌙 야간 — 카페인 주의", "")
컨디션 상태 이모지
if(prop("컨디션") >= 4, "🟢 좋음", if(prop("컨디션") == 3, "🟡 보통", "🔴 낮음"))
템플릿 2 · 논문·자료 정리
우선순위 점수
prop("중요도") * (if(prop("읽음상태") == "완료", 0, 1))
서지 인용 텍스트
prop("저자") + " (" + format(prop("발행연도")) + "). " + prop("제목") + "."
템플릿 3 · ADHD 습관관리
연속 기록 상태 뱃지
if(prop("연속일수") >= 21, "🔥 습관화 완료", if(prop("연속일수") >= 7, "✨ 1주 돌파", if(prop("연속일수") >= 1, "🌱 시작함", "⬜ 아직")))
오늘 대상 필터용
prop("요일") == "매일"
템플릿 4 · 상품 판매 파이프라인
평균단가 검증
if(prop("매출") == prop("가격") * prop("판매수"), "✅ 일치", "⚠️ 확인 필요")
등록 후 경과일
if(prop("등록일") != empty(), dateBetween(now(), prop("등록일"), "days"), 0)
조치 필요 뱃지
if(and(prop("경과일") > 7, prop("판매수") == 0), "🚨 홍보 재점검", "")
템플릿 5 · 예약+재고 통합관리
재고 부족 경고
if(prop("현재수량") <= prop("최소수량"), "🔴 재주문 필요", "🟢 충분")
재고가치 계산
prop("현재수량") * prop("단가")

04커스터마이징 프롬프트 19선

내 상황에 맞게 구조를 바꿀 때 그대로 붙여넣는 질문입니다. 대괄호만 채우세요.

템플릿 1 · 교대근무 스케줄
패턴 변경
3교대(주간/오후/야간) 패턴으로 바꾸고 싶어. 근무유형 선택 옵션과 색상 배정을 다시 제안해줘.
연속근무 경고
야간 근무가 3일 이상 연속될 때 자동으로 경고 문구가 뜨는 수식을 만들어줘. 노션 수식 문법으로.
회복 패턴 분석
이 컨디션 데이터를 보고 내 회복 패턴을 분석하는 질문 리스트를 만들어줘: [최근 2주 컨디션 데이터]
템플릿 2 · 논문·자료 정리
초록 3줄 요약
이 논문 초록을 읽고 3줄 요약과 핵심 키워드 5개를 뽑아줘: [초록 붙여넣기]
연구 연결점
내 연구 주제는 [주제]야. 이 논문이 내 연구와 어떻게 연결되는지 한 문단으로 정리해줘: [논문 요약]
참고문헌 정리
다음 논문 목록을 참고문헌 형식(APA)으로 정리해줘: [저자, 연도, 제목 목록]
속성 확장
이 데이터베이스에 '재현 가능 여부(코드 공개 여부)' 속성을 추가하고 싶어. 어떤 타입이 적절한지, 관련 수식도 함께 제안해줘.
템플릿 3 · ADHD 습관관리
최소단위 쪼개기
[하고 싶은 습관, 예: 책 읽기]을 ADHD 성향인 사람도 부담 없이 시작할 수 있는 최소단위로 쪼개줘. 예시 3단계로.
재시작 응원 문구
연속일수가 끊겼을 때 자책하지 않고 다시 시작하게 도와주는 짧은 응원 문구 10개를 만들어줘.
즉각 보상 설계
이 습관 목록에 맞는 보상(작고 즉각적인 것)을 5개 제안해줘: [습관 목록]
템플릿 4 · 상품 판매 파이프라인
주간 우선순위
이번 주 상품 파이프라인 데이터를 정리했어: [단계별 개수, 매출]. 다음 주 우선순위 3가지를 제안해줘.
부진 원인 분석
판매수가 0인 상품들의 공통점을 찾아줘. 가격, 등록일, 유형 데이터를 기준으로: [해당 상품 목록]
다음 상품 발굴
가장 잘 팔린 상품과 비슷한 다음 상품 아이디어 5개를 제안해줘: [매출 상위 상품 설명]
템플릿 5 · 예약+재고 통합관리
업종별 속성 확장
우리 가게는 [업종]이야. 예약목록에 필요한 속성을 추가로 제안해줘. 지금은 고객명/연락처/일시/서비스/상태만 있어.
최소수량 기준
재고 최소수량을 정하는 기준을 어떻게 잡으면 좋을지, 우리 가게 상황([공급 주기, 사용량])을 참고해서 제안해줘.
노쇼 대응 문자
노쇼가 반복되는 고객에게 보낼 정중한 예약 확인 문자 템플릿을 만들어줘.
월간 발주 계획
이번 달 예약/재고 데이터를 정리했어: [데이터]. 다음 달 발주량과 예약 정책 개선점을 제안해줘.

05설치 체크리스트

템플릿마다 딱 4단계입니다. 하나 끝내고 다음으로 넘어가세요.

템플릿 1교대근무 스케줄 관리

  • 근무스케줄.csv 가져오기
  • 근무유형·요일 선택 옵션 색상 지정
  • 야간경고·컨디션표시 수식 추가
  • 캘린더/보드/표 뷰 3종 구성

템플릿 2논문·자료 정리

  • 논문트래커.csv 가져오기
  • 키워드 다중선택으로 재분류
  • 우선순위·인용텍스트 수식 추가
  • 읽을 목록 뷰 정렬 확인(우선순위 내림차순)

템플릿 3ADHD 습관관리

  • 습관트래커.csv 가져오기
  • 매일 자정 완료 체크박스 초기화 자동화 설정
  • 상태뱃지 수식 추가
  • 홈 화면에 오늘의 습관 보드만 배치(정보량 최소화)

템플릿 4상품 판매 파이프라인

  • 상품파이프라인.csv 가져오기
  • 단계별 칸반 보드 구성
  • 조치필요 수식 추가 후 필터 뷰 생성
  • 내 실제 상품 데이터로 교체

템플릿 5예약+재고 통합관리

  • 예약목록.csv, 재고목록.csv 각각 가져오기
  • 예약목록 → 재고목록 관계형 속성 연결
  • 재주문필요·재고가치 수식 추가
  • 오늘의 예약 / 재주문 필요 뷰 홈에 임베드

CSV를 가져오고, 수식을 붙여넣고, 뷰 3개만 만들면 끝입니다.
