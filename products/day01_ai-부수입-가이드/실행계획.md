# 실행 계획 — AI 부수입 전자책 판매 프로젝트

## 준비된 산출물

| 파일 | 용도 |
|---|---|
| `ebook/manuscript.md` | 전자책 원고 (12가지 방법 + 프롬프트 20선) |
| `ebook/ebook.html` | 표지 포함 디자인된 전자책 (PDF 변환용) |
| `marketing/sales_page.md` | 래피드 상품 등록용 상세페이지 카피, 가격 제안 |
| `marketing/threads_posts.md` | 스레드 홍보 글 7개 + 댓글 답글 템플릿 |

**디자인된 전자책 미리보기**: https://claude.ai/code/artifact/89e40380-9046-4f43-a30a-b331e14da39d
→ 브라우저에서 열어서 Ctrl+P(인쇄) → "PDF로 저장"하면 바로 래피드에 업로드할 PDF가 완성됩니다.

## 사용자님이 직접 하셔야 하는 부분 (실제 등록/결제)

1. **래피드(latpeed.com) 가입 및 상품 등록**
   - `marketing/sales_page.md`의 제목/카피/가격을 그대로 입력
   - PDF는 `ebook/manuscript.md`를 변환해서 업로드 (원하시면 제가 보기 좋은 표지 포함 HTML/PDF 버전도 만들어드릴 수 있어요)
   - 결제(정산) 계좌 연동은 래피드 가입 절차 안에서 진행

2. **스레드(Threads) 계정에서 홍보 글 발행**
   - `marketing/threads_posts.md`의 7개 글을 요일별로 발행
   - 프로필에 래피드 상품 링크 등록
   - 댓글 달리면 템플릿 참고해서 답글

3. **1주 뒤 결과 공유해주시면**
   - 반응 좋았던 글/안 좋았던 글을 분석해서 다음 홍보 글 세트를 다시 만들어드릴게요
   - 후기 쌓이면 가격 인상 타이밍도 같이 판단해드릴게요
