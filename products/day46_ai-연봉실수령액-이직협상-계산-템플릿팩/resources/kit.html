계산은 다 만들어놨습니다. 이제 조건만 넣으면 됩니다. 이 키트는 전자책 방법 1~9(실수령액 구성 원리·2026년 요율 계산·비과세 최적화·오퍼 비교·희망연봉 산정·협상 멘트·처우협의서 체크리스트·퇴직금 손익 계산)를 이미 끝낸 완성본입니다.

엑셀 계산기 3종과 워드 템플릿 1종, 체크리스트 1종을 같은 톤으로 만들었습니다.

  1. 안내 시트 — "확정 세액·보장 금액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다.
  2. 계산기·템플릿 시트 — 노란색 칸에 값을 입력하면 올리브색 칸에 결과가 바로 뜹니다.
  3. 참고표(해당 파일만) — 4대보험 요율·비과세 한도처럼 반복해서 쓰는 기준을 계산기 시트 상단에 함께 정리해뒀습니다.

사용법 — 아래 계산기별 참고표에서 원하는 것부터 확인하고, 실제 파일을 열어 본인(또는 의뢰인) 조건으로 한 번 테스트해본 뒤 협상 멘트·처우협의서 체크리스트까지 이어서 진행하세요.

01계산기·템플릿 5종 빠른 참고표

각 파일의 입력값 예시, 결과값, 그리고 어떤 순서로 이어 쓰는지를 정리했습니다. 실제 파일에 그대로 입력해 결과를 재현할 수 있습니다.

A. 연봉 실수령액 계산기
파일 — 연봉실수령액_계산기.xlsx · 연봉·부양가족 수·비과세 적용 여부를 입력하면 2026년 4대보험 요율과 연간 추정 소득세를 반영한 월·연 실수령액을 자동 계산합니다
입력값결과값
연봉 5,000만원부양가족 1인 / 식대 비과세 적용월 실수령액약 3,517,000원
위 조건 기준연간 환산연 실수령액 / 비율약 42,207,000원 / 84.4%

이런 상담에게 — "연봉 OOOO면 한 달에 얼마 받는 거예요?"라고 묻는 사람. 4대보험·소득세를 뗀 실제 숫자를 바로 보여주면 "왜 생각보다 적은지" 설득력이 생깁니다.

B. 오퍼 비교 계산기

입력값결과값
A사 확정 5,500만원B사 확정 5,300만원확정 실수령액 우위A사 (약 4,594만원)
변동성과급·사이닝보너스 반영B사가 더 큼1년차 총합 우위B사 (약 5,594만원)

이런 상담에게 — 세전 연봉만 보고 어느 오퍼가 좋은지 헷갈려 하는 의뢰인. 확정 기준과 변동 요소 반영 기준이 다를 수 있다는 걸 숫자로 보여주면 바로 이해합니다.

C. 퇴직금·연차수당·이직손익 계산기

이런 상담에게 — 이직 직후가 유리해 보여 성급히 결정하려는 의뢰인. 퇴직금·공백기까지 포함한 전체 손익을 보여주면 더 신중한 판단을 돕습니다.

04판매 준비 체크리스트

브리프부터 등록까지, 순서대로 체크하며 진행하세요.

1단계검증

  • Worksheet 2로 계산기 A·B·C 모두 내(또는 지인의) 실제 조건으로 테스트하기
  • 4insure.or.kr 모의계산·홈택스 간이세액표와 대조해 오차 확인하기
  • 계산기 시트에 확인한 요율과 확인 날짜 메모 남기기

2단계다듬기

  • 입력 셀(노란색) 옆에 "여기에 값을 입력하세요" 안내 문구 확인하기
  • "참고용 추정치이며 보장된 금액이 아니다"는 경계 문구가 각 파일에 붙어있는지 확인하기
  • 파일명·시트명에 오탈자 없는지 최종 점검하기

3단계등록

  • Worksheet 1로 패키지·가격 확정하기
  • 래피드에 상품명 "계산기/연봉/이직협상" 단어 포함해 등록하기
  • Day45 전자책과 세트 상품(업셀) 옵션도 함께 등록하기

4단계갱신 관리

  • 4대보험 요율·소득세 구간 매년 1월마다 확인해 캘린더에 표시해두기
  • 기존 상담 고객 연락처/알림 목록 만들어두기(다음 연봉 협상·이직 시즌 안내용)
  • 요율·세액표 변경 시 계산기 A·B·C의 참고표만 교체 후 Worksheet 2 검증 다시 거치기
