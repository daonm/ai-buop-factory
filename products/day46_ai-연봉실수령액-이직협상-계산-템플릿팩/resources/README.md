# AI 연봉 실수령액·이직 협상 계산 대행 — 계산기 + 협상 템플릿팩 사용 가이드

『그 오퍼, AI한테 먼저 계산받으세요』(Day45 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~9(실수령액 구성 원리·2026년 요율 계산·비과세 항목 최적화·오퍼 비교·희망연봉 산정·협상 멘트·처우협의서 체크리스트·퇴직금 손익 계산)를 이미 끝내둔 완성본 엑셀 계산기 3종·체크리스트 1종·워드 협상 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 세액·보장 금액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자(또는 텍스트)를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`처우협의서_검토_체크리스트.xlsx`는 계산 파일이 아니라 체크(O 표시) + 완료율 자동 집계용 표입니다. `희망연봉_협상멘트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 복사해 쓰는 문서입니다.

## 계산기·템플릿을 잇는 순서

1. **연봉 실수령액 계산기**로 현재(또는 제안받은) 연봉의 월·연 실수령액부터 계산합니다.
2. 오퍼가 2개 이상이면 **오퍼 비교 계산기**로 확정 실수령액과 변동 요소 반영 시나리오를 나란히 비교합니다.
3. 이직을 고려 중이라면 **퇴직금·연차수당·이직손익 계산기**로 퇴사 시 정산받을 금액과 공백기까지 포함한 전체 손익을 계산합니다.
4. **희망연봉·협상멘트 템플릿**으로 희망연봉 근거를 정리하고, 협상 이메일·멘트를 완성합니다.
5. 처우협의서(오퍼 레터)를 받으면 **처우협의서 검토 체크리스트**로 숫자 외 조건을 서명 전에 확인합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 연봉·오퍼 조건을 넣어보고, 4대사회보험 정보연계센터(4insure.or.kr) 모의계산·국세청 홈택스 간이세액표 조회와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "연봉", "이직협상"이라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 세액·보장 금액이 아니라 **참고용 추정 계산 도구**입니다. 소득세는 국세청 근로소득 간이세액표(월별 원천징수)가 아니라 연말정산 방식의 연간 추정 계산 로직을 사용했으므로, 회사가 적용하는 원천징수 비율(80/100/120%)에 따라 실제 매월 공제액은 달라질 수 있습니다. 4대보험 요율·비과세 한도·소득세 구간은 매년 바뀌므로, 실제 상담이나 협상에 사용하기 전 반드시 최신 정보(4insure.or.kr·국세청 홈택스)로 재확인하세요. 퇴직금은 회사의 평균임금 산정 기준(상여금·성과급 포함 여부)에 따라 달라질 수 있는 간이 추정치이며, 정확한 금액은 반드시 인사팀에 공식 확인해야 합니다. 이 부업은 협상을 대행하거나 결과를 보장하는 것이 아니라 계산·비교·멘트 초안 제공이라는 점을 상담 시작 전 항상 명확히 안내해 오해를 예방해야 합니다.
