클로드(Claude)로 만드는 나만의 업무 자동화 스크립트 — 코딩 없이 설명만으로 12가지 자동화

12가지 방법

이 책의 목차·본문·프롬프트까지, 전부 클로드가 기획하고 작성했습니다.

매주 월요일, 똑같은 순서로 엑셀을 정리하고 있다면 이 책이 그 시간을 없애 드립니다.

자동화라고 하면 개발자의 영역처럼 느껴지지만, 실제로 돈이 되는 자동화의 90%는 화려한 시스템이 아니라 "엑셀 정리 5분 걸리던 걸 5초로 줄이는" 수준의 작은 스크립트입니다.

당신은 "무엇을 반복하고 있는지"만 정확히 설명하면 되고, 스크립트는 클로드가 씁니다. 이 책은 오늘 컴퓨터 앞에서 바로 따라 할 수 있는 12가지 자동화 방법과, 클로드에게 그대로 던지는 프롬프트를 담았습니다.

01자동화를 코딩 없이 만든다는 것

"자동화"라고 하면 파이썬, API, 서버 같은 단어부터 떠오릅니다. 하지만 클로드와 함께라면 순서가 바뀝니다.

  1. 당신이 할 일 — 반복되는 업무를 말로 설명하기
  2. 클로드가 할 일 — 그 설명을 실제로 동작하는 스크립트로 바꾸기
  3. 당신이 다시 할 일 — 실행해보고, 안 되는 부분을 다시 설명해서 고치기

2026년 기준 Zapier·Make·n8n 같은 노코드 자동화 플랫폼은 모두 AI 에이전트가 워크플로우를 직접 설계하거나 실행하는 기능을 갖췄습니다. n8n은 LangChain 기반 AI 노드를 70개 이상 내장해 시각적 편집기 안에서 바로 AI 자동화를 구성할 수 있습니다. 지금은 "자동화 툴을 배우는 시간"보다 "무엇을 자동화할지 정확히 설명하는 능력"이 훨씬 중요해진 시점입니다.

02시작 전에 준비할 것

준비물은 딱 4가지 — 다 무료로 시작 가능합니다
  1. 클로드 계정 — 스크립트를 길게 짜고 여러 번 수정할 일이 많으니, 무료 플랜이 부담되면 Pro 플랜 권장
  2. 자동화할 업무 하나 — "매주 반복되고, 규칙이 명확한" 가장 단순한 업무 하나
  3. 실행 환경 하나 — 구글 스프레드시트(Apps Script) 또는 노코드 툴(Zapier/Make/n8n) 중 익숙한 것
  4. 테스트용 샘플 데이터 — 민감한 정보를 지운 샘플로 먼저 검증

방법 1(진단)은 반드시 먼저 읽고, 그다음은 순서와 상관없이 지금 필요한 방법으로 건너뛰어도 됩니다.

03방법 1 — 반복 업무 진단표 만들기

자동화에서 가장 많이 실패하는 지점은 "너무 큰 업무"부터 시작하는 것입니다. 처음엔 반드시 작게 시작하세요.

진행 순서

  1. 최근 2주간 반복 업무를 떠오르는 대로 10개 적는다
  2. "빈도 × 소요시간 × 규칙성" 3가지 기준으로 클로드에게 점수를 매겨달라고 요청
  3. 점수가 가장 높은 업무 1개를 첫 자동화 대상으로 확정
  4. 그 업무의 "입력 → 처리 → 출력"을 한 문장씩 적는다
예시 — "매주 월요일 매출 엑셀 합계를 내서 팀 채팅방에 공유" → 빈도 높음, 규칙 명확 → 자동화 1순위

04방법 2 — 구글 시트 + Apps Script

구글 스프레드시트를 이미 쓰고 있다면 가장 진입장벽이 낮은 방법입니다. Apps Script는 별도 설치 없이 시트 안에서 바로 실행되는 스크립트 환경입니다.

진행 순서

  1. 자동화할 시트의 구조를 클로드에게 설명
  2. "이 데이터를 요약해서 매주 월요일 오전 9시에 이메일로 보내는 Apps Script를 짜줘"라고 요청
  3. 시트 상단 메뉴 확장 프로그램 → Apps Script에 코드를 붙여넣기
  4. 트리거 메뉴에서 "매주 월요일 실행"으로 예약 설정
  5. 에러가 나면 에러 메시지를 그대로 클로드에게 붙여넣어 수정 요청
주의 — 개인 계정 이메일 발송은 하루 약 100통 제한이 있습니다. 대량 발송은 방법 4를 참고하세요.

05방법 3 — 이메일 자동 분류 · 요약

문의·주문·스팸이 뒤섞여 들어올 때 매번 열어보는 시간을 줄이는 방법입니다.

진행 순서

  1. 최근 메일 20통의 제목/발신자 패턴을 클로드와 함께 분류 기준으로 정리
  2. Gmail이라면 "필터 + 라벨" 규칙을 클로드에게 요청해서 1차 자동 분류
  3. 규칙만으로 안 걸러지는 메일은 Apps Script로 "본문을 읽고 판단해 라벨을 붙이는" 스크립트 요청
  4. 매일 아침 "어제 온 문의 메일 요약"을 만들어주는 스크립트 추가

완벽한 분류를 처음부터 노리지 마세요. "확실한 것만 자동 분류하고, 애매한 건 사람이 보는 폴더로 모으기" 방식이 실패율이 훨씬 낮습니다.

06방법 4 — 노코드 툴에 클로드 연결하기

Zapier, Make, n8n은 "이 앱에서 이런 일이 생기면 저 앱에서 이런 일을 해라"는 흐름을 코딩 없이 연결해주는 도구입니다.

도구강점이런 사람에게
Zapier7,000개 이상 앱 연동, 가장 쉬운 온보딩처음 자동화를 시작하는 사람
Make시각적 분기/필터가 강력함조건이 여러 갈래인 복잡한 흐름
n8n오픈소스, AI 에이전트 노드 내장, 직접 호스팅 가능비용을 아끼고 데이터를 직접 관리하고 싶은 사람

진행 순서

  1. 흐름을 "A 앱에서 B 이벤트가 생기면 → C 앱에서 D를 한다" 한 문장으로 정리
  2. 클로드에게 이 문장을 보여주고 Trigger·Action 단계로 설계 요청
  3. 설계안대로 툴 화면에서 단계를 하나씩 만든다
  4. 테스트 실행 → 실패하면 에러 로그를 클로드에게 전달해 원인 파악

07방법 5 — 데이터 정리 스크립트

"파일을 열어서 형식을 맞추고, 중복을 지우고, 표를 다시 만드는" 작업은 반복성이 가장 높은 업무 중 하나입니다.

진행 순서

  1. 정리 전/후 데이터 예시(가짜 데이터로)를 클로드에게 보여준다
  2. "이 형태를 저 형태로 바꾸는 스크립트를 짜줘"라고 요청(Python+pandas 또는 Apps Script)
  3. 샘플 파일로 먼저 실행해서 결과 확인
  4. 문제없으면 실제 파일에 적용, 원본은 항상 백업

데이터 정리 자동화는 "겉보기엔 맞는데 특정 케이스에서만 틀리는" 실수가 잘 드러나지 않습니다. 처음 몇 번은 결과를 손으로 대조해서 확인하세요.

08방법 6 — 견적서 · 인보이스 자동 생성

프리랜서, 소상공인에게 매달 반복되는 대표적인 업무입니다.

진행 순서

  1. 기존에 쓰던 양식을 클로드에게 보여준다
  2. "고객명·품목·수량·단가만 입력하면 문서가 자동 생성되는 스크립트"를 요청
  3. 시트에 정보를 입력하면 자동으로 PDF가 생성되는 방식(Apps Script) 선택
  4. 완성본 1개를 실제 발송해보고 형식 확인

인보이스 생성과 동시에 "발송 완료" 상태를 시트에 기록하고, 결제 기한이 지나면 자동 리마인드 메일을 보내는 흐름까지 방법 4와 연결하면 완전한 자동 청구 시스템이 됩니다.

09방법 7 — 카카오톡 · 슬랙 알림 자동화

중요한 일이 생겼을 때 사람이 직접 확인하지 않아도 알림이 오게 만드는 방법입니다.

진행 순서

  1. "언제 알림을 받고 싶은지" 조건을 명확히 한다
  2. 슬랙은 Incoming Webhook, 카카오톡은 채널 알림톡/친구톡 API 연동을 클로드와 함께 설계
  3. 조건이 맞을 때 메시지를 보내는 스크립트 구현
  4. 본인에게 먼저 테스트 메시지를 보내 문구/타이밍 확인

알림이 너무 잦으면 오히려 무시당합니다. 정말 사람이 봐야 하는 순간만 골라 알림을 설계하세요.

10방법 8 — 고객 문의 자동 응대

자주 묻는 질문에 매번 같은 답을 직접 타이핑하고 있다면 자동화 대상 1순위입니다.

진행 순서

  1. 최근 문의 중 반복되는 질문 유형 10개 정리
  2. 클로드에게 유형별 답변 스크립트 요청 (친절하되 로봇 같지 않은 톤으로)
  3. 카카오톡 채널 관리자센터 자동응답, 혹은 SNS DM 자동 응답 기능에 등록
  4. 패턴에 안 걸리는 질문은 사람에게 넘어가도록 예외 처리 문구 필수

자동 응답이라는 걸 숨기지 않는 편이 신뢰를 더 얻습니다. "빠른 안내를 위해 자동 답변이 먼저 나가고, 추가 문의는 담당자가 확인합니다" 같은 문구 하나면 충분합니다.

11방법 9 — 파일 · 폴더 정리 자동화

다운로드 폴더, 공유 드라이브가 뒤죽박죽인 경우 의외로 수요가 큰 자동화입니다.

진행 순서

  1. 정리 규칙을 말로 정의 (예: 파일명에 날짜가 있으면 연도별 폴더로)
  2. 클로드에게 이 규칙을 그대로 스크립트로 요청
  3. 테스트 폴더에서 먼저 실행해보고 결과 확인
  4. 삭제가 아니라 "이동"으로 설계해서 되돌릴 수 있게 한다
주의 — 자동 삭제 기능은 처음부터 넣지 마세요. 몇 주간 "이동/분류"만 시켜보고 신뢰가 쌓인 다음 고려해도 늦지 않습니다.

12방법 10 — 정기 실행 자동화

만든 스크립트를 사람이 매번 눌러서 실행하지 않고, 정해진 시간에 저절로 돌게 만드는 마지막 단계입니다.

진행 순서

  1. Apps Script는 트리거 메뉴에서 시간 기반 트리거 등록
  2. GitHub 저장소로 관리하면 GitHub Actions의 schedule(cron) 설정을 클로드에게 요청
  3. 노코드 툴은 Trigger를 "스케줄"로 설정
  4. 처음 1~2주는 실행 로그(성공/실패)를 꼭 직접 확인

스케줄링은 "이미 손으로 여러 번 실행해서 검증이 끝난 스크립트"에만 적용해야 합니다. 검증 안 된 스크립트를 자동 반복시키면 실수도 그만큼 반복됩니다.

13방법 11 — SNS/콘텐츠 발행 자동화

블로그, SNS에 꾸준히 올려야 하는데 매번 잊어버린다면 이 방법이 유용합니다.

진행 순서

  1. 발행 주기와 콘텐츠 유형을 정한다
  2. 클로드에게 "이번 주 발행할 콘텐츠 초안 2개"를 미리 요청
  3. 초안 검수 후, 예약 발행 기능이 있는 채널은 그 기능 활용
  4. 없는 채널은 방법 4의 스케줄 기능과 연결

전량 자동 발행(사람 검수 없이 바로 게시)은 추천하지 않습니다. 초안까지는 자동화하되, 최종 게시 버튼은 사람이 누르는 구조를 권장합니다 — 실계정 신뢰도와 직결되기 때문입니다.

14방법 12 — 자동화를 부업으로 파는 법

지금까지의 11가지를 직접 한 번씩 해봤다면, 이 경험 자체가 상품이 됩니다.

진행 순서

  1. 가장 자신 있게 만든 자동화 1개를 "사례"로 정리 (전/후 비교, 걸린 시간)
  2. 비슷한 반복 업무를 가진 사람에게 무료로 1건 시범 적용
  3. 후기와 사례를 근거로 크몽/숨고에 "업무 자동화 대행" 서비스 등록
  4. 처음엔 건당 요금, 신뢰가 쌓이면 월 유지보수 구독 요금으로 확장
가격 감각 — "자동화로 절약되는 시간 × 그 사람의 시급"을 기준으로 설명하면 가격 저항이 훨씬 줄어듭니다.

오늘30분

  • 클로드 계정 준비 (긴 작업 많으면 Pro 권장)
  • 반복 업무 10개 적고 프롬프트 A1로 우선순위 매기기
  • 1순위 업무의 "입력 → 처리 → 출력"을 한 문장씩 정리

이번 주1차 완성

  • 1순위 업무 자동화 스크립트 1차 완성(샘플 데이터로 테스트)
  • 실제 데이터로 전환 전, 결과를 손으로 대조 확인
  • 정기 실행이 필요하면 스케줄링(트리거/크론) 설정

이번 달확장

  • 2~3개 업무로 자동화 확장
  • 가장 자신 있는 사례 1개를 대행 서비스 소개 문구로 정리
  • 주변 1명에게 무료 시범 적용해서 후기 확보
