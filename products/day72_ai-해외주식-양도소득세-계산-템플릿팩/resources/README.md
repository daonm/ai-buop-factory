# AI 해외주식 양도소득세 계산 대행 — 계산기 + 신고서류 체크리스트 템플릿팩 사용 가이드

『5월에 세금 폭탄 맞기 전에, AI한테 먼저 계산시키세요』(Day71 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~8(거래내역 통합, 환율 환산, 취득원가 계산, 손익통산, 기본공제 적용, 세율 적용, 신고기한 점검, 홈택스 입력값 정리)을 이미 끝내둔 완성본 엑셀 계산기 3종·엑셀 D-day계산기+신고서류체크리스트 1종·워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 구성 파일

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 세액이 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자(또는 분류)를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`해외주식_거래내역통합_환율환산_계산기.xlsx`는 구분(매수/매도)을 드롭다운으로 고르게 했고, `취득원가_종목별손익_손익통산_계산기.xlsx`는 선입선출법 비교를 위해 Lot별 배분수량을 직접 입력하면 이동평균법과의 차이를 자동 계산하며 적용방식(이동평균/선입선출)도 드롭다운으로 고를 수 있고, `신고기한Dday_신고서류체크리스트.xlsx`는 D-day계산기 시트(연도 1개 입력 → 신고기한 자동 계산)와 체크리스트 시트(서류 20종, 준비상태 드롭다운)로 구성되고, `의뢰접수_고객리포트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 쓰는 문서입니다.

## 계산기·체크리스트·템플릿을 잇는 순서

1. **해외주식_거래내역통합_환율환산_계산기**로 증권사별 매수·매도 거래내역과 환율부터 입력해, 종목별 원화 거래금액과 여러 증권사 합산 결과를 확인합니다.
2. 같은 종목을 여러 번 나눠 매수했다면 **취득원가_종목별손익_손익통산_계산기**로 넘어가 이동평균법 취득원가와 종목별 손익, 손익통산 합계를 계산합니다.
3. **기본공제_세율적용_최종세액_계산기**로 손익통산 합계에 기본공제·세율을 적용한 최종 납부세액을 계산합니다.
4. **신고기한Dday_신고서류체크리스트**로 신고·납부 마감일을 확인하고, 준비해야 할 서류 20종의 상태를 점검합니다.
5. **의뢰접수_고객리포트_템플릿**으로 의뢰를 접수하고, 계산 결과를 고객용 리포트로 정리해 전달합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·체크리스트·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 거래내역으로 직접 테스트하기** — 실제 엑셀 파일에 실제 증권사 거래내역·환율을 넣어보고, 국세청 홈택스(hometax.go.kr) 양도소득세(국외주식) 모의계산·국세법령정보시스템(txsi.hometax.go.kr) 최신 기준과 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "해외주식", "양도소득세", "신고"라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 납부세액이 아니라 **참고용 추정 계산 도구**입니다. 기본공제 250만 원, 세율 22%, 신고기한(5월)은 이 계산기를 만든 시점 기준의 예시값이며, 금융투자소득세 도입 논의 등 세법 개정으로 바뀔 수 있으므로, 실제 적용 전 반드시 국세청 홈택스(hometax.go.kr)·국세법령정보시스템(txsi.hometax.go.kr)으로 최신 기준을 재확인하세요. 특히 환율은 거래(또는 결제일) 당시 기준환율·재정환율이 원칙이고, 손실 종목도 반드시 손익통산에 포함해야 하며, 기본공제는 종목·거래 횟수와 무관하게 1인당 연 1회만 적용된다는 점을 의뢰인에게 항상 명확히 안내해야 합니다. 이 부업은 세무대리·세무조정·과세관청 상대 이의신청·심판청구 대리를 대신하는 것이 아니라 계산 정리 대행이라는 점을 상담 시작 전 항상 명확히 안내해, 세무사법 위반(비세무사의 세무대리) 소지가 없도록 서비스 범위를 벗어나지 않게 운영하세요.
