# AI 이혼 재산분할·위자료 계산 대행 — 계산기 + 서류 체크리스트 템플릿팩 사용 가이드

『이혼 서류에 도장 찍기 전에, AI한테 먼저 물어보세요』(Day69 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 1~11(재산 목록화, 기여도 추정, 순재산·분할액 계산, 퇴직금·연금 분할, 위자료 산정요소·예상범위 추정, 양육비 구분, 청구기한 점검)을 이미 끝내둔 완성본 엑셀 계산기 3종·엑셀 D-day계산기+서류체크리스트 1종·워드 템플릿 1종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 엑셀 파일 공통 구조

계산기 파일들은 같은 구조로 만들었습니다.

1. **안내 시트** — "확정 재산분할액·위자료가 아니라 참고용 추정 계산 도구"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **계산기 시트** — 노란색 칸에 숫자(또는 분류)를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

`이혼재산분할_순재산분할액_계산기.xlsx`는 재산·채무 분류를 드롭다운(공동재산/특유재산-포함/특유재산-제외, 공동채무/개인채무)으로 고르게 했고, `위자료_예상범위_추정_계산기.xlsx`는 유책사유 해당여부를 Y/N 드롭다운으로 고르면 가중치 합산 점수가 자동 계산되며, `청구기한Dday_이혼서류준비_체크리스트.xlsx`는 D-day계산기 시트(날짜 3개 입력 → 청구기한 3종 자동 계산)와 체크리스트 시트(서류 20종, 준비상태 드롭다운)로 구성되고, `의뢰접수_고객리포트_템플릿.docx`는 대괄호 [ ] 부분만 조건에 맞게 바꿔서 그대로 쓰는 문서입니다.

## 계산기·체크리스트·템플릿을 잇는 순서

1. **이혼재산분할_순재산분할액_계산기**로 재산·채무 목록과 기여도 비율부터 입력해, 순재산과 재산분할 예상액 범위를 확인합니다.
2. 퇴직금·연금이 있다면 **퇴직금연금분할_계산기**로 넘어가 혼인기간 비율을 적용한 분할대상 가액을 계산합니다.
3. 유책사유가 있다면 **위자료_예상범위_추정_계산기**로 산정 요소를 점검하고 참고용 예상범위를 계산합니다.
4. **청구기한Dday_이혼서류준비_체크리스트**로 재산분할·분할연금·위자료 관련 청구기한을 모두 확인하고, 준비해야 할 서류 20종의 상태를 점검합니다.
5. **의뢰접수_고객리포트_템플릿**으로 의뢰를 접수하고, 계산 결과를 고객용 리포트로 정리해 전달합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기·체크리스트·템플릿 5종 훑어보기** — 어떤 파일이 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 의뢰인) 조건으로 직접 테스트하기** — 실제 엑셀 파일에 실제 재산·채무·혼인 조건을 넣어보고, 대한법률구조공단(klac.or.kr) 법률상담·대법원 종합법률정보(glaw.scourt.go.kr) 판례 검색 결과와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트 가격을 정한 뒤, 상품명에 "계산기", "이혼", "재산분할", "위자료"라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 확정 재산분할액·위자료가 아니라 **참고용 추정 계산 도구**입니다. 재산분할 기여도 비율과 위자료 예상범위는 법정 산정표가 없는 법원의 판단 영역이며, 사건마다 다르게 결정됩니다. 청구기한(제척기간·소멸시효) 관련 법령과 판례 경향도 바뀔 수 있으므로, 실제 적용 전 반드시 대한법률구조공단(klac.or.kr)·변호사 상담으로 최신 기준을 재확인하세요. 특히 재산분할은 명의가 아닌 실질 기여를 기준으로 하고, 위자료는 유책사유 하나만으로 단정할 수 없으며, 양육비는 재산분할·위자료와 법적 성격이 다른 별개 항목이라는 점을 의뢰인에게 항상 명확히 구분해서 안내해야 합니다. 이 부업은 소송 대리·법적 자문·조정·심판 신청을 대신하는 것이 아니라 계산 정리 대행이라는 점을 상담 시작 전 항상 명확히 안내해, 변호사법 위반(비변호사의 법률사무 취급) 소지가 없도록 서비스 범위를 벗어나지 않게 운영하세요.
