# 업종별 상세페이지 템플릿 5종

> 이 문서는 **『사장님, 그 카피로는 안 팔립니다』(Day05 전자책)** 를 읽고 "그래서 내 상품엔 어떻게 적용하지?"에서 막히는 분들을 위한 실행 템플릿입니다. 책의 방법 8(업종별 템플릿)을 실제로 빈칸만 채우면 완성되는 형태로 구체화했습니다.

## 사용법 3줄 요약

1. 내 상품과 가장 가까운 업종 템플릿 하나를 고릅니다. (완전히 안 맞아도 괜찮습니다 — 요소를 섞어 쓰세요.)
2. 표의 "채워보기" 칸에 내 상품 정보를 직접 채우거나, 그대로 클로드에 붙여넣고 "이 표를 채워줘, [상품 정보]는 이거야"라고 요청하세요.
3. 다 채운 표를 순서대로 나열하면 그게 상세페이지 초안입니다. 문장을 다듬는 건 그다음입니다.

## 2026년 상세페이지는 이렇게 바뀌었습니다

최근 이커머스 트렌드를 조사해보니, 상세페이지 구조가 예전보다 훨씬 "모듈화·짧게" 바뀌는 흐름이 뚜렷합니다.

- **모듈형 구조가 표준이 되었습니다.** [히어로 컷 → 핵심 혜택 3개 → 구성/옵션 → 사용 시나리오 → 리뷰 → FAQ → CTA] 순서로, 한 화면(한 스크롤)에 메시지 하나만 담는 짧고 강렬한 호흡이 대세입니다.
- **정보 밀도를 의도적으로 낮춥니다.** 상단은 감성 이미지 한 장으로 시선을 잡고, 하단부터 구성·혜택·신뢰 요소를 또렷하게 모듈로 쪼개어 가독성을 높입니다.
- **플랫폼별 권장 이미지 규격**: 스마트스토어는 가로 860px(네이버 공식 권장), 쿠팡은 가로 780px(셀러 통용 기준)입니다. 래피드 등 PDF/디지털 콘텐츠 판매 플랫폼은 규격보다 "표지+목차 미리보기" 조합이 더 중요합니다.

아래 5개 템플릿은 모두 이 **[히어로 컷 → 핵심 혜택 3개 → 구성/옵션 → 사용 시나리오 → 리뷰 → FAQ → CTA]** 7모듈 구조를 뼈대로, 업종마다 강조점만 다르게 채웠습니다.

---

## 템플릿 1 — 뷰티/화장품

**강조 순서**: 성분 → 효과 → 후기 → 비교
**핵심 포인트**: 성분 안전성, 사용 전후 변화

| 모듈 | 이 모듈에서 할 일 | 내 상품 채우기 |
|---|---|---|
| 히어로 컷 | 사용 전후 변화가 한눈에 보이는 이미지 + 결과 한 문장 | |
| 핵심 혜택 3개 | 대표 성분 3가지 + "그래서 피부가 어떻게 되는지"를 짝지어 3줄 | |
| 구성/옵션 | 용량, 세트 구성, 피부타입별 옵션 | |
| 사용 시나리오 | 아침/저녁, 계절별, 다른 제품과의 조합 사용법 | |
| 리뷰 | 실제 사용 전후 후기 2~3건 (없으면 체험단 진행) | |
| FAQ | 성분 알레르기, 임산부 사용 가능 여부, 유통기한 | |
| CTA | "지금 시작하고 4주 후 달라진 피부 확인하기" 류 | |

**예시** — "히알루론산 2% 저분자 캡슐"(성분) → "발라도 안 끈적, 속은 촉촉"(결과)

---

## 템플릿 2 — 식품

**강조 순서**: 맛/신선도 → 원산지 → 후기 → 보관법
**핵심 포인트**: 먹는 상상이 가능한 묘사

| 모듈 | 이 모듈에서 할 일 | 내 상품 채우기 |
|---|---|---|
| 히어로 컷 | 먹음직스러운 완성 이미지 + 맛을 상상하게 하는 한 문장 | |
| 핵심 혜택 3개 | 신선도/원산지/조리법 중 가장 강한 것 3가지 | |
| 구성/옵션 | 중량, 세트 구성, 개별포장 여부 | |
| 사용 시나리오 | 데워먹기/그대로/응용 레시피 1~2개 | |
| 리뷰 | "재구매했어요" 류 실제 후기, 별점 분포 | |
| FAQ | 보관법(냉장/냉동), 유통기한, 알레르기 유발 성분 | |
| CTA | "오늘 주문하면 [배송일]에 받아보세요" 류 | |

**예시** — "산지 직송 당일 수확"(원산지) → "밭에서 딴 그날 맛 그대로"(결과)

---

## 템플릿 3 — 전자기기/가전

**강조 순서**: 문제 → 스펙 비교 → 사용 장면 → A/S
**핵심 포인트**: 경쟁 제품과의 명확한 비교표

| 모듈 | 이 모듈에서 할 일 | 내 상품 채우기 |
|---|---|---|
| 히어로 컷 | 제품이 해결하는 불편 상황 + 핵심 결과 한 문장 | |
| 핵심 혜택 3개 | 경쟁 제품 대비 우위 스펙 3가지 (숫자로) | |
| 구성/옵션 | 색상, 용량/사양, 구성품(박스 내용물) | |
| 사용 시나리오 | 집/사무실/이동 중 등 실제 사용 장면 2~3개 | |
| 리뷰 | 사용 기간별 후기(1주/1개월 사용기) | |
| FAQ | A/S 기간, 고장 시 대응, 호환 기기 | |
| CTA | "이 가격, 지금 조건에서만" 류 (재고/기간 한정 시) | |

**예시** — "노이즈 캔슬링 -32dB"(스펙) → "지하철에서도 조용한 사무실처럼"(결과)

---

## 템플릿 4 — 서비스(컨설팅·대행)

**강조 순서**: 문제 → 과정 → 결과 사례 → 가격
**핵심 포인트**: 프로세스를 투명하게 공개

| 모듈 | 이 모듈에서 할 일 | 내 상품 채우기 |
|---|---|---|
| 히어로 컷 | 고객이 겪는 문제 상황 + 서비스 후 결과 한 문장 | |
| 핵심 혜택 3개 | 진행 과정 3단계 요약 (신청→진행→결과) | |
| 구성/옵션 | 패키지별 차이(기본/스탠다드/프리미엄) | |
| 사용 시나리오 | 실제 진행 사례 Before/After 1~2건 | |
| 리뷰 | 고객 후기(익명 처리 가능), 재의뢰율 | |
| FAQ | 소요 기간, 환불/취소 정책, 담당자 자격 | |
| CTA | "지금 상담 신청하고 [혜택] 받기" 류 | |

**예시** — "3단계 진단→설계→실행 프로세스"(과정) → "뭘 하는지 모르고 맡기지 않아도 됩니다"(결과)

---

## 템플릿 5 — 디지털 콘텐츠(전자책·강의·템플릿)

**강조 순서**: 결과 → 목차 미리보기 → 후기 → FAQ
**핵심 포인트**: 무엇을 얻는지 구체적으로 미리 보여주기

| 모듈 | 이 모듈에서 할 일 | 내 상품 채우기 |
|---|---|---|
| 히어로 컷 | 이 콘텐츠를 다 보면 얻는 결과 한 문장 | |
| 핵심 혜택 3개 | 분량/구성 수치(챕터 수, 프롬프트 개수 등) 3가지 | |
| 구성/옵션 | 파일 형식(PDF 등), 페이지 수, 부록 유무 | |
| 사용 시나리오 | 목차 미리보기 (실제 목차 5~8개 항목) | |
| 리뷰 | 구매자 후기 또는 "제작 과정 공개형" 신뢰 확보 | |
| FAQ | 환불 정책, 업데이트 여부, 관련 상품과의 차이 | |
| CTA | "지금 시작하세요, 방법 1부터 바로 적용해보세요" 류 | |

**예시** — "12가지 방법 + 프롬프트 18개"(구성) → "오늘 읽고 오늘 바로 써먹는 실전서"(결과)
