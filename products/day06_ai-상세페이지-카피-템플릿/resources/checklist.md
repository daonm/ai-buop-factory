# 업종별 상세페이지 실전 체크리스트

> `templates.md`와 `prompt_pack.md`를 실제로 완성까지 끌고 가는 순서표입니다. 오늘 30분 → 이번 주 1차 완성 → 이번 달 확장, 3단계로 나눴습니다.

## 오늘 · 30분

- [ ] 내 상품과 가장 가까운 업종 템플릿 1개 고르기 (`templates.md`)
- [ ] 해당 업종 프롬프트 1번(성분/맛/스펙/과정/목차 관련)으로 핵심 소재 뽑아보기
- [ ] 히어로 컷에 쓸 결과 한 문장 확정하기

## 이번 주 · 1차 완성

- [ ] 7모듈(히어로 컷 → 핵심 혜택 3개 → 구성/옵션 → 사용 시나리오 → 리뷰 → FAQ → CTA) 표를 전부 채우기
- [ ] 해당 업종 프롬프트 5개를 모두 한 번씩 사용해보기
- [ ] 리뷰/후기가 없다면 지인 체험단 3~5건이라도 확보하기 (없으면 "제작 과정 공개형"으로 대체)
- [ ] 이미지 규격 확인 — 스마트스토어 가로 860px, 쿠팡 가로 780px, 래피드는 표지+목차 미리보기 위주
- [ ] 완성된 카피를 판매 채널에 등록하기

## 이번 달 · 확장

- [ ] 다른 업종 템플릿의 모듈도 훑어보고, 내 상품에 맞는 요소를 섞어 반영하기
- [ ] 실제 판매/문의 데이터를 보고 약한 모듈부터 프롬프트로 재작성하기
- [ ] 반응 좋았던 모듈 구성을 다음 상품 상세페이지에도 재사용하기

---

## 참고 — 2026년 상세페이지 모듈 순서

```
히어로 컷 → 핵심 혜택 3개 → 구성/옵션 → 사용 시나리오 → 리뷰 → FAQ → CTA
```

한 화면(한 스크롤)에 메시지 하나만 담는 짧은 호흡이 최근 흐름입니다. 위 순서를 기본 뼈대로 두고, 업종별 강조점만 `templates.md`를 참고해 바꾸세요.

디자인된 버전은 `kit.html`을 열어보세요.
