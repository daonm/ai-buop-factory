# 업종별 상세페이지 프롬프트팩 — 25선

> `templates.md`의 5개 업종 템플릿과 짝을 이루는 프롬프트입니다. 업종마다 5개씩, 표의 "채워보기" 칸을 채울 때 그대로 클로드에 붙여넣으세요. `[대괄호]` 부분만 내 상품 정보로 바꾸면 됩니다.

## 사용법

1. 먼저 `templates.md`에서 내 업종 템플릿을 고릅니다.
2. 표의 각 모듈(히어로 컷, 핵심 혜택 3개 등)을 채울 때, 아래에서 같은 업종의 프롬프트 번호를 찾아 붙여넣습니다.
3. 한 번에 만족스럽지 않으면 "더 짧게", "숫자를 넣어서", "이 톤 말고 담백하게" 등을 이어서 요청하세요.

---

## 뷰티/화장품

**BE1. 성분→효과 전환**
```
다음은 내 화장품의 성분 목록이야: [성분 목록]. 각 성분을 "그래서 피부가 어떻게
되는지" 결과 중심 문장으로 바꿔줘. 과장된 의학적 효능 표현은 피해줘.
```

**BE2. 사용 전후 후기 다듬기**
```
다음은 체험단이 남긴 사용 전후 후기 원문이야: [후기 원문]. 과장 없이,
원문 표현은 살려서 상세페이지에 쓸 문장으로 다듬어줘.
```

**BE3. 피부타입별 페르소나**
```
[제품명]을 살 것 같은 피부타입별(건성/지성/민감성) 페르소나 3명을 만들어줘.
각각 어떤 고민 때문에 이 제품을 찾는지 포함해서.
```

**BE4. 성분 신뢰 문구**
```
[제품명]의 핵심 성분 [성분명]에 대해, 소비자가 안심할 수 있는 신뢰 문구를
2~3개 만들어줘. 근거 없는 과장(부작용 없음 단정 등)은 넣지 말고.
```

**BE5. 숏폼 요약 카피**
```
[제품 상세페이지 전체 카피]를 인스타그램/숏폼 영상 자막용으로 한 화면에
한 메시지만 담기는 짧고 강렬한 문장 5개로 압축해줘.
```

## 식품

**FD1. 맛/신선도 묘사**
```
[식품명]의 맛과 신선도를 먹는 상상이 되도록 감각적으로 묘사해줘.
너무 화려한 수식어 대신 구체적인 감각 표현(식감, 온도, 향)으로.
```

**FD2. 원산지·제조과정 신뢰 문구**
```
[식품명]의 원산지/제조과정 정보를 소비자가 신뢰할 수 있는 문장으로
정리해줘: [원산지/제조 정보]
```

**FD3. 보관법 안내문**
```
[식품명]의 보관법(냉장/냉동/실온)과 유통기한을 고객이 헷갈리지 않게
간결한 안내문으로 만들어줘.
```

**FD4. 활용 레시피 제안**
```
[식품명]을 활용할 수 있는 간단한 레시피 2~3개를 재료·조리시간과 함께
제안해줘. 상세페이지에 넣을 짧은 버전으로.
```

**FD5. 계절/시즌 CTA**
```
[식품명]을 [계절/시즌]에 맞춰 구매를 유도하는 CTA 문구 3개를 만들어줘.
거짓 긴급성(허위 품절 임박 등)은 쓰지 말고.
```

## 전자기기/가전

**EL1. 스펙 비교표**
```
내 제품 [제품명]의 스펙은 [스펙 목록]이야. 경쟁 제품(또는 일반적인 동급
제품) 대비 비교표를 만들어줘. 상대를 비방하지 않는 톤으로.
```

**EL2. 문제-해결 스토리**
```
[제품명]이 해결하는 불편한 상황을 먼저 구체적으로 묘사하고, 이 제품이
어떻게 해결하는지 이어지는 짧은 스토리형 카피를 써줘.
```

**EL3. A/S·보증 안내**
```
[제품명]의 A/S 기간과 고장 시 대응 절차를 고객이 안심할 수 있게
간결하게 정리해줘: [A/S 정책 정보]
```

**EL4. 사용 시나리오**
```
[제품명]을 [집/사무실/이동 중] 등 실제 생활 장면에서 쓰는 모습을
구체적으로 그려주는 문장 2~3개를 만들어줘.
```

**EL5. 경쟁 제품 비교 문구**
```
[제품명]과 비슷한 가격대 경쟁 제품들의 공통적인 약점을 추정하고,
내 제품이 다르게 접근한 차별점 3가지를 담백한 톤으로 만들어줘.
```

## 서비스(컨설팅·대행)

**SV1. 프로세스 투명 공개**
```
[서비스명]의 진행 과정을 신청→진행→결과 3단계로, 고객이 "뭘 하는지
모르고 맡기는" 불안이 없도록 구체적으로 설명해줘.
```

**SV2. Before/After 사례**
```
다음은 실제 진행 사례 정보야: [사례 정보]. 이걸 Before(문제 상황)와
After(결과) 구조로 상세페이지에 쓸 문장으로 정리해줘.
```

**SV3. 신뢰 프로필**
```
[담당자 경력/자격/실적]을 나열이 아니라 "왜 이 사람에게 맡겨도
되는지"가 느껴지는 신뢰 문구로 재구성해줘.
```

**SV4. 상담 신청 CTA**
```
[서비스명]의 상담 신청 문턱을 낮추는 CTA 문구 3~5개와, 신청 버튼
위에 넣을 안심 문구(예: 무료 상담, 부담 없이)를 함께 만들어줘.
```

**SV5. 패키지별 설명**
```
[서비스명]의 패키지 구성(기본/스탠다드/프리미엄 등)을 각각 누구에게
맞는지와 함께 비교표로 정리해줘: [패키지 정보]
```

## 디지털 콘텐츠(전자책·강의·템플릿)

**DC1. 목차 미리보기 카피**
```
다음은 내 [전자책/강의]의 목차야: [목차 목록]. 상세페이지에 넣을
"목차 미리보기" 섹션으로, 각 항목이 궁금해지도록 한 줄씩 다듬어줘.
```

**DC2. 결과 중심 헤드라인**
```
[콘텐츠명]을 다 보면 얻는 결과를 한 문장으로 정리하고, 이를 바탕으로
헤드라인 후보 5개를 만들어줘.
```

**DC3. 구매자 후기 재구성**
```
다음 구매 후기 원문을 상세페이지에 쓸 문장으로 재구성해줘. 과장
없이, 원문 표현은 살려서: [후기 원문]
```

**DC4. 제작 과정 공개형 카피**
```
후기가 아직 없어. [콘텐츠명]을 어떻게 만들었는지 제작 과정을 신뢰가
가도록 담백하게 정리해줘: [제작 과정 정보]
```

**DC5. 업셀 유도 문구**
```
[콘텐츠명]을 구매한 사람에게 자연스럽게 다음 상품([업셀 상품명])을
제안하는 짧은 문구를 만들어줘. 강매 느낌 없이.
```
