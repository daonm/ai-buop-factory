# 실전 템플릿 사용법

이 폴더의 파일은 `kit.html`(전체 워크시트·체크리스트·프롬프트팩)에서 실무에 바로 넣어 쓰기 좋은 두 가지를 파일로 따로 뺀 것입니다.

## 1. `직무별_첨삭_기준표.csv`
엑셀/구글시트/노션에 그대로 열어서 씁니다. 직무군별 강조 포인트, 피해야 할 표현, ATS 키워드 예시, 면접 단골 꼬리질문을 한 눈에 봅니다. 새 고객 직무가 표에 없으면 행을 추가하세요 — 첨삭 건수가 쌓일수록 이 표 자체가 자산이 됩니다.

## 2. `고객_접수_양식.md`
카카오톡 채널, 크몽 메시지, 구글폼 어디에 붙여도 되는 접수 질문지입니다. 첫 응대 메시지에 이 양식을 그대로 복사해서 보내면 왕복 문의 횟수가 줄어듭니다.

## 사용 순서
1. 첫 문의가 오면 `고객_접수_양식.md`를 복사해서 전달
2. 답변이 오면 `직무별_첨삭_기준표.csv`에서 해당 직무 행 확인
3. `kit.html`의 프롬프트팩(A~E)을 순서대로 사용해 첨삭 진행
4. `kit.html`의 체크리스트 4단계로 누락 항목 확인
