# 브리프 인터뷰 & 등록정보 워크시트

클라이언트(위탁판매/사입 셀러)에게 상품 정보를 받을 때 이 워크시트부터 채우세요. (`kit.html`에 채워 쓸 수 있는 디자인 버전이 있습니다.)

## Worksheet 1 — 클라이언트 브리프 인터뷰 시트

| 질문 | 클라이언트 답변 |
|---|---|
| 상품명/카테고리(패션·화장품·식품·생활용품·디지털 중)는? | |
| 위탁판매인가요, 사입인가요? (책임 범위 확인용) | |

| 경쟁 상품과 다른 점은? | |
| 가장 많이 받는 재구매·재주문 후기는? | |
| 내세울 수 있는 숫자(재구매율, 후기 수, 판매량 등)는? | |
| 절대 쓰면 안 되는 표현/과장하면 안 되는 효능은? | |
