# 등록 검수·납품 체크리스트

리서치부터 등록정보 최종확인, 납품까지 순서대로 체크하며 진행하세요. Day25 전자책 방법 6(정책 준수)·7(등록정보 최적화)·8(프로세스 표준화)을 실전 작업 순서로 그대로 옮겼습니다.

## 1단계 — 리서치

- [ ] Worksheet 1로 클라이언트 브리프 인터뷰 진행하기
- [ ] 카테고리(A~E) 확정하고 `등록_프롬프트팩.md`의 A1~A4 프롬프트로 키워드·경쟁사·카테고리 후보 조사하기
- [ ] Worksheet 2로 해당 카테고리의 필수 고시정보 항목이 전부 채워졌는지 1차 확인하기 — 빈칸이 있으면 이 단계에서 클라이언트에게 재요청

## 2단계 — 카피 초안

- [ ] `카테고리별_등록_템플릿_전체모음.md`에서 해당 카테고리의 표준 구조(문제 제기→해결→근거→행동 유도) 가져오기
- [ ] B1~B4 프롬프트로 섹션별 카피·사용 장면·FAQ 초안 작성하기
- [ ] 카테고리 문구 예시의 대괄호를 클라이언트 실제 정보로 교체하기

## 3단계 — 정책준수 검수

- [ ] C1 프롬프트로 2026년 7월 네이버 AI 생성물 정책(AI 생성 이미지·영상 미표시, 실제와 다른 색상·크기·구성 표현, 전문가 오인 가상 인물 사용, 유명인 모방 이미지 사용 금지) 기준 위반 소지 점검하기
- [ ] C4 프롬프트로 카피와 스펙표를 한 줄씩 대조해 스펙에 없는 내용(효능 과장 등) 걸러내기
- [ ] E1~E5 중 해당 카테고리 프롬프트로 법정 고시정보 누락 여부 재점검하기 (화장품 전성분·기능성 표현, 식품 알레르기 표시, 생활용품/디지털 KC 인증 등)
- [ ] 위반 소지가 있는 표현은 전부 수정 완료했는지 최종 확인

## 4단계 — 등록정보 최종확인

- [ ] A4로 추천받은 카테고리 후보를 실제 스마트스토어 카테고리 트리와 대조해 최종 확정하기
- [ ] C2 프롬프트로 옵션명(색상/사이즈 등) 표기 통일하기
- [ ] C3 프롬프트로 검색어 필드에 넣을 키워드가 상품 속성과 실제로 일치하는지 재확인하기
- [ ] Worksheet 2의 카테고리별 고시정보 체크박스를 등록 화면 필드와 1:1로 대조하며 최종 입력하기
- [ ] 가격·배송정보·교환/환불 정책까지 등록 직전 상태로 정리하기

## 5단계 — 납품 & 사후관리

- [ ] Worksheet 4로 견적 확정하고 납품 범위(등록 직전까지인지, 실제 등록까지인지) 클라이언트에게 명확히 안내하기
- [ ] 완성한 상세페이지·등록정보를 카테고리별로 분류해 포트폴리오로 저장하기

- [ ] 정책이 개정되면(특히 AI 생성물 정책, 카테고리별 고시 기준) 기존 고객에게 반영 필요 여부 먼저 안내하기
