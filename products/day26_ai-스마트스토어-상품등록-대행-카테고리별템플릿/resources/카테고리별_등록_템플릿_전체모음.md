# 카테고리별 등록 템플릿 전체모음

『사진은 있는데, 상세페이지가 없습니다』(Day25 전자책) 방법 5(상세페이지 카피)~9(등록정보 최적화)에서 다룬 구조를, 스마트스토어에서 필수 고시정보가 서로 다른 5개 카테고리(패션/의류잡화, 화장품/뷰티, 식품, 생활용품/리빙, 디지털/가전)에 그대로 채워 넣었습니다.

각 카테고리마다 아래 4가지를 담았습니다.
- **(a) 필수 고시정보 체크리스트** — 전자상거래법(전자상거래 등에서의 상품 등의 정보제공에 관한 고시) 및 개별 법령(화장품법·식품위생법·전기용품안전관리법 등) 기준으로 온라인 판매 시 빠뜨리면 안 되는 항목
- **(b) 상세페이지 표준 구조** — 문제 제기 → 해결 → 근거 → 행동 유도 4단계(Day25 방법 4·6 구조 재사용, 카테고리 특성에 맞게 순서·비중만 조정)
- **(c) 문구 예시 2~3개** — 클라이언트 상품명·스펙만 바꿔 끼우면 되는 실제 문장
- **(d) 검색 최적화 키워드 유형** — 검색어 필드·태그에 넣을 키워드를 유형별로 분류

> **주의 — 고시정보는 법 개정·품목별 세부 기준에 따라 계속 바뀝니다.** 아래 체크리스트는 대행 작업 시작 전 "이 정도는 반드시 확인해야 한다"는 기준선입니다. 실제 등록 직전에는 반드시 스마트스토어 판매자센터의 카테고리별 고시정보 자동입력 항목과 국가법령정보센터(law.go.kr)의 최신 고시 원문을 한 번 더 대조하세요. 이 확인 절차 자체가 `등록_검수_납품_체크리스트.md`의 3단계에 포함되어 있습니다.

## A. 패션/의류잡화

### (a) 필수 고시정보 체크리스트
- [ ] 품명 및 모델명
- [ ] 소재(섬유의 조성 — 겉감/안감/충전재 등 부위별로 구분 표시)
- [ ] 색상
- [ ] 치수(사이즈 표기 기준 — 예: 55/66/66-77, 실측 cm 병기 권장)
- [ ] 제조자(수입자일 경우 수입자, OEM/ODM인 경우 실제 제조원)
- [ ] 제조연월
- [ ] 세탁방법 및 취급 시 주의사항(드라이클리닝/손세탁/건조 방법 등)
- [ ] 제조국(원산지)
- [ ] A/S 책임자와 전화번호(교환·환불 문의처)
- [ ] 품질보증기준(교환/환불 가능 기간·조건)

### (b) 상세페이지 표준 구조 (의류 특화)
1. **문제 제기** — "사진이랑 실물이 다르다"는 의류 카테고리 고질 불신을 정면으로 짚는다.
2. **해결** — 실측 사이즈, 원단 클로즈업, 실제 착용컷으로 "받아보면 이렇다"를 먼저 보여준다.
3. **근거** — 소재 혼용률, 세탁 후 변형 테스트, 재구매율·교환율 숫자로 신뢰를 굳힌다.
4. **행동 유도** — 사이즈 품절·재입고 불가 등 한정성 + "지금 사이즈표 확인하고 담기" CTA.

### (c) 문구 예시
- 문제 제기: "사진은 예쁜데 받아보면 다른 옷, [상품명]은 다릅니다."
- 해결: "겉감 [소재명] [혼용률]%, 실측 사이즈를 [사이즈 종류] 개 구간으로 나눠 그대로 공개합니다."
- 근거: "이 [카테고리명] 재구매율 [숫자]%, 사이즈 교환 요청률 [숫자]% 미만."
- 행동 유도: "이 컬러, 재입고 계획 없습니다. 지금 사이즈 확인하고 담아두세요."

### (d) 검색 최적화 키워드 유형
- 속성형: [소재명]+[아이템명] (예: "니트가디건", "린넨원피스")
- 상황형: [계절]+[상황]+[아이템명] (예: "가을출근룩 니트")
- 사이즈/핏형: [핏]+[아이템명] (예: "오버핏 후드")
- 브랜드/스타일형: [스타일 태그]+[아이템명] (예: "미니멀 셔츠")

## B. 화장품/뷰티

### (a) 필수 고시정보 체크리스트 (화장품법 기준)
- [ ] 화장품의 명칭
- [ ] 화장품책임판매업자 및 제조업자(또는 제조판매업자) 상호
- [ ] 내용물의 용량 또는 중량
- [ ] 제조번호(배치넘버)
- [ ] 사용기한 또는 개봉 후 사용기간(예: "PAO 12M")
- [ ] 가격
- [ ] 전성분(포장에 표시된 전성분 그대로, 임의로 누락·요약 금지)
- [ ] 기능성 화장품의 경우 "기능성화장품" 문구 및 심사받은 효능·효과만 표기
- [ ] 사용할 때의 주의사항(피부 이상반응 시 대응법 등)
- [ ] 제조국(원산지) / 수입화장품의 경우 수입관리번호

### (b) 상세페이지 표준 구조 (뷰티 특화)
1. **문제 제기** — 피부 고민(트러블/건조/탄력 등)을 구체적 상황으로 제시.
2. **해결** — 핵심 성분·제형·사용감을 스펙표 기반으로 소개(효능 과장 없이).
3. **근거** — 임상/테스트 결과, 성분표, 재구매율, 실사용 후기 인용.
4. **행동 유도** — 기간 한정 구성/사은품 + "지금 피부 타입 확인하고 담기" CTA.

### (c) 문구 예시
- 문제 제기: "아침마다 당기고 각질 일어나는 피부, [상품명] 하나로 루틴을 줄여보세요."
- 해결: "[핵심성분명] 함유, [제형](예: 크림/앰플) 타입으로 [효능] 목적에 맞춰 설계했습니다."
- 근거: "전성분·사용기한은 제품 뒷면 그대로 표기했고, 재구매율 [숫자]%입니다."
- 행동 유도: "이번 기획 구성, [수량] 한정입니다. 지금 피부 타입에 맞는 라인 확인하세요."

> **정책준수 주의** — "미백/주름개선/자외선차단" 등 기능성 효능은 실제로 식약처 심사를 받은 제품에만 쓸 수 있습니다. 스펙표에 없는 효능(예: "여드름이 사라진다", "즉각 재생") 표현은 절대 만들어내지 않습니다(Day25 방법 5·6 원칙 그대로 적용).

### (d) 검색 최적화 키워드 유형
- 고민형: [피부고민]+[제품군] (예: "건성피부 크림", "모공 세럼")
- 성분형: [핵심성분]+[제형] (예: "히알루론산 앰플")
- 상황형: [사용시점]+[제품군] (예: "아침루틴 스킨케어")
- 타깃형: [연령대/성별]+[제품군] (예: "20대 남성 스킨")

## C. 식품

### (a) 필수 고시정보 체크리스트 (식품위생법·식품 등의 표시·광고에 관한 법률 기준)
- [ ] 식품의 유형(예: 과자, 음료류, 건강기능식품 등 분류)
- [ ] 생산자(제조원) 및 소재지 / 수입식품은 수입원
- [ ] 유통기한 또는 소비기한
- [ ] 원재료명 및 함량(많이 쓴 순서대로)
- [ ] 내용량(중량/용량/개수)
- [ ] 영양성분(열량·나트륨·탄수화물·당류·지방·트랜스지방·포화지방·단백질 — 해당 품목 기준)
- [ ] 알레르기 유발물질 표시(난류, 우유, 메밀, 땅콩, 대두, 밀, 고등어, 게, 새우, 돼지고기, 복숭아, 토마토, 아황산류, 호두, 닭고기, 쇠고기, 오징어, 조개류 등 원재료 사용 시 필수)
- [ ] 보관방법 및 취급 시 주의사항
- [ ] 원산지(농산물/수산물/축산물 각각 표기 기준 확인)
- [ ] 소비자 안전을 위한 주의사항(질식 위험, 이물 주의 등 해당 시)

### (b) 상세페이지 표준 구조 (식품 특화)
1. **문제 제기** — "먹거리인데 뭐가 들었는지 모르고 산다"는 불안을 짚는다.
2. **해결** — 원재료·제조 공정·보관법을 투명하게 공개해 안심시킨다.
3. **근거** — 재구매율, 인증(HACCP 등 실제 보유 시), 실제 섭취 후기.
4. **행동 유도** — 신선도 기반 한정 수량 + "오늘 주문하면 언제 도착" CTA.

### (c) 문구 예시
- 문제 제기: "이 가격에 이 정도 재료가 들어갈 수 있냐고 물으신다면, [상품명]입니다."
- 해결: "원재료는 [주요 원재료]가 [비율]%, 유통기한은 [기간], 냉장 보관 기준입니다."
- 근거: "알레르기 유발물질은 [해당 성분]이 포함되어 있고, 재구매 주문이 전체의 [숫자]%입니다."
- 행동 유도: "매일 소량 생산이라 오늘 주문분은 [수량]개 한정입니다. 지금 담으시면 [배송일] 도착합니다."

> **정책준수 주의** — "다이어트에 효과", "질병 예방/치료" 같은 표현은 건강기능식품 인정 문구가 아닌 이상 절대 쓰지 않습니다. 알레르기 유발물질 누락은 소비자 안전과 직결되므로 스펙표에 원재료명이 하나라도 빠져 있으면 반드시 클라이언트에게 재확인을 요청합니다.

### (d) 검색 최적화 키워드 유형
- 상황형: [상황]+[식품명] (예: "야식 안주", "아침대용 시리얼")
- 재료형: [핵심 원재료]+[식품명] (예: "국내산 사과즙")
- 보관/조리형: [보관방식]+[식품명] (예: "냉동 만두", "에어프라이어 간식")
- 인증/속성형: [속성]+[식품명] (예: "무첨가 잼", "글루텐프리 쿠키")

## D. 생활용품/리빙

### (a) 필수 고시정보 체크리스트
- [ ] 품명 및 모델명
- [ ] 재질/구성(주요 소재, 세트 구성품 개수)
- [ ] 크기(치수) 및 중량
- [ ] KC 인증 여부(안전확인대상·공급자적합성확인대상 생활용품인 경우 인증번호 표기, 해당 없으면 "해당사항 없음" 명시)
- [ ] 색상
- [ ] 제조자(수입자) 및 제조국
- [ ] 제조연월
- [ ] 취급 시 주의사항(파손 위험, 아동 사용 주의 등)
- [ ] A/S 책임자와 전화번호
- [ ] 품질보증기준(교환/환불 조건, 파손 시 대응)

### (b) 상세페이지 표준 구조 (생활용품 특화)
1. **문제 제기** — 기존 제품의 불편함(공간 차지, 내구성, 사용법 복잡 등)을 구체적으로 짚는다.
2. **해결** — 치수·구성품·재질로 "우리 집에 맞는지" 바로 판단 가능하게 보여준다.
3. **근거** — 내구성 테스트, KC 인증 유무, 실사용 후기·재구매율.
4. **행동 유도** — 세트 구성 할인/한정 재고 + "지금 사이즈(치수) 확인하고 담기" CTA.

### (c) 문구 예시
- 문제 제기: "정리했는데도 자꾸 어질러지는 이유, 수납 크기가 안 맞아서일 수 있습니다."
- 해결: "[재질명] 소재, 가로×세로×높이 [치수]cm, [구성품 개수]개 구성으로 [공간명]에 맞췄습니다."
- 근거: "KC 안전확인 인증 [인증번호 또는 '해당없음'], 실사용 후기 평점 [숫자]."
- 행동 유도: "이번 구성 재고 [수량]개 남았습니다. 지금 사이즈 확인하고 장바구니에 담아두세요."

### (d) 검색 최적화 키워드 유형
- 공간형: [공간명]+[제품군] (예: "베란다 수납장", "욕실 선반")
- 기능형: [기능]+[제품군] (예: "접이식 테이블", "미끄럼방지 매트")
- 소재형: [소재명]+[제품군] (예: "스테인리스 수세미")
- 세트형: [구성수]+[제품군] (예: "3종세트 정리함")

## E. 디지털/가전

### (a) 필수 고시정보 체크리스트 (전기용품 및 생활용품 안전관리법 기준)
- [ ] 품명 및 모델명
- [ ] KC 인증 마크 및 인증번호(안전인증/안전확인/공급자적합성확인 대상 여부 확인)
- [ ] 정격전압, 정격전류(또는 소비전력)
- [ ] 정격주파수(해당 시)
- [ ] 제조자(수입자) 및 제조국
- [ ] 제조연월(또는 로트번호)
- [ ] KC 인증 시험기관 및 인증일자(가능하면)
- [ ] A/S 책임자와 전화번호(국내 실제 연락 가능한 번호)
- [ ] 품질보증기준(무상 A/S 기간, 유상 A/S 조건)
- [ ] 주요 사양(용량, 크기, 무게, 부속품 구성)

### (b) 상세페이지 표준 구조 (디지털/가전 특화)
1. **문제 제기** — 기존 제품의 스펙 부족·고장 잦음·A/S 어려움 등 실사용 불편을 짚는다.
2. **해결** — 핵심 스펙(성능·용량·전력)을 표로 명확히 제시해 비교 판단을 돕는다.
3. **근거** — KC 인증 정보, 실측 성능 테스트, A/S 정책, 재구매·재주문율.
4. **행동 유도** — 사은품/구성 한정 + "지금 스펙 비교하고 담기" CTA.

### (c) 문구 예시
- 문제 제기: "스펙표만 보고 샀는데 실제론 다르더라, [상품명]은 그 걱정을 없앴습니다."
- 해결: "정격전압 [값], 소비전력 [값], KC 인증번호 [번호]까지 그대로 공개합니다."
- 근거: "A/S는 [지역/전국] [연락처]로 바로 연결되고, 무상 A/S 기간은 [기간]입니다."
- 행동 유도: "이번 구성엔 [사은품/부속품]까지 포함, 재고 [수량]대 남았습니다. 지금 스펙 확인하고 담으세요."

### (d) 검색 최적화 키워드 유형
- 스펙형: [용량/사양]+[제품군] (예: "1500W 에어프라이어")
- 상황형: [사용상황]+[제품군] (예: "자취생 전자레인지")
- 브랜드/호환형: [호환기기]+[제품군] (예: "아이폰 고속충전기")
- 인증/신뢰형: [인증]+[제품군] (예: "KC인증 보조배터리")

## 카테고리 매칭이 애매할 때

| 클라이언트 상품 | 가장 가까운 카테고리 |
|---|---|
| 신발·가방·모자·액세서리 | A. 패션/의류잡화 |
| 향수·헤어제품·바디케어 | B. 화장품/뷰티 |
| 건강기능식품·다이어트보조식품 | C. 식품 (단, 기능성 표현은 별도 심사 문구 확인 필수) |
| 인테리어 소품·주방용품·수납용품 | D. 생활용품/리빙 |
| 소형가전·PC주변기기·모바일액세서리 | E. 디지털/가전 |

5개 중 애매한 상품은 두 카테고리의 고시정보 체크리스트를 모두 확인하는 것이 안전합니다(예: 전기 찜질 안대 → D+E 둘 다 확인).
