# AI 세금·급여 계산 자동화 — 실전 계산기 템플릿팩 사용 가이드

『세무사가 아니어도, 계산기는 팔 수 있습니다』(Day23 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 방법 3~7(리서치·설계·수식·검증)까지 이미 끝내둔 완성본 엑셀 계산기 4종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 구성 파일

| 파일 | 내용 |
|---|---|
| `kit.html` | 계산기 4종 빠른 참고표(입력·결과 예시) + 패키지·검증 워크시트 + 판매 준비 체크리스트를 한눈에 보기 좋게 디자인한 버전 (브라우저로 열거나 PDF로 인쇄) |
| `네_가지_계산기,_오늘_바로_파세요.pdf` | `kit.html`을 인쇄한 PDF 버전 (오프라인·인쇄용) |
| `4대보험료_계산기.xlsx` | 월 급여를 입력하면 국민연금·건강보험·장기요양보험·고용보험의 근로자·사업주 부담분을 자동 계산 |
| `종합소득세_예상세액_계산기.xlsx` | 연 수입·필요경비·소득공제를 입력하면 8단계 누진세율을 자동 적용해 과세표준·산출세액·지방소득세까지 계산, 3.3% 원천징수 환급/추가납부 여부도 확인 |
| `퇴직금_계산기.xlsx` | 퇴직 전 3개월 급여·상여금·연차수당·재직일수를 입력하면 평균임금과 예상 퇴직금을 자동 계산 |
| `급여명세서_자동생성_시트.xlsx` | 지급 항목(기본급·수당)만 입력하면 4대보험 공제와 근로소득세 근사치까지 자동 계산해 급여명세서 형태로 정리 |

## 엑셀 파일 공통 구조

네 파일 모두 같은 3단 구조로 만들었습니다.

1. **면책조항 시트** — "참고용 계산 도구이며 세무 상담·신고 대행이 아니다"라는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **기준표 시트** — 국민연금·건강보험 요율, 종합소득세 구간표처럼 매년 바뀌는 숫자만 따로 모아뒀습니다(2026년 9월 확인 기준: 국민연금 9.5%, 건강보험료율 7.19%). **요율이 개정되면 이 시트 숫자만 교체하면 전체 계산기가 자동으로 갱신됩니다** — 재판매·연간 갱신 상품으로 확장할 때 이 구조를 그대로 활용하세요.
3. **계산기(또는 급여명세서) 시트** — 노란색 칸에 숫자를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기 4종 훑어보기** — 어떤 계산기가 어떤 고객에게 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인 상황으로 직접 테스트하기** — `kit.html`의 Worksheet 2(교차검증)를 참고해 실제 엑셀 파일에 본인 급여·소득 정보를 넣어보고, 국민연금공단·국세청 홈택스 등 공식 계산기와 결과를 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트/구독 가격을 정한 뒤, 상품명에 "계산기", "템플릿"이라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.
