# 그 엑셀, 아무도 안 읽습니다
### AI로 데이터를 진짜 읽히는 리포트로 바꾸는 법 — 원본 데이터만 던지면 되는 프롬프트 16개

---

## 프롤로그 — 데이터는 쌓이는데, 아무도 안 봅니다

카페 사장님의 POS 정산 엑셀, 온라인 쇼핑몰의 주문 데이터, 마케팅 담당자의 광고 성과표. 다들 매달 꼬박꼬박 쌓입니다. 그런데 정작 그 파일을 열어서 "그래서 이번 달에 뭘 해야 하는지"까지 읽어내는 사람은 드뭅니다. 데이터가 없어서가 아니라, **데이터를 리포트로 바꿔줄 시간과 안목이 없어서**입니다.

이 지점에서 AI 데이터 분석 리포트 대행이라는 부업이 생깁니다. 최근 클로드 같은 AI는 엑셀·CSV 파일을 직접 열어서 수식 구조를 이해하고, 파이썬 코드를 실행해 집계·시각화까지 처리하는 수준까지 왔습니다. 크몽에는 이미 5,000원짜리 스팟 리포트부터 데이터분석 대행 서비스가 수백 건 등록돼 있고, 정부의 AI 기반 소상공인 매출 예측 서비스 시범 사업에서는 도입 업체의 평균 매출이 7.2% 오르고 재고 폐기율이 34% 줄어드는 결과까지 나왔습니다. **"데이터를 해석해서 다음 행동을 알려주는 사람"에 대한 수요가 이미 숫자로 증명되고 있는 셈**입니다.

이 책이 다루는 건 복잡한 통계학이 아닙니다. **AI에게 데이터 정제와 계산을 맡기고, 사람은 "이 숫자가 무슨 의미인지"를 판단해 리포트로 엮어내는 방법**입니다. 당신이 할 일은 대학원 수준의 분석 기법이 아니라, 원본 데이터를 리포트로 바꾸는 순서를 아는 것뿐입니다.

## 1. 왜 지금 AI 데이터 분석 리포트 서비스인가

데이터 분석 리포트 대행은 예전에도 있던 시장이지만, AI 시대가 되면서 진입장벽이 크게 낮아졌습니다.

- **데이터는 쌓이는데 볼 시간이 없습니다.** 소상공인·1인 사업자일수록 데이터를 뽑을 시스템은 갖고 있어도(포스기, 쇼핑몰 관리자 페이지), 그걸 분석할 시간과 지식은 없는 경우가 대부분입니다.
- **표는 있지만 "그래서 뭘 해야 하는지"가 없습니다.** 엑셀로 정리된 매출표, 방문자 통계는 그 자체로는 결론이 아닙니다. "이번 달 매출 3,200만 원"이라는 숫자만으로는 다음 행동이 나오지 않습니다.
- **AI가 직접 파일을 열어 분석하는 시대가 됐습니다.** 예전에는 분석가가 직접 함수를 짜야 했던 집계·시각화 작업을, 이제는 AI에게 원본 파일을 주고 "이 데이터에서 중요한 걸 뽑아줘"라고 요청하는 것만으로 상당 부분 처리할 수 있습니다.

결국 지금 필요한 건 "복잡한 통계 기법을 배우는 것"이 아니라, **AI가 뽑아준 숫자를 사람이 읽는 이야기로 엮어내는 순서를 아는 것**입니다. 이 책의 모든 방법은 이 원칙 하나로 통합니다 — AI에게 정제와 계산을 맡기고, 사람은 "이 숫자가 사장님에게 무슨 의미인지"를 판단하는 역할을 합니다.

## 2. 시작 전에 딱 3가지만 준비하세요

1. **AI 챗봇(파일 분석 가능한) 계정** — 클로드처럼 엑셀·CSV 파일을 직접 열어서 구조를 이해하고 계산까지 실행하는 도구가 유리합니다. 파일을 통째로 주고 "이 안에서 정제·계산·요약을 해줘"라고 맡길 수 있어야 작업 속도가 납니다.
2. **연습용 데이터 3~5건** — 본인의 가계부, 사이드 프로젝트 방문자 통계, 공공데이터포털의 공개 데이터셋, 혹은 지인 소상공인의 매출 데이터(허락받고) 등으로 충분합니다.
3. **판매 채널 하나** — 데이터분석 카테고리가 이미 활성화된 크몽, 또는 사업자등록 없이 시작할 수 있는 **래피드(Latpeed)**를 기준으로 설명합니다.

통계학 학위나 데이터 분석 실무 경력이 없어도 괜찮습니다. "AI에게 계산을 맡기고 결론만 사람이 판단하는 방법"을 이 책대로 따라 하면, 오늘 첫 샘플 리포트를 만들 수 있습니다.

## 3. 방법 1 — 리포트 유형별 템플릿 정하기

리포트라고 다 같은 리포트가 아닙니다. 어떤 데이터를 누구에게 주는지에 따라 봐야 할 지표가 다릅니다. 먼저 내가 다룰 리포트 유형을 정해두면 이후 모든 작업의 틀이 잡힙니다.

| 리포트 유형 | 핵심 지표 | 주 고객 |
|---|---|---|
| 매출 리포트 | 매출·객단가·재방문율 | 카페·음식점·소상공인 |
| 마케팅 성과 리포트 | CTR·전환율·CAC(획득단가) | 온라인 마케터·소상공인 |
| 설문·피드백 리포트 | 만족도 점수·키워드 빈도 | 소규모 서비스 운영자 |
| SNS·콘텐츠 리포트 | 도달·참여율·팔로워 증감 | 1인 창작자·개인 브랜드 |

### 진행 순서
1. 위 표 중 내가 가장 자신 있게 설명할 수 있는 유형 1개를 먼저 정한다 (여러 개를 동시에 시작하지 않는다).
2. 해당 유형의 샘플 데이터(연습용)를 구해 AI에게 "이 데이터로 만들 수 있는 리포트 항목"을 먼저 물어본다.
3. AI가 제안한 항목 중 실제로 매달 반복해서 쓸 수 있는 항목만 골라 "이 유형의 표준 리포트 목차"로 고정한다.
4. 표준 목차가 정해지면, 다음 고객이 비슷한 유형의 데이터를 가져와도 목차를 재사용해 속도를 낼 수 있다.

> 참고 — 리포트 유형은 한 번에 하나만 깊게 파는 것이 유리합니다. 처음부터 여러 유형을 다 하려고 하면 각 유형의 표준 목차가 흐릿해집니다.

## 4. 방법 2 — 원본 데이터 클렌징 프롬프트로 정제하기

고객이 보내는 원본 데이터는 대부분 지저분합니다. 날짜 형식이 제각각이고, 중복 행이 섞여 있고, 빈 값이 그대로 남아 있는 경우가 많습니다. 이 정제 단계를 AI에게 먼저 맡기면 이후 분석 전체의 정확도가 올라갑니다.

### 진행 순서
1. 원본 데이터를 AI에게 그대로 주고 "중복 행, 빈 값, 날짜 형식 불일치"를 찾아 목록으로 정리해달라고 요청한다.
2. 빈 값을 어떻게 처리할지(제외/0으로 채움/평균으로 채움)를 데이터 성격에 맞게 사람이 결정하고, AI에게 해당 규칙대로 정제해달라고 요청한다.
3. 정제된 데이터의 행 수와 원본 행 수를 대조해, 얼마나 제외됐는지 반드시 확인한다.
4. 정제 규칙(무엇을 어떻게 처리했는지)을 짧게 메모해둔다 — 나중에 고객이 "왜 이 행이 빠졌나요"라고 물었을 때 바로 설명할 수 있어야 한다.

> 주의 — 정제 과정에서 임의로 값을 지어내면 안 됩니다. 빈 값을 채울 때는 반드시 그 근거(평균, 직전 값 등)를 리포트에 남겨야 합니다.

---

## 5. 방법 3 — 핵심 지표(KPI) 자동 추출하기

정제된 데이터에서 모든 숫자를 다 보여줄 필요는 없습니다. 고객이 실제로 궁금해할 핵심 지표 몇 개만 뽑아 보여주는 것이 리포트의 핵심입니다.

### 진행 순서
1. 정제된 데이터와 함께 "이 업종에서 가장 중요한 핵심 지표 5개가 뭘지" AI에게 먼저 물어본다.
2. AI가 제안한 지표 중 방법 1에서 정한 리포트 유형의 핵심 지표와 겹치는 것 위주로 최종 3~5개를 고른다.
3. 각 지표의 이번 기간 수치와, 비교 가능한 이전 기간(전월/전주) 수치를 함께 계산해달라고 요청한다.
4. 계산된 수치는 반드시 원본 데이터의 일부를 직접 확인해 검산한다 (방법 9에서 자세히 다룹니다).

## 6. 방법 4 — 시각화(차트) 구성 설계하기

같은 숫자라도 표로 보여줄 때와 그래프로 보여줄 때 전달력이 다릅니다. 어떤 지표를 어떤 차트로 보여줄지 미리 정해두면 리포트가 훨씬 읽기 쉬워집니다.

### 진행 순서
1. 방법 3에서 뽑은 핵심 지표별로 어떤 차트 종류(막대·선·파이 등)가 적합한지 AI에게 이유와 함께 제안받는다.
2. 시간에 따른 추이(월별 매출 등)는 선 그래프, 항목 간 비교(메뉴별 판매량 등)는 막대 그래프, 구성 비율(채널별 유입 비중 등)은 파이 차트로 기본 원칙을 정한다.
3. 차트 하나당 "이 차트에서 봐야 할 포인트"를 한 문장으로 캡션에 넣어, 그래프만 보고 지나치지 않도록 만든다.
4. 차트 개수는 5~7개 이내로 제한한다 — 너무 많으면 오히려 어떤 게 중요한지 흐려진다.

## 7. 방법 5 — 인사이트·원인 분석 문장으로 만들기

숫자를 나열하는 것과 "왜 이런 숫자가 나왔는지"를 설명하는 것은 완전히 다른 작업입니다. 이 단계가 리포트의 가치를 가장 크게 좌우합니다.

### 진행 순서
1. 특정 지표가 오르거나 내린 구간을 짚어, "이 변화의 원인으로 데이터 안에서 확인 가능한 요인"을 AI에게 추정해달라고 요청한다.
2. AI가 제시한 원인 중 데이터로 뒷받침되지 않는 추측성 내용은 "확인 필요" 문구를 붙이거나 리포트에서 제외한다.
3. 요일별·상품별·채널별 등으로 데이터를 나눠 성과가 좋은 상위 항목과 부진한 하위 항목을 비교해, 인사이트에 구체성을 더한다.
4. 최종 인사이트 문장은 "숫자 + 원인 추정 + 근거"의 3단 구조로 정리한다 (예: "화요일 매출이 20% 낮습니다. 이는 화요일 방문자 수 자체가 다른 요일보다 적기 때문으로 보입니다. 최근 4주 데이터에서 동일한 패턴이 반복됐습니다.").

> 주의 — AI가 만든 원인 분석은 상관관계이지 인과관계 증명이 아닙니다. 확신이 안 서는 부분은 "~로 추정됩니다", "추가 확인이 필요합니다"로 표현해 과장하지 않습니다.

## 8. 방법 6 — 액션 아이템(다음 스텝) 도출하기

리포트를 읽고도 "그래서 뭘 하면 되나요"라는 질문이 나오면 그 리포트는 실패한 것입니다. 마지막은 항상 실행 가능한 다음 스텝으로 마무리합니다.

### 진행 순서
1. 방법 5에서 정리한 인사이트를 바탕으로, 다음 2주 안에 실행할 수 있는 구체적인 액션 아이템을 AI에게 3개 제안받는다.
2. 각 액션 아이템에 우선순위(가장 효과가 크고 비용이 적게 드는 순)를 매긴다.
3. "이 액션을 실행하면 어떤 지표가 개선될 것으로 기대되는지"를 한 문장씩 붙여, 다음 리포트에서 실제로 개선됐는지 확인할 수 있게 만든다.
4. 액션 아이템은 리포트 맨 앞이나 맨 뒤, 눈에 잘 띄는 위치에 별도 박스로 배치한다.

## 9. 방법 7 — 업종별 맞춤 리포트 설계

같은 "매출 데이터"라도 업종마다 봐야 할 포인트가 다릅니다. 업종별 맞춤 리포트는 단가를 올릴 수 있는 차별화 포인트이기도 합니다.

| 업종군 | 강조 포인트 | 피해야 할 표현 |
|---|---|---|
| 카페·음식점 | 시간대별 매출, 재방문율, 메뉴별 기여도 | 막연한 "잘 되고 있다" 식 총평 |
| 이커머스·쇼핑몰 | 전환율, 이탈 구간, 재구매 주기 | 클릭수·조회수만 나열 |
| 마케팅 대행 | 채널별 ROI, CAC 대비 LTV | 단순 노출수만 강조 |
| 1인 창작자·SNS | 참여율 추이, 콘텐츠 유형별 반응 | 팔로워 총량만 언급 |

### 진행 순서
1. 고객의 업종을 확인하고 위 표를 참고해 이번 리포트에서 특히 강조할 지표 1~2개를 정한다.
2. AI에게 해당 업종에서 사장님들이 가장 궁금해하는 질문이 무엇인지 물어 리포트 목차를 보완한다.
3. 방법 3~5에서 뽑은 지표·인사이트를 이 업종별 강조 포인트에 맞춰 재배치한다.
4. 업종별로 반복되는 패턴을 정리해두면, 다음 고객이 같은 업종으로 올 때 작업 속도가 크게 빨라진다.

## 10. 방법 8 — 정기 리포트 자동화 파이프라인 구축하기

한 번 만든 리포트 구조는 매달 반복해서 쓸 수 있어야 진짜 수익이 됩니다. 매번 처음부터 새로 만들면 정기 구독 상품을 팔기 어렵습니다.

### 진행 순서
1. 방법 1~8에서 확정한 목차·지표·차트 구성을 "표준 리포트 템플릿"으로 문서화한다.
2. 새 데이터가 들어올 때마다 AI에게 "이전 리포트와 같은 구조로, 이번 달 데이터로 업데이트해줘"라고 요청해 재사용한다.
3. 매달 바뀌는 부분(핵심 지표 수치, 인사이트, 액션 아이템)과 고정되는 부분(목차, 차트 종류, 톤)을 구분해두면 작업 시간이 크게 줄어든다.
4. 처리 시간을 매달 기록해두고, 일정 건수 이상 쌓이면 어느 단계에서 시간이 가장 많이 드는지 점검해 추가로 자동화한다.

> 참고 — 정기 리포트는 "매번 새로 만드는 상품"이 아니라 "템플릿에 새 데이터를 흘려보내는 상품"이 될수록 마진이 커집니다.

## 11. 방법 9 — 신뢰도 높이는 검증·오류 체크

리포트에서 숫자가 틀리면 신뢰가 한 번에 무너집니다. AI가 계산한 수치라도 반드시 사람이 검증하는 단계를 거쳐야 합니다.

### 진행 순서
1. 핵심 지표 중 2~3개를 골라 원본 데이터에서 직접 손으로 재계산(또는 스프레드시트 함수로 재검산)해 AI의 계산 결과와 대조한다.
2. 합계·평균 등 단순 집계값은 원본 데이터의 행 수, 값의 범위(최댓값·최솟값)와 상식적으로 맞는지 확인한다.
3. 리포트에 사용된 모든 숫자에 "어떤 기간, 어떤 조건의 데이터인지"를 각주 형태로 명시해 오해를 방지한다.
4. 최종 리포트를 AI에게 다시 보여주고 "이 리포트 안에서 앞뒤가 안 맞는 숫자가 있는지" 교차 검토를 한 번 더 요청한다.

> 주의 — 검증 없이 AI 계산 결과를 그대로 리포트에 옮기지 않습니다. 특히 합계·비율 계산은 원본 데이터 일부를 직접 대조하는 습관을 들입니다.

## 12. 방법 10 — 패키지 설계와 가격 책정

| 패키지 유형 | 가격대 | 구성 |
|---|---|---|
| 스팟 리포트 | 10,000~20,000원 | 데이터 1건 업로드 → 요약 리포트 1부(PDF) |
| 정기 리포트 | 월 50,000~100,000원 | 월간 리포트 자동 갱신 + 인사이트 코멘트 |
| 맞춤 대시보드 | 150,000원~ | 엑셀·구글시트 대시보드 템플릿 + 매달 업데이트 |
| 컨설팅 패키지 | 200,000원~ | 리포트 + 30분 화상 인사이트 브리핑 |

### 진행 순서
1. 처음에는 스팟 리포트로 판매 기록과 후기를 빠르게 쌓는다.
2. 후기 10건 이상 쌓이면 정기 리포트를 주력 상품으로 전환하고, 스팟 리포트는 "체험판" 성격으로 유지한다.
3. 맞춤 대시보드는 방법 8(자동화 파이프라인)이 갖춰진 이후에 판매하는 것이 유리하다 — 매달 업데이트 부담이 크기 때문이다.
4. 컨설팅 패키지는 후기와 사례가 충분히 쌓인 뒤, 객단가를 크게 올릴 수 있는 상위 상품으로 추가한다.

## 13. 방법 11 — 크몽·래피드 등록과 판매 페이지

1. **크몽** — 이미 데이터분석·리포트 카테고리가 활성화되어 검색 유입이 꾸준합니다. "AI 활용 속도 + 업종별 맞춤 지표"라는 차별점을 상세페이지 첫 줄에 명시합니다.
2. **래피드(Latpeed)** — 사업자등록 없이 시작할 수 있고, 스레드 등 SNS 홍보와 연결하기 쉽습니다. 리포트 샘플 파일을 미리보기로 첨부하기에도 유리합니다.

### 진행 순서
1. AI에게 서비스 설명을 주고 문제 제기형(이 데이터, 지금 그냥 잠들어 있습니다)과 결과 중심형(리포트 하나로 이렇게 달라집니다) 2가지 상세페이지 카피를 요청한다.
2. 가상의 샘플 데이터로 만든 리포트 전/후 비교 예시(실제 고객 데이터 아님을 명시)를 페이지에 넣는다.
3. 구매를 망설이는 사람이 물어볼 질문(데이터 보안, 소요 시간, 파일 형식 등) 6개를 FAQ로 정리한다.
4. 첫 5건은 후기 확보 목적으로 할인가로 진행하는 것도 고려한다.

## 14. 방법 12 — 고객 응대와 정기구독 전환

스팟 리포트 한 건으로 끝나면 매번 새 고객을 구해야 합니다. 정기 구독으로 전환시키는 것이 이 서비스의 진짜 수익 구조입니다.

### 진행 순서
1. 접수 시 "데이터 형식, 원하는 리포트 유형, 리포트 주기, 특히 궁금한 지표"를 필수로 받는 온보딩 질문지를 사용한다.
2. 스팟 리포트 전달 시 "다음 달에는 이번 달과 비교한 추이까지 볼 수 있다"는 점을 자연스럽게 언급해 정기 구독 필요성을 미리 심어둔다.
3. 리포트 전달 후 1주일 뒤, 실제로 액션 아이템을 실행했는지 가볍게 확인하며 정기 구독을 정중히 제안한다.
4. 정기 구독 고객에게는 매달 리포트 외에 "지난달 대비 눈에 띄는 변화"만 짧게 요약한 알림 메시지를 추가로 보내 재구독률을 높인다.

- C4 액션 아이템 도출 — 이 리포트 내용을 바탕으로, 다음 2주 안에 실행할 수 있는 구체적인 액션 아이템 3개를 우선순위와 함께 제안해줘: [리포트 초안]

- D3 온보딩 질문지 — 신규 고객에게 데이터 리포트 작업을 시작하기 전 받아야 할 정보(데이터 형식, 원하는 지표, 리포트 주기 등)를 체크리스트 질문지로 만들어줘.
