카페 사장님의 POS 정산 엑셀, 쇼핑몰의 주문 데이터, 광고 성과표 — 다들 매달 쌓이지만 아무도 열어보지 않습니다. 데이터가 없어서가 아니라, 리포트로 바꿔줄 시간과 안목이 없어서입니다.

최근 AI는 엑셀·CSV 파일을 직접 열어서 수식 구조를 이해하고, 집계·시각화까지 처리하는 수준까지 왔습니다. 크몽에는 5,000원짜리 스팟 리포트부터 데이터분석 대행 서비스가 이미 수백 건 등록돼 있고, 정부의 AI 기반 소상공인 매출 예측 시범 사업에서는 도입 업체 매출이 평균 7.2% 오르는 결과까지 나왔습니다.

이 책이 다루는 건 복잡한 통계학이 아닙니다. AI에게 데이터 정제와 계산을 맡기고, 사람은 "이 숫자가 무슨 의미인지"를 판단해 리포트로 엮어내는 방법을 오늘부터 시작하는 12가지로 정리했습니다.

01왜 지금 AI 데이터 분석 리포트 서비스인가

데이터 분석 리포트 대행은 예전에도 있던 시장이지만, AI 시대가 되면서 진입장벽이 크게 낮아졌습니다.

  1. 데이터는 쌓이는데 볼 시간이 없습니다. 소상공인·1인 사업자일수록 데이터를 뽑을 시스템은 있어도, 분석할 시간과 지식은 없는 경우가 대부분입니다.
  2. 표는 있지만 "그래서 뭘 해야 하는지"가 없습니다. "이번 달 매출 3,200만 원"이라는 숫자만으로는 다음 행동이 나오지 않습니다.
  3. AI가 직접 파일을 열어 분석하는 시대가 됐습니다. 원본 파일을 주고 "중요한 걸 뽑아줘"라고 요청하는 것만으로 상당 부분 처리할 수 있습니다.

결국 지금 필요한 건 복잡한 통계 기법이 아니라, AI가 뽑아준 숫자를 사람이 읽는 이야기로 엮어내는 순서를 아는 것입니다. AI에게 정제와 계산을 맡기고, 사람은 "이 숫자가 사장님에게 무슨 의미인지"를 판단하는 역할을 합니다.

02시작 전에 딱 3가지만

준비물은 딱 3가지 — 통계학 학위나 분석 실무 경력이 없어도 괜찮습니다
  1. 파일 분석 가능한 AI 챗봇 계정 — 클로드처럼 엑셀·CSV를 직접 열어서 구조를 이해하고 계산까지 실행하는 도구가 유리합니다
  2. 연습용 데이터 3~5건 — 본인 가계부, 사이드 프로젝트 통계, 공공데이터포털 공개 데이터셋 등으로 충분합니다
  3. 판매 채널 하나 — 데이터분석 카테고리가 활성화된 크몽, 또는 사업자등록 없이 시작하는 래피드(Latpeed)

"AI에게 계산을 맡기고 결론만 사람이 판단하는 방법"을 이 책대로 따라 하면, 오늘 첫 샘플 리포트를 만들 수 있습니다.

03리포트 유형별 템플릿 정하기

리포트라고 다 같은 리포트가 아닙니다. 먼저 내가 다룰 리포트 유형을 정해두면 이후 모든 작업의 틀이 잡힙니다.

리포트 유형핵심 지표주 고객
매출 리포트매출·객단가·재방문율카페·음식점·소상공인
마케팅 성과 리포트CTR·전환율·CAC(획득단가)온라인 마케터·소상공인
설문·피드백 리포트만족도 점수·키워드 빈도소규모 서비스 운영자
SNS·콘텐츠 리포트도달·참여율·팔로워 증감1인 창작자·개인 브랜드

진행 순서

  1. 위 표 중 가장 자신 있게 설명할 수 있는 유형 1개를 먼저 정한다 (여러 개를 동시에 시작하지 않는다)
  2. 해당 유형의 샘플 데이터를 구해 AI에게 "이 데이터로 만들 수 있는 리포트 항목"을 먼저 물어본다
  3. 매달 반복해서 쓸 수 있는 항목만 골라 "이 유형의 표준 리포트 목차"로 고정한다
  4. 표준 목차가 정해지면 다음 고객이 비슷한 유형으로 와도 목차를 재사용해 속도를 낼 수 있다
참고 — 리포트 유형은 한 번에 하나만 깊게 파는 것이 유리합니다. 여러 유형을 동시에 하려고 하면 표준 목차가 흐릿해집니다.

04원본 데이터 클렌징 프롬프트로 정제하기

고객이 보내는 원본 데이터는 대부분 지저분합니다. 날짜 형식이 제각각이고, 중복 행과 빈 값이 그대로 남아 있는 경우가 많습니다. 이 정제 단계를 AI에게 먼저 맡기면 이후 분석 전체의 정확도가 올라갑니다.

진행 순서

  1. 원본 데이터를 AI에게 그대로 주고 "중복 행, 빈 값, 날짜 형식 불일치"를 찾아 목록으로 정리해달라고 요청한다
  2. 빈 값 처리 방식(제외/0으로 채움/평균으로 채움)을 사람이 결정하고 그 규칙대로 정제해달라고 요청한다
  3. 정제된 데이터의 행 수와 원본 행 수를 대조해 얼마나 제외됐는지 반드시 확인한다
  4. 정제 규칙을 짧게 메모해둔다 — 고객이 "왜 이 행이 빠졌나요"라고 물었을 때 바로 설명할 수 있어야 한다
주의 — 정제 과정에서 임의로 값을 지어내면 안 됩니다. 빈 값을 채울 땐 반드시 그 근거를 리포트에 남깁니다.

05핵심 지표(KPI) 자동 추출하기

정제된 데이터의 모든 숫자를 다 보여줄 필요는 없습니다. 고객이 실제로 궁금해할 핵심 지표 몇 개만 뽑아 보여주는 것이 리포트의 핵심입니다.

진행 순서

  1. 정제된 데이터와 함께 "이 업종에서 가장 중요한 핵심 지표 5개"를 AI에게 먼저 물어본다
  2. 제안받은 지표 중 방법 1에서 정한 리포트 유형의 핵심 지표와 겹치는 것 위주로 최종 3~5개를 고른다
  3. 각 지표의 이번 기간 수치와 비교 가능한 이전 기간(전월/전주) 수치를 함께 계산해달라고 요청한다
  4. 계산된 수치는 반드시 원본 데이터 일부를 직접 확인해 검산한다 (방법 9에서 자세히 다룹니다)

06시각화(차트) 구성 설계하기

같은 숫자라도 표로 보여줄 때와 그래프로 보여줄 때 전달력이 다릅니다. 어떤 지표를 어떤 차트로 보여줄지 미리 정해두면 리포트가 훨씬 읽기 쉬워집니다.

진행 순서

  1. 핵심 지표별로 어떤 차트 종류(막대·선·파이 등)가 적합한지 AI에게 이유와 함께 제안받는다
  2. 추이는 선 그래프, 항목 간 비교는 막대 그래프, 구성 비율은 파이 차트로 기본 원칙을 정한다
  3. 차트마다 "이 차트에서 봐야 할 포인트"를 한 문장 캡션으로 넣어 그냥 지나치지 않게 만든다
  4. 차트 개수는 5~7개 이내로 제한한다 — 너무 많으면 오히려 무엇이 중요한지 흐려진다

07인사이트·원인 분석 문장으로 만들기

숫자를 나열하는 것과 "왜 이런 숫자가 나왔는지"를 설명하는 것은 완전히 다른 작업입니다. 이 단계가 리포트의 가치를 가장 크게 좌우합니다.

진행 순서

  1. 특정 지표가 오르거나 내린 구간을 짚어 "데이터 안에서 확인 가능한 원인"을 AI에게 추정해달라고 요청한다
  2. 데이터로 뒷받침되지 않는 추측성 내용은 "확인 필요" 문구를 붙이거나 리포트에서 제외한다
  3. 요일별·상품별·채널별로 나눠 성과가 좋은 상위 항목과 부진한 하위 항목을 비교해 구체성을 더한다
  4. 최종 인사이트 문장은 "숫자 + 원인 추정 + 근거"의 3단 구조로 정리한다
주의 — AI가 만든 원인 분석은 상관관계이지 인과관계 증명이 아닙니다. 확신이 안 서면 "~로 추정됩니다"로 표현해 과장하지 않습니다.

08액션 아이템(다음 스텝) 도출하기

리포트를 읽고도 "그래서 뭘 하면 되나요"라는 질문이 나오면 그 리포트는 실패한 것입니다. 마지막은 항상 실행 가능한 다음 스텝으로 마무리합니다.

진행 순서

  1. 인사이트를 바탕으로 다음 2주 안에 실행할 수 있는 구체적인 액션 아이템을 AI에게 3개 제안받는다
  2. 각 액션 아이템에 우선순위(효과가 크고 비용이 적게 드는 순)를 매긴다
  3. "이 액션을 실행하면 어떤 지표가 개선될지"를 한 문장씩 붙여 다음 리포트에서 확인할 수 있게 만든다
  4. 액션 아이템은 리포트에서 가장 눈에 잘 띄는 위치에 별도 박스로 배치한다

09업종별 맞춤 리포트 설계

같은 "매출 데이터"라도 업종마다 봐야 할 포인트가 다릅니다. 업종별 맞춤 리포트는 단가를 올릴 수 있는 차별화 포인트이기도 합니다.

업종군강조 포인트피해야 할 표현
카페·음식점시간대별 매출, 재방문율, 메뉴별 기여도막연한 "잘 되고 있다" 식 총평
이커머스·쇼핑몰전환율, 이탈 구간, 재구매 주기클릭수·조회수만 나열
마케팅 대행채널별 ROI, CAC 대비 LTV단순 노출수만 강조
1인 창작자·SNS참여율 추이, 콘텐츠 유형별 반응팔로워 총량만 언급

진행 순서

  1. 고객의 업종을 확인하고 위 표를 참고해 이번 리포트에서 특히 강조할 지표 1~2개를 정한다
  2. AI에게 해당 업종 사장님들이 가장 궁금해하는 질문이 무엇인지 물어 목차를 보완한다
  3. 방법 3~5에서 뽑은 지표·인사이트를 업종별 강조 포인트에 맞춰 재배치한다
  4. 업종별로 반복되는 패턴을 정리해두면 다음 고객이 같은 업종으로 올 때 속도가 크게 빨라진다

10정기 리포트 자동화 파이프라인 구축하기

한 번 만든 리포트 구조는 매달 반복해서 쓸 수 있어야 진짜 수익이 됩니다. 매번 처음부터 새로 만들면 정기 구독 상품을 팔기 어렵습니다.

진행 순서

  1. 확정한 목차·지표·차트 구성을 "표준 리포트 템플릿"으로 문서화한다
  2. 새 데이터가 들어올 때마다 AI에게 "이전 리포트와 같은 구조로 업데이트해줘"라고 요청해 재사용한다
  3. 매달 바뀌는 부분(수치·인사이트)과 고정되는 부분(목차·차트 종류·톤)을 구분해두면 작업 시간이 크게 줄어든다
  4. 처리 시간을 매달 기록해두고, 어느 단계에서 시간이 가장 많이 드는지 점검해 추가로 자동화한다
참고 — 정기 리포트는 "매번 새로 만드는 상품"이 아니라 "템플릿에 새 데이터를 흘려보내는 상품"이 될수록 마진이 커집니다.

11신뢰도 높이는 검증·오류 체크

리포트에서 숫자가 틀리면 신뢰가 한 번에 무너집니다. AI가 계산한 수치라도 반드시 사람이 검증하는 단계를 거쳐야 합니다.

진행 순서

  1. 핵심 지표 중 2~3개를 골라 원본 데이터에서 직접 재계산해 AI의 계산 결과와 대조한다
  2. 합계·평균 등 집계값은 원본 데이터의 행 수, 값의 범위와 상식적으로 맞는지 확인한다
  3. 리포트에 쓴 모든 숫자에 "어떤 기간, 어떤 조건의 데이터인지"를 각주로 명시해 오해를 방지한다
  4. 최종 리포트를 AI에게 다시 보여주고 앞뒤가 안 맞는 숫자가 있는지 교차 검토를 한 번 더 요청한다
주의 — 검증 없이 AI 계산 결과를 그대로 옮기지 않습니다. 특히 합계·비율 계산은 원본 데이터 일부를 직접 대조하는 습관을 들입니다.

12패키지 설계와 가격 책정

패키지 유형가격대구성
스팟 리포트10,000~20,000원데이터 1건 업로드 → 요약 리포트 1부(PDF)
정기 리포트월 50,000~100,000원월간 리포트 자동 갱신 + 인사이트 코멘트
맞춤 대시보드150,000원~엑셀·구글시트 대시보드 템플릿 + 매달 업데이트
컨설팅 패키지200,000원~리포트 + 30분 화상 인사이트 브리핑

진행 순서

  1. 처음엔 스팟 리포트로 판매 기록과 후기를 빠르게 쌓는다
  2. 후기 10건 이상 쌓이면 정기 리포트를 주력 상품으로 전환하고, 스팟은 "체험판"으로 유지한다
  3. 맞춤 대시보드는 방법 8(자동화 파이프라인)이 갖춰진 뒤 판매하는 것이 유리하다
  4. 컨설팅 패키지는 후기·사례가 쌓인 뒤 객단가를 크게 올릴 수 있는 상위 상품으로 추가한다

13크몽·래피드 등록과 판매 페이지

크몽 — 이미 데이터분석·리포트 카테고리가 활성화되어 검색 유입이 꾸준합니다. "AI 활용 속도 + 업종별 맞춤 지표"라는 차별점을 상세페이지 첫 줄에 명시합니다. 래피드(Latpeed) — 사업자등록 없이 시작 가능, 리포트 샘플을 미리보기로 첨부하기에도 유리합니다.

진행 순서

  1. 문제 제기형(이 데이터, 지금 그냥 잠들어 있습니다)과 결과 중심형(리포트 하나로 이렇게 달라집니다) 카피 2가지를 요청한다
  2. 가상 데이터로 만든 리포트 전/후 비교 예시(실제 고객 데이터 아님을 명시)를 페이지에 넣는다
  3. 데이터 보안, 소요 시간, 파일 형식 등 FAQ 6개를 정리한다
  4. 첫 5건은 후기 확보 목적으로 할인가 진행도 고려한다

14고객 응대와 정기구독 전환

스팟 리포트 한 건으로 끝나면 매번 새 고객을 구해야 합니다. 정기 구독으로 전환시키는 것이 이 서비스의 진짜 수익 구조입니다.

진행 순서

  1. 접수 시 "데이터 형식, 원하는 리포트 유형, 리포트 주기, 궁금한 지표"를 필수로 받는 온보딩 질문지를 사용한다
  2. 스팟 리포트 전달 시 "다음 달엔 이번 달과 비교한 추이까지 볼 수 있다"는 점을 자연스럽게 언급한다
  3. 리포트 전달 후 1주일 뒤, 액션 아이템 실행 여부를 확인하며 정기 구독을 정중히 제안한다
  4. 정기 구독 고객에게는 "지난달 대비 눈에 띄는 변화"만 짧게 요약한 알림 메시지를 추가로 보내 재구독률을 높인다

15바로 쓰는 프롬프트 16선

대괄호 부분만 바꿔서 그대로 붙여넣으세요. 카테고리별로 정리했습니다.

A. 데이터 정제·구조화
A1 원본 데이터 정리

A2 컬럼 구조 설계
이 데이터로 [리포트 유형]을 만들려고 해. 분석에 필요한 컬럼 구조(파생 컬럼 포함)를 제안해줘: [현재 컬럼 목록]
A3 이상치 탐지
이 데이터에서 평균·추세를 벗어나는 이상치(오입력 의심 값 포함)를 찾아 이유와 함께 표로 정리해줘: [데이터]
A4 기간 비교 정렬
이 데이터를 [주간/월간] 단위로 집계하고 전 기간 대비 증감률까지 계산해줘: [데이터]
B. 지표·인사이트 추출
B1 핵심 지표 추출
이 데이터에서 [업종]에 가장 중요한 핵심 지표(KPI) 5개를 정하고, 각각의 이번 기간 수치를 계산해줘: [데이터]
B2 원인 분석
[지표명]이 [상승/하락]한 이유를 데이터 안에서 찾을 수 있는 요인 위주로 추정해줘. 근거가 부족하면 "확인 필요"라고 표시해줘: [데이터]
B3 세그먼트 비교
이 데이터를 [요일별/상품별/채널별]로 나눠서 성과가 좋은 상위 3개와 부진한 하위 3개를 비교해줘: [데이터]
B4 다음 기간 예측
최근 [N개월] 추세를 바탕으로 다음 기간 [지표명]을 보수적으로 예측하고, 전제 조건도 함께 적어줘: [데이터]
C. 리포트 작성·시각화
C1 리포트 초안 생성
아래 분석 결과를 [업종] 사장님도 이해할 수 있게, 요약→핵심지표→인사이트→다음 액션 순서의 리포트로 작성해줘: [분석 결과]

D1 패키지 구성

D2 판매 페이지 카피

D4 정기구독 전환
스팟 리포트를 받은 고객에게 월간 정기 리포트 구독을 제안하는 후속 안내 메시지를 정중한 톤으로 만들어줘.

  • 업종별 강조 포인트 표(방법 7) 참고해 타겟 업종 1개 확정하기
  • 샘플 리포트 전/후 예시(가상 데이터) 1건 만들어 포트폴리오로 준비하기

  • 정기 리포트 자동화 파이프라인(방법 8) 구축해 반복 작업 시간 줄이기
  • 스팟 고객에게 정기구독 전환 제안하기 (프롬프트 D4)
  • 반응 좋은 업종 파악해 특화 상품으로 확장하기

사장님이 필요한 건 숫자가 아니라 결론입니다. "이번 달 매출 3,200만 원"은 정보지만, "화요일 매출이 유독 낮으니 화요일 한정 프로모션을 검토해보세요"는 결정을 도와줍니다. 이 서비스가 파는 건 엑셀 실력이 아니라 그 차이를 만들어내는 한 문장입니다.

AI는 정제와 계산을 빠르게 해줍니다. 그 계산을 사람이 읽는 결론으로 바꾸는 안목은 이 책에서 다룬 방법이 대신해줍니다. 오늘, 방법 1부터 딱 하나만 적용해 보세요.
