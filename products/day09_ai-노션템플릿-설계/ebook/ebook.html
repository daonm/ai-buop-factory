예쁘길래 저장해뒀는데, 다시 열어보지 않습니다. 노션 워크스페이스 사이드바엔 그렇게 저장만 하고 안 쓰는 템플릿이 몇 개씩 쌓여 있습니다.

역설적으로 이게 기회입니다. "저장은 하는데 안 쓴다"는 건 수요는 있지만 그 수요를 제대로 채워주는 템플릿이 드물다는 뜻이기 때문입니다. 사람들이 원하는 건 화려한 대시보드가 아니라, 열자마자 "이거 나한테 딱 맞네"라는 느낌이 드는 구조입니다.

2026년 지금, 범용 생산성 템플릿은 반응이 식어가고 특정 상황·직업·습관에 맞춘 좁은 니치 템플릿은 오히려 성장하고 있습니다. 이 책이 그 니치를, AI와 함께 팔 수 있는 구조로 설계하는 방법을 다룹니다.

01왜 지금 AI로 노션 템플릿을 파는가

노션 템플릿은 디지털 상품 중에서도 특히 "한 번 만들면 계속 팔린다"는 장점이 큽니다. 재고도, 배송도, 유통기한도 없습니다. 그런데 이걸 만드는 데 걸리는 시간이 문제였습니다. AI가 바꾼 건 바로 이 설계 단계입니다.

  1. 구조 설계가 몇 분으로 줄어듭니다. 용도만 말하면 데이터베이스 속성, 뷰 구성, 페이지 트리까지 초안이 바로 나옵니다.
  2. 수식·자동화의 진입 장벽이 낮아집니다. 문법을 몰라도 원하는 결과만 말하면 수식과 설명이 함께 나옵니다.
  3. 가이드 문서 작성이 빨라집니다. 템플릿보다 오래 걸리던 "사용법 문서"를 AI가 빠르게 초안으로 만들어 줍니다.

2026년 데이터가 알려주는 신호 하나 — 범용 생산성 템플릿은 반응이 식어가고, 특정 대상·상황에 맞춘 니치 템플릿은 오히려 성장하고 있습니다. AI에게 "노션 템플릿 만들어줘"라고 막연히 시키는 대신, 어떤 니치를 어떤 구조로 설계해야 실제로 팔리는지가 이 책의 전부입니다.

02시작 전에 딱 3가지만

준비물은 딱 3가지 — 노션 마스터가 아니어도 괜찮습니다
  1. 노션 계정 — 무료 플랜으로 충분, 템플릿 복제 링크(퍼블리시) 기능만 있으면 됩니다
  2. 내가 실제로 쓰는 노션 페이지 하나 — 완벽하지 않아도 됩니다, 몇 주 이상 써본 페이지가 가장 좋은 출발점
  3. 판매 채널 하나 — 사업자등록 없이 시작 가능한 래피드(Latpeed) 기준으로 설명

완벽하게 정리된 노션이 아니어도 괜찮습니다. "쓰다 보니 이렇게 정리하게 됐다"는 실사용 경험 자체가 차별점이 됩니다.

03잘 팔리는 카테고리와 니치 정하기

노션 템플릿은 이미 3만 개가 넘게 나와 있는 레드오션처럼 보이지만, 실제로는 "범용"과 "니치"의 온도차가 뚜렷한 시장입니다. 대상을 좁힐수록 경쟁은 줄고 구매 전환은 오히려 올라갑니다.

대분류범용 예시(경쟁 심함)니치로 좁힌 예시(기회)
개인 생산성일반 할 일 관리교대근무자용 불규칙 스케줄 관리

진행 순서

  1. 내 관심사·경험·직업 3~5개를 나열하고 AI에게 "이걸로 만들 수 있는 카테고리 5개" 요청
  2. 반응이 있을 것 같은 카테고리를 골라 "더 좁힌 니치 아이디어"를 다시 요청
  3. 니치를 고를 때는 "내가 실제로 그 상황을 겪어봤는가"를 최우선 기준으로 삼는다
  4. 확정한 니치의 타겟 사용자를 한 문장으로 정리한다
참고 — 니치가 좁을수록 불안할 수 있지만, 그만큼 대안이 별로 없어 구매로 이어질 확률이 높습니다.

04AI로 데이터베이스 스키마 설계하기

노션 템플릿의 핵심은 페이지 디자인이 아니라 데이터베이스 구조입니다. 속성 설계에 따라 쓰기 편한 템플릿과 불편한 템플릿이 갈립니다.

진행 순서

  1. 니치와 사용 시나리오를 설명하고 "이 용도에 맞는 데이터베이스 속성 목록" 요청 (제목/선택/다중선택/날짜/관계형/숫자 등)
  2. 매일 입력할 항목과 자동 계산될 항목을 구분해달라고 요청 — 입력이 많으면 지쳐서 안 씁니다
  3. 뷰(보드/캘린더/타임라인/갤러리) 구성을 용도에 맞게 추천받는다
  4. 속성 5~7개, 뷰 2~3개를 넘지 않는 선에서 1차 초안을 확정한다
주의 — 이론적으로 완벽해도 입력 부담이 크면 며칠 안에 손을 놓습니다. "이 속성, 매일 채울 수 있는가"를 항상 되물으세요.

05수식·관계형·롤업으로 스마트하게 만들기

수식 하나만 잘 넣어도 "직접 계산 안 해도 알아서 보여주는" 템플릿이 됩니다. 이게 "돈 주고 살 만하다"고 느끼는 지점입니다.

진행 순서

  1. 넣고 싶은 자동 계산 결과를 말로 정리한다 (D-day, 진행률 %, 예산 초과 여부 등)
  2. AI에게 원하는 결과만 설명하고 수식 초안과 각 부분의 의미 설명을 요청
  3. 여러 데이터베이스를 다루면 관계형(Relation)으로 연결하고 롤업(Rollup)으로 자동 집계 설계
  4. 실제 노션에 넣어보고 예시 데이터로 반드시 테스트한다
참고 — 수식이 복잡할수록 있어 보이지만, 구매자가 이해 못 하면 커스터마이징을 못 해 불만이 쌓입니다.

06버튼·자동화로 "직접 만든 티" 없애기

노션의 버튼(Button)과 자동화(Automation) 기능을 쓰면 반복 작업을 클릭 한 번으로 줄일 수 있습니다. 이 디테일이 "그냥 정리해놓은 페이지"와 "잘 설계된 상품"을 가릅니다.

진행 순서

  1. 반복될 만한 작업을 나열한다 (매주 새 할 일 페이지 만들기, 완료 항목 아카이브 이동 등)
  2. AI에게 버튼/자동화 기능으로 처리하는 설정 방법을 단계별로 요청
  3. 버튼에는 헷갈리지 않는 명확한 이름을 붙인다 (예: "+ 이번 주 할 일 만들기")
  4. 핵심 반복 작업 1~2개에만 집중한다 — 과하면 처음 여는 사람이 이해를 못 합니다

07페이지 구조·대시보드 홈 설계

데이터베이스가 잘 만들어져도 처음 열었을 때 뭘 봐야 할지 모르면 사용자는 헤맵니다. 홈 대시보드가 그 첫인상을 결정합니다.

진행 순서

  1. 만든 데이터베이스 목록을 주고 "전체 페이지 트리(홈→하위 페이지→DB 위치)" 설계 요청
  2. 홈 대시보드에 넣을 요소(오늘 할 일, 이번 주 진행률, 바로가기 등)를 우선순위와 함께 요청
  3. 처음 여는 사람이 3초 안에 "뭐부터 볼지" 알 수 있게 최상단에 핵심 1가지만 크게 배치
  4. 모든 하위 페이지 상단에 홈으로 바로 돌아오는 링크를 넣는다
참고 — 복제하고 5분 안에 뭘 해야 할지 모르면 그대로 방치됩니다. 대시보드는 예쁜 것보다 "다음에 뭘 눌러야 하는지 명확한 것"이 우선입니다.

08커버·아이콘 비주얼 아이덴티티

같은 구조라도 커버 이미지와 아이콘이 통일감 있으면 완성도가 훨씬 높아 보입니다. 갤러리를 스크롤하다 멈추는 것도 결국 첫 화면입니다.

진행 순서

  1. 니치의 톤(미니멀/파스텔/다크/빈티지 등)에 맞는 색상 팔레트와 아이콘 컨셉 요청
  2. 이미지 도구나 노션 기본 커버·이모지 조합으로 제작 — 화려함보다 일관성이 중요
  3. 모든 하위 페이지 아이콘을 같은 스타일로 통일한다
  4. 완성 화면을 스크린샷으로 찍어 판매 페이지 미리보기로 바로 활용한다
주의 — 커버가 화려해도 구조가 부실하면 후기에서 바로 드러납니다. 비주얼은 구조를 완성한 다음 단계입니다.

09온보딩 가이드 만들기

템플릿 자체보다 가이드 문서에서 만족도가 갈리는 경우가 많습니다. "복제는 했는데 어떻게 쓰는지 모르겠다"는 가장 흔한 불만입니다.

진행 순서

  1. 템플릿 구조를 설명하고 "복제 방법 → 첫 설정 → 매일/매주 쓰는 법" 순서로 가이드 초안 요청
  2. 초보자가 자주 헷갈릴 설정 실수와 예방법을 별도 섹션으로 정리
  3. 짧은 PDF나 노션 페이지 자체로 만들어 템플릿과 함께 제공한다
  4. 가이드 마지막에 "막히면 어디로 문의하면 되는지" 한 줄을 남긴다

10가격 책정 전략

노션 템플릿 가격은 형태와 문서화 수준에 따라 폭이 넓습니다. 국내외 사례를 참고해 감을 잡아보겠습니다.

유형가격대(원화 환산)특징
단일 목적 트래커5,000~15,000원기능 1~2개, 가벼운 진입가
개인용 통합 시스템15,000~40,000원DB 다수 연결, 자동화 포함
팀/비즈니스용 시스템60,000~150,000원상세 문서화, 협업 기능
크몽식 맞춤 제작50,000~300,000원페이지·DB·뷰 개수 기준 견적

진행 순서

  1. 비슷한 사례를 참고해 저가/중가/고가 3가지 시나리오를 근거와 함께 제안받는다
  2. 처음엔 후기·판매 기록이 우선이므로 진입장벽을 낮게 잡는다
  3. 후기 10개 이상이면 중간가, 30개 이상이면 정가로 단계적으로 인상한다
  4. 다음 상품과 묶는 번들 가격도 함께 검토한다

11판매 페이지 카피와 미리보기

노션 템플릿은 실물을 만져볼 수 없는 상품이라, 미리보기 이미지와 카피가 구매 결정의 전부라고 봐도 됩니다.

진행 순서

  1. 템플릿명과 핵심 기능을 주고 문제 제기형/결과 중심형 2가지 카피 버전 요청
  2. 완성 화면을 3~4장 스크린샷으로 찍고 각 장면에 짧은 캡션을 붙인다
  3. 구매를 망설이는 사람이 물어볼 질문 6개와 답변(FAQ)을 요청해 하단에 배치
  4. "복제 후 5분 안에 시작 가능"처럼 구체적인 사용 경험을 앞부분에 배치한다

12판매 채널 선택과 등록

채널마다 특성이 다릅니다. 처음엔 하나만 골라 집중하는 게 낫습니다.

  1. 래피드(Latpeed) — 사업자등록 없이 5분 등록, SNS 홍보 연결이 쉬워 이 시리즈의 기본 채널
  2. 크몽 — 맞춤 제작 문의가 자연스럽게 들어와 완성 템플릿+커스터마이징 투트랙 운영에 유리 (수수료 4.4~16.4%+결제망 이용료)
  3. 노션 공식 템플릿 갤러리 — 검색 유입이 꾸준하지만 경쟁이 많아 니치가 뚜렷할수록 유리

진행 순서

  1. 처음엔 래피드에 집중해 등록하고 판매 페이지 카피와 미리보기를 그대로 활용한다
  2. 복제 링크(퍼블리시)를 결제 완료 후에만 전달되도록 안내 문구를 준비한다
  3. 반응이 확인되면 크몽에도 같은 상품을 올려 채널을 넓힌다

13후기로 개선하고 신뢰 쌓기

노션 템플릿은 눈에 안 보이는 상품이라 후기가 곧 신뢰입니다. 첫 구매자의 피드백을 빠르게 반영하는 것이 장기적으로 가장 중요합니다.

진행 순서

  1. 구매자에게 "어떤 부분이 좋았는지, 헷갈렸는지" 부담 없는 톤으로 피드백을 요청한다
  2. AI에게 피드백을 정리해서 "구조를 바꿔야 할 부분"과 "가이드 문구만 보완할 부분"을 구분받는다
  3. 자주 나오는 질문은 가이드와 판매 페이지 FAQ에 계속 추가한다
  4. 개선된 버전은 기존 구매자에게도 업데이트 안내를 남겨 재방문 가능성을 높인다

14라인업 확장(시리즈·번들)

템플릿 하나가 반응이 좋으면, 다음은 "같은 사용자에게 팔 수 있는 다음 상품"을 찾는 단계입니다.

진행 순서

  1. 첫 템플릿 구매자가 다음으로 필요할 만한 기능을 물어 후속 아이디어를 받는다
  2. 관련 템플릿 여러 개를 하나의 "시스템"으로 묶어 번들 가격을 제안받는다
  3. 시리즈 이름과 넘버링을 붙여 다음 편에 대한 기대감을 만든다
  4. 번들은 개별 구매 대비 확실한 할인폭을 제공한다

15바로 쓰는 프롬프트 20선

대괄호 부분만 바꿔서 그대로 붙여넣으세요. 카테고리별로 정리했습니다.

A. 기획 · 구조 설계
A1 카테고리 발굴
내 관심사/경험/강점은 [목록]이야. 이걸로 만들 수 있는 노션 템플릿 카테고리 5개와 각각의 타겟 사용자를 제안해줘.
A2 니치 좁히기
"[넓은 카테고리]" 템플릿은 이미 많아. 더 구체적인 타겟으로 좁힌 니치 아이디어 5개를 제안해줘.
A3 페이지 구조 설계
[템플릿 주제]에 맞는 노션 페이지 트리 구조(홈 대시보드, 하위 페이지, 데이터베이스 위치)를 설계해줘.
A4 대시보드 홈 레이아웃
[템플릿 주제]의 홈 대시보드에 넣을 위젯/섹션을 우선순위와 함께 제안해줘.
B. 데이터베이스 · 자동화
B1 DB 스키마 설계
[템플릿 주제]에 어울리는 노션 데이터베이스 속성과 뷰(보드/캘린더/타임라인) 구성을 설계해줘.
B2 수식 설계
[원하는 계산 결과, 예: 진행률 %, D-day]를 노션 수식으로 어떻게 만들 수 있을지 수식 초안과 설명을 알려줘.
B3 관계형 · 롤업 설계
이 두 데이터베이스([DB1]와 [DB2])를 관계형으로 연결하고 롤업으로 [원하는 값]을 자동 계산하고 싶어. 설정 방법을 단계별로 알려줘.
B4 버튼 · 자동화 설계
[반복 작업, 예: 매주 새 할 일 페이지 생성]을 노션 버튼/자동화 기능으로 처리하려면 어떻게 설정해야 하는지 알려줘.
C. 비주얼 · 가이드
C1 아이콘 · 커버 컨셉
[템플릿 주제]에 어울리는 톤의 아이콘·커버 이미지 컨셉을 색상 팔레트와 함께 제안해줘.
C2 온보딩 가이드
이 템플릿을 처음 받은 사람을 위한 사용 가이드를 "복제 방법 → 첫 설정 → 매일 쓰는 법" 순서로 써줘: [템플릿 구조 설명]
C3 예시 데이터 채우기
[템플릿 주제]에 넣을 예시 데이터를 만들어줘. 너무 완벽하지 않게 현실적인 수준으로.
C4 자주 하는 실수 안내
[템플릿 주제] 초보 사용자가 자주 하는 설정 실수 5가지와 예방법을 정리해줘.
D. 가격 · 판매 페이지
D1 가격 책정
비슷한 노션 템플릿의 가격대를 참고해서 [템플릿 주제]의 초기가/인상가를 근거와 함께 제안해줘.
D2 판매 페이지 카피
[템플릿명]의 판매 페이지 카피를 문제 제기형/결과 중심형 2버전으로 써줘. 각 제목-소개-포함 구성-FAQ 구조로.
D3 미리보기 이미지 문구
판매 페이지에 넣을 스크린샷 3~4장 각각에 붙일 짧은 설명 캡션을 만들어줘: [화면별 설명]
D4 FAQ 초안
[템플릿명]을 살까 말까 고민하는 사람이 물어볼 질문 6개와 신뢰가 가는 답변을 만들어줘.
E. 홍보 · 확장
E1 홍보 후킹 문장
[템플릿 설명]을 한 문장으로 요약해서 SNS 후킹 문장 5개를 만들어줘.
E2 사용 전후 비교
"이 템플릿 쓰기 전/후"를 비교하는 홍보 콘텐츠 문구를 만들어줘.
E3 번들 구성 제안
[기존 템플릿 목록]을 참고해서 함께 묶어 팔면 좋을 번들 구성과 할인 근거를 제안해줘.
E4 다음 템플릿 발굴
지금까지 반응 좋았던 템플릿은 [내용/데이터]야. 비슷한 다음 템플릿 아이디어 5개와 이유를 제안해줘.

16실전 체크리스트

오늘30분

  • 내가 실제로 쓰는 노션 페이지 하나 고르기
  • 프롬프트 A1~A2로 카테고리·니치 후보 뽑아보기
  • 타겟 사용자 한 문장으로 정리하기

이번 주1차 완성

  • 데이터베이스 스키마와 수식 초안 완성 (프롬프트 B1~B2)
  • 페이지 구조·대시보드 홈 확정 (프롬프트 A3~A4)
  • 커버·아이콘 통일, 온보딩 가이드 작성 (프롬프트 C1~C2)
  • 가격 확정 후 판매 페이지 카피 작성 (프롬프트 D1~D2)

이번 달확장

  • 래피드에 등록하고 첫 판매 1건 만들기
  • 구매자 피드백 수집 후 가이드/구조 개선
  • 번들·후속 템플릿 아이디어 발굴 (프롬프트 E3~E4)
  • 반응 좋았던 요소를 다음 니치에 재사용

노션 템플릿은 화려한 디자인이 아니라, 열자마자 "이거 나한테 딱 맞네"라는 느낌을 주는 구조에서 시작합니다. 데이터베이스 속성 하나, 수식 하나, 가이드 한 줄이 저장만 하고 안 쓰는 템플릿과 계속 열어보는 템플릿을 가릅니다.

AI는 그 구조를 빠르게 초안으로 만들어 줍니다. 하지만 어떤 니치를, 어떤 순서로 설계할지는 이 책에서 다룬 방법이 대신해줍니다. 오늘, 방법 1부터 딱 하나만 적용해 보세요.
