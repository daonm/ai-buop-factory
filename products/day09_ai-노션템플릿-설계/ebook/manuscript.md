# 그 노션, 저장만 하고 안 씁니다
### AI로 설계해서 파는 노션 템플릿 — 카테고리 선정부터 가격 책정까지

---

## 프롤로그 — "예쁘길래 저장해뒀어요"의 함정

노션 템플릿 갤러리를 구경하다가 예쁜 대시보드를 발견하면 일단 저장부터 합니다. 그리고 다시 열어보지 않습니다. 워크스페이스 사이드바에는 그렇게 저장만 하고 안 쓰는 템플릿이 몇 개씩 쌓여 있습니다.

역설적으로 이게 기회입니다. **"저장은 하는데 안 쓴다"는 건 수요는 있지만 그 수요를 제대로 채워주는 템플릿이 드물다는 뜻**이기 때문입니다. 사람들이 원하는 건 화려한 대시보드가 아니라, 열자마자 "이거 나한테 딱 맞네"라는 느낌이 드는 구조입니다.

2026년 지금 노션 템플릿 시장은 재미있는 국면입니다. 노션 공식 템플릿 갤러리에만 3만 개가 넘는 템플릿이 올라와 있고, 크몽 같은 국내 플랫폼에서는 노션 하나만 다루는 판매자가 본업 외 월 수백만 원의 순수익을 올리는 사례도 나옵니다. 동시에 "그냥 예쁜 개인 생산성 템플릿"은 점점 흔해지고 반응이 식어가는 반면, **특정 상황·직업·습관에 맞춘 좁은 니치 템플릿**(교대근무자 자기관리, 프리랜서 세금 관리, 논문 쓰는 대학원생용 등)은 오히려 반응이 좋아지는 추세입니다.

당신이 노션을 오래 써온 사람이라면, 이미 "내가 실제로 쓰는" 잘 정리된 페이지 하나쯤은 있을 겁니다. 이 책은 그 페이지를 클로드(Claude)와 함께 **팔 수 있는 구조·수식·가이드를 갖춘 상품**으로 만드는 방법을 다룹니다. 노션 마스터가 아니어도, 데이터베이스와 수식을 다뤄본 적이 없어도 오늘부터 시작할 수 있습니다.

## 1. 왜 지금 AI로 노션 템플릿을 파는가

노션 템플릿은 디지털 상품 중에서도 특히 "한 번 만들면 계속 팔린다"는 장점이 큽니다. 재고도, 배송도, 유통기한도 없습니다. 그런데 이걸 만드는 데 걸리는 시간이 문제였습니다 — 데이터베이스 속성 설계, 수식 문법, 가이드 문서 작성까지 혼자 하려면 며칠씩 걸리곤 했습니다.

AI가 바꾼 건 바로 이 **설계 단계**입니다.

- **구조 설계가 몇 분으로 줄어듭니다.** "이런 용도의 템플릿을 만들고 싶다"고만 말하면 데이터베이스 속성, 뷰 구성, 페이지 트리까지 초안이 바로 나옵니다.
- **수식·자동화의 진입 장벽이 낮아집니다.** 노션 수식 문법을 몰라도 "진행률을 퍼센트로 보여주고 싶다"처럼 원하는 결과만 말하면 AI가 수식을 만들어주고 설명까지 붙여줍니다.
- **가이드 문서 작성이 빨라집니다.** 템플릿은 만드는 것보다 "어떻게 쓰는지 알려주는" 문서가 의외로 더 오래 걸리는데, AI가 초안을 빠르게 만들어 줍니다.

그리고 2026년 시장 데이터가 알려주는 중요한 신호가 하나 있습니다. **범용 생산성 템플릿은 반응이 식어가고, 특정 대상·상황에 맞춘 니치 템플릿은 오히려 성장하고 있다**는 것입니다. 이 책의 목표는 AI에게 "노션 템플릿 만들어줘"라고 막연히 시키는 대신, **어떤 니치를, 어떤 구조로, 어떤 순서로 설계해야 실제로 팔리는지**를 알려드리는 것입니다.

## 2. 시작 전에 딱 3가지만 준비하세요

1. **노션 계정** — 무료 플랜으로 충분히 시작할 수 있습니다. 템플릿 복제 링크(퍼블리시) 기능만 있으면 됩니다.
2. **내가 실제로 쓰는 노션 페이지 하나** — 완벽하지 않아도 됩니다. 가계부, 할 일 관리, 독서 기록처럼 실제로 몇 주 이상 써본 페이지가 있다면 그게 가장 좋은 출발점입니다.
3. **판매 채널 하나** — 사업자등록 없이 시작할 수 있는 **래피드(Latpeed)** 기준으로 설명합니다. 크몽, 노션 공식 템플릿 갤러리도 함께 고려할 수 있습니다(방법 10에서 비교).

완벽하게 정리된 노션이 아니어도 괜찮습니다. "쓰다 보니 이렇게 정리하게 됐다"는 실사용 경험 자체가 다른 템플릿과의 차별점이 됩니다.

## 3. 방법 1 — 잘 팔리는 카테고리와 니치 정하기

노션 템플릿은 이미 3만 개가 넘게 나와 있는 레드오션처럼 보이지만, 실제로는 **"범용"과 "니치"의 온도차가 뚜렷한 시장**입니다. "다이어리", "할 일 관리" 같은 범용 키워드는 경쟁이 극심하지만, 대상을 좁힐수록 경쟁은 줄고 구매 전환은 오히려 올라갑니다.

| 대분류 | 범용 예시 (경쟁 심함) | 니치로 좁힌 예시 (기회) |
|---|---|---|
| 개인 생산성 | 일반 할 일 관리 | 교대근무자용 불규칙 스케줄 관리 |
| 세컨드브레인/PARA | 범용 지식 관리 | 논문·자료 정리하는 대학원생용 |
| 자기관리/갓생 | 일반 습관 트래커 | ADHD 성향을 고려한 초저마찰 습관판 |
| 부업/사이드프로젝트 | 부업 아이디어 정리 | 1인 디지털 상품 판매 파이프라인 관리 |
| 학생/취준생 | 스터디 플래너 | 자소서·면접 일정 통합 관리판 |
| 크리에이터 | 콘텐츠 아이디어 노트 | 숏폼 채널 대본·업로드 스케줄 통합판 |
| 소상공인 | 매출 정리 | 1인 카페·스튜디오 예약+재고 통합판 |

### 진행 순서
1. AI에게 내 관심사·경험·직업 3~5개를 나열하고 "이걸로 만들 수 있는 노션 템플릿 카테고리 5개"를 요청한다.
2. 그중 반응이 있을 것 같은 카테고리 1~2개를 골라 "더 좁힌 니치 아이디어"를 다시 요청한다.
3. 니치를 고를 때는 "내가 실제로 그 상황을 겪어봤는가"를 최우선 기준으로 삼는다 — 직접 안 겪어본 니치는 디테일에서 어색함이 드러난다.
4. 확정한 니치의 타겟 사용자를 한 문장으로 정리한다. 예: "매주 다른 요일에 출근하는 3교대 근무자."

> 참고 — 니치가 좁을수록 "나만 쓸 것 같은데?"라는 불안이 들 수 있습니다. 하지만 좁은 니치일수록 그 사람들이 검색할 때 대안이 별로 없어서, 오히려 구매로 이어질 확률이 높습니다.

## 4. 방법 2 — AI로 데이터베이스 스키마 설계하기

노션 템플릿의 핵심은 페이지 디자인이 아니라 **데이터베이스 구조**입니다. 속성을 어떻게 설계하느냐에 따라 같은 용도라도 쓰기 편한 템플릿과 불편한 템플릿이 갈립니다.

### 진행 순서
1. 방법 1에서 정한 니치와 사용 시나리오를 AI에게 설명하고 "이 용도에 맞는 데이터베이스 속성 목록"을 요청한다 (제목, 선택, 다중선택, 날짜, 관계형, 숫자 등 속성 타입 포함).
2. 사용자가 실제로 매일 입력할 항목과, 자동으로 계산되어야 할 항목을 구분해달라고 요청한다 — 입력 항목이 너무 많으면 사용자가 지쳐서 안 씁니다.
3. 뷰(보드/캘린더/타임라인/갤러리) 구성을 용도에 맞게 추천받는다. 예: 할 일 관리는 보드+캘린더, 콘텐츠 기획은 캘린더+타임라인.
4. 속성 5~7개, 뷰 2~3개를 넘지 않는 선에서 1차 초안을 확정한다 — 처음부터 과하게 설계하면 정작 사용성이 떨어진다.

> 주의 — AI가 제안하는 속성이 이론적으로는 완벽해도 실제 입력 부담이 크면 사용자는 며칠 안에 손을 놓습니다. "이 속성, 매일 채울 수 있는가"를 항상 되물어보세요.

## 5. 방법 3 — 수식·관계형·롤업으로 스마트하게 만들기

수식 하나만 잘 넣어도 "직접 계산 안 해도 알아서 보여주는" 템플릿이 됩니다. 이게 사람들이 "돈 주고 살 만하다"고 느끼는 지점입니다.

### 진행 순서
1. 템플릿에 넣고 싶은 자동 계산 결과를 말로 정리한다. 예: "목표일까지 남은 날짜(D-day)", "이번 달 진행률 퍼센트", "예산 대비 지출 초과 여부".
2. AI에게 원하는 결과만 설명하고 노션 수식 초안과 각 부분이 무슨 의미인지 설명을 요청한다.
3. 여러 데이터베이스를 다루는 템플릿이라면, 관계형(Relation)으로 연결하고 롤업(Rollup)으로 합계·평균·개수를 자동 집계하도록 설계한다.
4. 실제 노션에 넣어보고 예시 데이터로 테스트한다 — 수식은 반드시 실제 데이터로 검증해야 합니다. AI가 만든 수식도 노션 버전이나 속성명이 달라지면 오류가 날 수 있습니다.

> 참고 — 수식이 복잡할수록 있어 보이지만, 정작 구매자는 "왜 이렇게 되는지" 이해가 안 되면 커스터마이징을 못 해서 불만이 쌓입니다. 가이드 문서(방법 7)에 수식 로직을 간단히 설명해두는 것이 중요합니다.

## 6. 방법 4 — 버튼·자동화로 "직접 만든 티" 없애기

노션의 버튼(Button)과 자동화(Automation) 기능을 쓰면 반복 작업을 클릭 한 번으로 줄일 수 있습니다. 이 디테일이 "그냥 정리해놓은 페이지"와 "잘 설계된 상품"을 가릅니다.

### 진행 순서
1. 템플릿 사용 중 반복될 만한 작업을 나열한다. 예: "매주 새 할 일 페이지 만들기", "완료된 항목을 아카이브로 이동하기".
2. AI에게 이 반복 작업을 노션 버튼이나 데이터베이스 자동화 기능으로 처리하는 설정 방법을 단계별로 요청한다.
3. 버튼에는 사용자가 헷갈리지 않도록 명확한 이름(예: "+ 이번 주 할 일 만들기")을 붙인다.
4. 자동화가 많을수록 좋아 보이지만, 처음 여는 사람이 이해 못 할 정도로 복잡하면 오히려 역효과입니다. 핵심 반복 작업 1~2개에만 집중한다.

---

## 7. 방법 5 — 페이지 구조·대시보드 홈 설계

데이터베이스가 잘 만들어져도 처음 열었을 때 뭘 봐야 할지 모르면 사용자는 헤맵니다. 홈 대시보드가 그 첫인상을 결정합니다.

### 진행 순서
1. AI에게 방법 1~4에서 만든 데이터베이스 목록을 주고 "이 템플릿의 전체 페이지 트리(홈 → 하위 페이지 → 데이터베이스 위치)"를 설계해달라고 요청한다.
2. 홈 대시보드에 넣을 요소(오늘의 할 일, 이번 주 진행률, 자주 쓰는 페이지 바로가기 등)를 우선순위와 함께 요청한다.
3. 처음 여는 사람이 3초 안에 "뭐부터 봐야 하는지" 알 수 있도록, 홈 화면 최상단에 가장 중요한 정보 1가지만 크게 배치한다.
4. 하위 페이지로 넘어갈 때도 뒤로가기 없이 홈으로 바로 돌아올 수 있는 링크를 각 페이지 상단에 넣는다.

> 참고 — 노션 템플릿 구매자의 상당수는 "복제하고 5분 안에 뭘 해야 할지 모르면" 그대로 방치합니다. 대시보드 홈은 예쁜 것보다 "다음에 뭘 눌러야 하는지 명확한 것"이 우선입니다.

## 8. 방법 6 — 커버·아이콘 비주얼 아이덴티티

같은 구조라도 커버 이미지와 아이콘이 통일감 있으면 완성도가 훨씬 높아 보입니다. 노션 갤러리를 스크롤하다 멈추는 것도 결국 첫 화면입니다.

### 진행 순서
1. AI에게 니치의 톤(미니멀/파스텔/다크/빈티지 등)에 맞는 색상 팔레트와 아이콘 스타일 컨셉을 요청한다.
2. 이미지 생성 도구(캔바, AI 이미지 생성기 등)로 커버 이미지를 만들거나, 노션 기본 커버/이모지 조합만으로도 통일감을 줄 수 있다 — 화려함보다 일관성이 중요하다.
3. 모든 하위 페이지 아이콘을 같은 스타일(같은 이모지 계열 또는 같은 톤의 아이콘)로 통일한다.
4. 완성된 화면을 스크린샷으로 찍어 판매 페이지 미리보기 이미지로 바로 활용할 수 있게 정리해둔다(방법 9와 연결).

> 주의 — 커버 이미지가 화려해도 실제 데이터베이스 구조가 부실하면 초반 클릭은 될지언정 후기에서 바로 드러납니다. 비주얼은 구조를 완성한 다음 단계입니다.

---

## 9. 방법 7 — 온보딩 가이드 만들기

템플릿 자체보다 가이드 문서에서 구매자의 만족도가 갈리는 경우가 많습니다. "복제는 했는데 어떻게 쓰는지 모르겠다"는 후기가 가장 흔한 불만입니다.

### 진행 순서
1. AI에게 템플릿 구조를 설명하고 "복제 방법 → 첫 설정(속성 값 채우기 등) → 매일/매주 쓰는 법" 순서로 온보딩 가이드 초안을 요청한다.
2. 초보 사용자가 자주 헷갈릴 만한 설정 실수(속성 삭제, 뷰 필터 초기화 등)와 예방법을 별도 섹션으로 정리한다.
3. 가이드는 짧은 PDF나 노션 페이지 자체로 만들어 템플릿과 함께 제공한다 — 별도로 찾아봐야 하면 안 읽습니다.
4. 가이드 마지막에 "막히면 어디로 문의하면 되는지"를 한 줄 남겨 신뢰를 더한다.

## 10. 방법 8 — 가격 책정 전략

노션 템플릿 가격은 형태(단일 템플릿/번들/팀용 시스템)와 문서화 수준에 따라 폭이 넓습니다. 국내외 사례를 함께 참고해 감을 잡아보겠습니다.

| 유형 | 가격대 (원화 환산 기준) | 특징 |
|---|---|---|
| 단일 목적 트래커 | 5,000~15,000원 | 습관·목표 등 기능 1~2개, 가벼운 진입가 |
| 개인용 통합 시스템 | 15,000~40,000원 | 여러 데이터베이스 연결, 자동화 포함 |
| 팀/비즈니스용 시스템 | 60,000~150,000원 | 문서화 상세, 협업 기능, 온보딩 가이드 포함 |
| 크몽식 맞춤 제작 외주 | 50,000~300,000원 | 페이지·DB·뷰 개수 기준 견적, 1:1 커스터마이징 |

### 진행 순서
1. AI에게 내 템플릿과 비슷한 사례를 참고해 저가/중가/고가 3가지 가격 시나리오를 근거와 함께 제안받는다.
2. 처음에는 후기·판매 기록을 쌓는 게 우선이므로 진입장벽을 낮게(위 표의 하단 가격대) 잡는다.
3. 후기가 10개 이상 쌓이면 중간가로, 30개 이상이면 정가로 단계적으로 인상한다.
4. 다음 상품(같은 니치의 템플릿 실물, 또는 확장판)과 묶어 파는 번들 가격도 함께 검토한다.

## 11. 방법 9 — 판매 페이지 카피와 미리보기

노션 템플릿은 실물을 만져볼 수 없는 상품이라, **미리보기 이미지와 카피가 구매 결정의 전부**라고 봐도 됩니다.

### 진행 순서
1. AI에게 템플릿명과 핵심 기능을 주고 판매 페이지 카피를 문제 제기형(이런 불편 겪어보셨죠)과 결과 중심형(이렇게 정리됩니다) 2가지 버전으로 요청한다.
2. 완성된 템플릿 화면을 3~4장 스크린샷으로 찍고, 각 장면에 짧은 캡션(무엇을 보여주는 화면인지)을 붙인다.
3. AI에게 구매를 망설이는 사람이 물어볼 만한 질문 6개와 답변(FAQ)을 요청해 페이지 하단에 배치한다.
4. "복제 후 5분 안에 시작 가능"처럼 구체적인 사용 경험을 강조하는 문구를 앞부분에 배치한다.

---

## 12. 방법 10 — 판매 채널 선택과 등록

채널마다 특성이 다릅니다. 처음엔 하나만 골라 집중하는 게 낫습니다.

1. **래피드(Latpeed)** — 사업자등록 없이 5분 만에 등록 가능, 국내 SNS(스레드 등)로 바로 홍보 연결이 쉽습니다. 이 시리즈에서는 이 채널을 기본으로 안내합니다.
2. **크몽** — 맞춤 제작 문의가 자연스럽게 들어오는 채널이라, 완성 템플릿 판매 + "커스터마이징 추가 제작" 투트랙 운영에 유리합니다. 수수료는 매출 구간별로 4.4~16.4%에 결제망 이용료가 별도로 붙습니다.
3. **노션 공식 템플릿 갤러리** — 검색 유입이 꾸준하지만 이미 3만 개 이상의 경쟁 템플릿이 있어, 니치가 뚜렷할수록 유리합니다.

### 진행 순서
1. 처음엔 래피드 하나에 집중해서 등록하고, 판매 페이지 카피(방법 9)와 미리보기 이미지를 그대로 활용한다.
2. 복제 링크(퍼블리시)를 결제 완료 후에만 전달되도록 안내 문구를 준비한다.
3. 반응이 확인되면 크몽에도 같은 상품을 올려 채널을 넓힌다.

---

## 13. 방법 11 — 후기로 개선하고 신뢰 쌓기

노션 템플릿은 눈에 안 보이는 상품이라 후기가 곧 신뢰입니다. 첫 구매자의 피드백을 다음 버전에 빠르게 반영하는 것이 장기적으로 가장 중요합니다.

### 진행 순서
1. 구매자에게 "어떤 부분이 좋았는지, 어떤 부분이 헷갈렸는지" 짧은 피드백을 요청한다(부담 없는 톤으로).
2. AI에게 받은 피드백을 정리해서 "구조를 바꿔야 할 부분"과 "가이드 문구만 보완하면 되는 부분"을 구분해달라고 요청한다.
3. 자주 나오는 질문은 가이드 문서와 판매 페이지 FAQ에 계속 추가한다.
4. 개선된 버전은 기존 구매자에게도 업데이트 안내를 남겨 재방문·재구매 가능성을 높인다.

---

## 14. 방법 12 — 라인업 확장(시리즈·번들)

템플릿 하나가 반응이 좋으면, 그 다음은 "같은 사용자에게 팔 수 있는 다음 상품"을 찾는 단계입니다.

### 진행 순서
1. 첫 템플릿을 산 사람이 다음으로 필요할 만한 기능을 AI에게 물어 후속 템플릿 아이디어를 받는다.
2. 관련 있는 템플릿 여러 개를 하나의 "시스템"으로 묶어 번들 가격을 제안받는다.
3. 시리즈 이름과 넘버링(예: 세컨드브레인 OS 01, 02…)을 붙여 다음 편에 대한 기대감을 만든다.
4. 번들은 개별 구매 대비 확실한 할인폭을 제공해 "몰아서 사는 게 이득"이라는 인식을 준다.

## 15. 바로 쓰는 프롬프트 20선

대괄호 부분만 바꿔서 그대로 붙여넣으세요. 카테고리별로 정리했습니다.

**A. 기획·구조 설계**
- A1 카테고리 발굴 — 내 관심사/경험/강점은 [목록]이야. 이걸로 만들 수 있는 노션 템플릿 카테고리 5개와 각각의 타겟 사용자를 제안해줘.
- A2 니치 좁히기 — "[넓은 카테고리]" 템플릿은 이미 많아. 더 구체적인 타겟으로 좁힌 니치 아이디어 5개를 제안해줘.
- A3 페이지 구조 설계 — [템플릿 주제]에 맞는 노션 페이지 트리 구조(홈 대시보드, 하위 페이지, 데이터베이스 위치)를 설계해줘.
- A4 대시보드 홈 레이아웃 — [템플릿 주제]의 홈 대시보드에 넣을 위젯/섹션을 우선순위와 함께 제안해줘.

**B. 데이터베이스·자동화**
- B1 DB 스키마 설계 — [템플릿 주제]에 어울리는 노션 데이터베이스 속성과 뷰(보드/캘린더/타임라인) 구성을 설계해줘.
- B2 수식 설계 — [원하는 계산 결과, 예: 진행률 %, D-day]를 노션 수식으로 어떻게 만들 수 있을지 수식 초안과 설명을 알려줘.
- B3 관계형·롤업 설계 — 이 두 데이터베이스([DB1]와 [DB2])를 관계형으로 연결하고 롤업으로 [원하는 값]을 자동 계산하고 싶어. 설정 방법을 단계별로 알려줘.
- B4 버튼·자동화 설계 — [반복 작업, 예: 매주 새 할 일 페이지 생성]을 노션 버튼/자동화 기능으로 처리하려면 어떻게 설정해야 하는지 알려줘.

**C. 비주얼·가이드**
- C1 아이콘·커버 컨셉 — [템플릿 주제]에 어울리는 톤의 아이콘·커버 이미지 컨셉을 색상 팔레트와 함께 제안해줘.
- C2 온보딩 가이드 — 이 템플릿을 처음 받은 사람을 위한 사용 가이드를 "복제 방법 → 첫 설정 → 매일 쓰는 법" 순서로 써줘: [템플릿 구조 설명]
- C3 예시 데이터 채우기 — [템플릿 주제]에 넣을 예시 데이터를 만들어줘. 너무 완벽하지 않게 현실적인 수준으로.
- C4 자주 하는 실수 안내 — [템플릿 주제] 초보 사용자가 자주 하는 설정 실수 5가지와 예방법을 정리해줘.

**D. 가격·판매 페이지**
- D1 가격 책정 — 비슷한 노션 템플릿의 가격대를 참고해서 [템플릿 주제]의 초기가/인상가를 근거와 함께 제안해줘.
- D2 판매 페이지 카피 — [템플릿명]의 판매 페이지 카피를 문제 제기형/결과 중심형 2버전으로 써줘. 각 제목-소개-포함 구성-FAQ 구조로.
- D3 미리보기 이미지 문구 — 판매 페이지에 넣을 스크린샷 3~4장 각각에 붙일 짧은 설명 캡션을 만들어줘: [화면별 설명]
- D4 FAQ 초안 — [템플릿명]을 살까 말까 고민하는 사람이 물어볼 질문 6개와 신뢰가 가는 답변을 만들어줘.

**E. 홍보·확장**
- E1 홍보 후킹 문장 — [템플릿 설명]을 한 문장으로 요약해서 SNS 후킹 문장 5개를 만들어줘.
- E2 사용 전후 비교 — "이 템플릿 쓰기 전/후"를 비교하는 홍보 콘텐츠 문구를 만들어줘.
- E3 번들 구성 제안 — [기존 템플릿 목록]을 참고해서 함께 묶어 팔면 좋을 번들 구성과 할인 근거를 제안해줘.
- E4 다음 템플릿 발굴 — 지금까지 반응 좋았던 템플릿은 [내용/데이터]야. 비슷한 다음 템플릿 아이디어 5개와 이유를 제안해줘.

## 에필로그

노션 템플릿은 화려한 디자인이 아니라, 열자마자 "이거 나한테 딱 맞네"라는 느낌을 주는 구조에서 시작합니다. 데이터베이스 속성 하나, 수식 하나, 가이드 한 줄이 "저장만 하고 안 쓰는 템플릿"과 "계속 열어보는 템플릿"을 가릅니다.

AI는 그 구조를 빠르게 초안으로 만들어 줍니다. 하지만 어떤 니치를, 어떤 순서로 설계할지는 이 책에서 다룬 방법이 대신해줍니다. 오늘, 방법 1부터 딱 하나만 적용해 보세요.
