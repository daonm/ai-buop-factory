4계산기
2026년 기준표
4단계 판매 체크리스트
『은행원도 아닌데, 대출 계산은 해드릴 수 있습니다』를 읽은 다음날 바로 펼치는 실행용 워크북입니다.

계산기는 다 만들어놨습니다. 이제 조건만 넣으면 됩니다. 이 키트는 전자책 방법 2·3·4·5·6(상환 계산·대환 순이익·중도상환수수료·전월세전환·갱신 상한)을 이미 끝낸 완성본입니다.

엑셀 파일 4개 모두 같은 구조로 만들었습니다.

  1. 안내 시트 — "참고용 계산 도구이며 법률·금융 자문을 대신하지 않는다"는 경계를 첫 화면에 명시합니다.
  2. 기준표 시트(해당 파일만) — 중도상환수수료 감면 구조, 전월세전환율 법정 상한처럼 자주 바뀌는 기준을 따로 모아뒀습니다.
  3. 계산기 시트 — 노란색 칸에 숫자를 입력하면 올리브색 칸에 결과가 바로 뜹니다.

사용법 — 아래 계산기별 참고표에서 원하는 것부터 확인하고, 실제 파일을 열어 본인(또는 상담 대상) 조건으로 한 번 테스트해본 뒤 상담·판매를 시작하세요.

01계산기 4종 빠른 참고표

각 계산기의 입력값 예시, 결과값, 그리고 어떤 순서로 이어 쓰는지를 정리했습니다. 실제 파일에 그대로 입력해 결과를 재현할 수 있습니다.

A. 대출상환 비교 계산기
파일 — 대출상환_비교_계산기.xlsx · 원금·연이율·상환개월수를 입력하면 원리금균등·원금균등 두 방식의 월상환액·총이자·회차별 내역을 나란히 계산합니다
입력값결과값
원금 / 연이율 / 기간3억원 / 4.5% / 360개월원리금균등 월상환액1,520,056원
원금균등 첫 달 상환액1,958,333원총이자 차액44,157,635원

이런 상담에게 — "매달 똑같이 낼지, 초반에 조금 더 내고 이자를 아낄지" 고민하는 대출 초기 상담. 회차별 내역표로 초반 부담 차이를 눈으로 보여줄 수 있습니다.

B. 대환대출 순이익 계산기
파일 — 대환대출_순이익_계산기.xlsx · 기존·신규 대출 조건과 중도상환수수료를 입력하면 "갈아탔을 때 진짜 남는 돈"과 손익분기 개월수를 계산합니다
입력값결과값
잔액 3억 / 4.8%→3.9%남은 240개월대환 순이익32,028,102원
중도상환수수료 + 부대비용2,200,000원 + 500,000원손익분기 개월수18.7개월

이런 상담에게 — "금리가 낮아졌는데 갈아타야 할지" 묻는 대환 상담. 수수료를 빼먹지 않고 계산한 순이익과 손익분기 개월수, 두 숫자를 함께 보여주면 신뢰가 생깁니다.

C. 전월세전환율 계산기
파일 — 전월세전환율_계산기.xlsx · 줄이는 보증금과 전환율을 입력하면 월세와 법정 상한 월세를 함께 계산하고, 갱신 계약의 적법 여부를 자동 판정합니다
입력값결과값
줄이는 보증금 / 전환율5,000만원 / 5.5%월세229,167원
한국은행 기준금리3.0%법정 상한 월세(갱신 한정)208,333원

이런 상담에게 — "보증금 일부를 월세로 돌리면 얼마가 될지" 궁금한 세입자. 법정 상한은 갱신 계약에만 강제된다는 점을 먼저 설명한 뒤 이 계산기를 보여주세요.

D. 전세갱신 상한 계산기
파일 — 전세갱신_상한_계산기.xlsx · 기존 보증금과 집주인 요구액을 입력하면 갱신청구권 5% 상한 기준 적법 여부를 판정하고, 인상분 분산 시나리오 3개를 비교합니다
입력값결과값
기존 보증금 / 요구 인상액3억원 / 2,000만원적법 여부상한 초과 — 협상 필요
인상 가능 최대 금액1,500만원초과 금액500만원

이런 상담에게 — 갱신 시기에 집주인이 인상을 요구했는데 "이게 맞는 금액인지" 확인하고 싶은 세입자. 상한 초과 금액과 분산 시나리오까지 한 번에 보여줄 수 있습니다.

03판매 준비 체크리스트

브리프부터 등록까지, 순서대로 체크하며 진행하세요.

1단계검증

  • Worksheet 2로 계산기 4종 모두 내(또는 지인의) 실제 조건으로 테스트하기
  • 은행 앱 실제 상환 스케줄·중도상환수수료 조회 결과와 대조해 오차 확인하기
  • 계산기 시트에 확인한 금리·수수료율과 확인 날짜 메모 남기기

2단계다듬기

  • 입력 셀(노란색) 옆에 "여기에 숫자를 입력하세요" 안내 문구 확인하기
  • "법률·금융 자문이 아닌 참고용 계산"이라는 경계 문구가 각 파일에 잘 붙어있는지 확인하기
  • 파일명·시트명에 오탈자 없는지 최종 점검하기

3단계등록

  • Worksheet 1로 패키지·가격 확정하기
  • 래피드에 상품명 "계산기/대환/전세갱신" 단어 포함해 등록하기
  • Day35 전자책과 세트 상품(업셀) 옵션도 함께 등록하기

4단계갱신 관리

  • 한국은행 기준금리·DSR 규제 비율 변경 공지 분기마다 확인해 캘린더에 표시해두기
  • 기존 상담 고객 연락처/알림 목록 만들어두기(다음 갱신 시점 안내용)
  • 법정 상한·수수료율 변경 시 C·D 계산기 기준표만 교체 후 Worksheet 2 검증 다시 거치기

조건을 넣고, 검증하고, 숫자로 답하세요.
