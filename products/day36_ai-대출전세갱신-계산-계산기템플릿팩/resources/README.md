# AI 대출·전세 갱신 계산 자동화 — 대출상환·전월세 전환 계산기 템플릿팩 사용 가이드

『은행원도 아닌데, 대출 계산은 해드릴 수 있습니다』(Day35 전자책)를 읽은 다음 바로 펼치는 실전 실행 자료입니다. 전자책 방법 2·3·4·5·6(원리금균등·원금균등 상환 계산기·대환대출 비교·중도상환수수료·전월세전환율·전세 갱신 상한)을 이미 끝내둔 완성본 엑셀 계산기 4종을 그대로 판매하거나, 본인 상황에 맞게 커스터마이징해서 팔 수 있습니다.

## 구성 파일

| 파일 | 내용 |
|---|---|
| `kit.html` | 계산기 4종 빠른 참고표(입력·결과 예시) + 패키지·검증 워크시트 + 판매 준비 체크리스트를 한눈에 보기 좋게 디자인한 버전 (브라우저로 열거나 PDF로 인쇄) |
| `계산기가_답을_먼저_드립니다.pdf` | `kit.html`을 인쇄한 PDF 버전 (오프라인·인쇄용) |
| `대출상환_비교_계산기.xlsx` | 원금·연이율·상환개월수를 입력하면 원리금균등상환과 원금균등상환 두 방식의 월상환액·총이자를 자동 비교하고, 1~12회차 상환 스케줄을 두 방식 나란히 보여준다 |
| `대환대출_순이익_계산기.xlsx` | 기존 대출과 신규 대출 조건, 중도상환수수료·부대비용을 입력하면 "갈아탔을 때 아끼는 총이자 − 중도상환수수료 − 부대비용"으로 대환 순이익을 계산하고, 손익분기 개월수와 여러 은행 후보 비교표까지 제공 |
| `전월세전환율_계산기.xlsx` | 줄이는 보증금과 전환율을 입력하면 월세를 계산하고, 한국은행 기준금리 기반 법정 상한(갱신 계약 한정)과 자동 비교. 보증금 감액 구간별 월세 시뮬레이션 표 포함 |
| `전세갱신_상한_계산기.xlsx` | 기존 보증금과 집주인 요구 인상액을 입력하면 갱신청구권 5% 상한 기준 적법 여부를 자동 판정하고, 인상분을 보증금/월세로 나누는 3가지 분산 시나리오를 비교 |

## 엑셀 파일 공통 구조

네 파일 모두 같은 구조로 만들었습니다.

1. **안내 시트** — "참고용 계산 도구이며 법률·금융 자문을 대신하지 않는다"는 경계를 첫 화면에 명시합니다. 판매 시 상세페이지에도 동일한 문구를 그대로 가져다 쓰세요.
2. **기준표 시트(대환대출·전월세전환율 계산기만 해당)** — 중도상환수수료 감면 구조, 전월세전환율 법정 상한 공식처럼 자주 바뀌는 정보를 따로 모아뒀습니다(2026년 9월 확인 기준). 기준이 바뀌면 이 시트를 참고해 계산기의 입력값만 새로 넣으면 됩니다.
3. **계산기 시트** — 노란색 칸에 숫자를 입력하면 올리브색 칸에 결과가 자동으로 뜹니다. 수식은 모두 셀에 그대로 들어있어 필요하면 직접 열어 확인·수정할 수 있습니다.

## 계산기 4종을 잇는 순서

1. **대출상환 비교 계산기**로 상담 대상의 원리금균등·원금균등 상환액과 총이자 차이를 먼저 보여줍니다.
2. 금리를 갈아탈 여지가 있다면 **대환대출 순이익 계산기**로 중도상환수수료까지 반영한 "진짜" 순이익과 손익분기 개월수를 확인합니다.
3. 전세 갱신·보증금 조정 상담이라면 **전월세전환율 계산기**로 적정 월세와 법정 상한을 함께 보여줍니다.
4. 집주인이 인상을 요구한 상황이라면 **전세갱신 상한 계산기**로 적법 범위를 판정하고, 인상분 분산 시나리오까지 제안합니다.

## 3단계 사용법

1. **`kit.html`(또는 PDF)로 계산기 4종 훑어보기** — 어떤 계산기가 어떤 상황에 맞는지, 입력·결과 예시가 어떻게 나오는지 빠른 참고표로 먼저 확인합니다.
2. **본인(또는 상담 대상) 조건으로 직접 테스트하기** — `kit.html`의 Worksheet 2(교차검증)를 참고해 실제 엑셀 파일에 실제 대출·전세 조건을 넣어보고, 은행 앱의 실제 상환 스케줄·중도상환수수료 조회 결과와 대조합니다.
3. **패키지·가격 정하고 등록하기** — `kit.html`의 Worksheet 1(패키지 계산기)로 단품/세트/상담 가격을 정한 뒤, 상품명에 "계산기", "대환", "전세갱신"이라는 단어를 넣어 래피드 등에 등록합니다.

전체 진행 순서를 놓치지 않으려면 `kit.html`의 판매 준비 체크리스트(검증 → 다듬기 → 등록 → 갱신 관리)를 등록 시작 전부터 펼쳐두고 순서대로 체크하세요.

## 주의 사항

이 계산기들은 법률·금융 자문이 아니라 **참고용 계산 도구**입니다. 금리·수수료율·법정 상한 기준은 정책과 은행에 따라 자주 바뀌므로, 실제 상담이나 판매에 사용하기 전 반드시 최신 정보로 재확인하세요. 최종 의사결정(대환 여부, 계약 진행 여부)은 항상 고객 본인의 몫으로 남겨두어야 합니다.
